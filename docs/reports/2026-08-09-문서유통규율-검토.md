# 검토 보고서 — 지시서·보고서 폴더 유통 규율 (ADR-97)

> 수신: 지휘부 · 발신: 클로드코드(클코1)
> 작성: 2026-08-09 · 기준 커밋: `164af43`
> 대상: 「앞으로 모든 작업지시서는 `docs/tasks/`, 보고서는 `docs/reports/`」 지시

---

## 0. 결론

**수용.** 다만 **30분 전 ADR-96과 정면 충돌**하므로 `.gitignore` 구조를 바꿔야 성립한다. 되돌리는 것이 아니라 **뒤집는다.**

---

## 1. 수용 — 지시의 취지

채팅은 휘발되고, 지휘부는 fresh clone 으로 감리한다(ADR-88 규율). 지시서와 보고서가 저장소에 없으면 **감리 대상과 감리 근거가 따로 논다.** 지금까지 `CC_ORDER_*.md` 4건이 저장소 **루트에 흩어져** 있었던 것도 정리된다.

| 현재 루트에 흩어진 것 |
|---|
| `CC_ORDER_checkin_session3.md` |
| `CC_ORDER_coach_report_detail_v2.md` |
| `CC_PLAN_checkin_rollout.md` |
| `CC_REPORT_checkin_rollout.md` |

→ **이관 여부는 지시를 기다린다.** `git mv` 로 이력을 보존해 옮길 수 있으나, 이관하면 기존 ADR 본문의 경로 인용이 어긋나므로 함께 갱신해야 한다.

---

## 2. 보완수용 ① — ADR-96과 충돌한다. 해법은 되돌리기가 아니라 뒤집기

**문제.** 30분 전 ADR-96이 `.gitignore` 에 `/docs/` 를 넣어 **통째로** 막았다. 그대로 두면 `docs/tasks/` 도 `docs/reports/` 도 push 되지 않는다. 실제로 도착한 지시서가 차단돼 있었다.

```
docs                 .gitignore:46:/docs/   docs
docs/tasks           .gitignore:46:/docs/   docs/tasks
docs/reports         .gitignore:46:/docs/   docs/reports
```

**해법.** `/docs/` 를 지우고 **기본 차단 + 명시 허용**으로 바꾼다.

```gitignore
/docs/*
!/docs/tasks/
!/docs/reports/
```

**이것은 ADR-96보다 약한 자세가 아니라 강한 자세다.** 종전은 "docs 를 막는다"였고, 이제는 "docs 는 전부 막되 지시서·보고서 두 자리만 연다"이다. 녹취록·워크북·상담 기록이 `docs/` 에 다시 떨어져도, **새 하위 폴더를 만들어 떨어져도** 자동으로 걸린다.

**문법 함정 — 이 구조를 단순화하면 안 된다.** git 은 **디렉터리 자체가 제외되면 그 안의 negation 을 보지 않는다.** `/docs/` + `!/docs/tasks/` 는 **동작하지 않는다.** 반드시 `/docs/*`(한 겹만 제외) 여야 한다. `.gitignore` 주석에 이 사실을 남겼다.

### 실측 (양방향)

| 경로 | 기대 | 결과 |
|---|---|---|
| `docs/tasks` | 추적 가능 | ✓ |
| `docs/reports` | 추적 가능 | ✓ |
| `docs/tasks/GALMURI_ORDER_S3_rev1.md` | 추적 가능 | ✓ |
| `docs/녹취록-테스트.txt` | 차단 | ✓ |
| `docs/원문/상담기록.md`(새 하위 폴더) | 차단 | ✓ |
| `docs/무엇이든.md` | 차단 | ✓ |

## 3. 보완수용 ② — 두 폴더의 내용에도 §6.0이 걸린다

`docs/tasks/` 와 `docs/reports/` 는 **공개 저장소**에 올라간다. 저장소가 public 인 사실은 바뀌지 않았다.

- **보고서**: 실측 수치·집계·문안은 되지만 개인을 지목하는 서술은 안 된다.
- **지시서**: 이쪽이 더 위험하다. 이번에 도착한 지시서만 해도 **녹취 인용 두 건**(`[46:10]` 인도자 발언, `[139:45]` 참여자 소감)이 들어 있다. 발언만 있고 이름이 없어 이번은 통과지만, 같은 형식으로 이름이 한 번 섞이면 그대로 공개된다.

**규율로 못박기를 청한다.** 지시서에 실명·연락처·식별 가능한 정황이 섞여 오면 **클코1 은 커밋하지 않고 먼저 보고한다.** 두 폴더의 `README.md` 에 이 규율을 적어 두었다.

---

## 4. 판단해서 진행한 것

**보고 채널은 병행으로 본다.** 지시가 "보고하거나 … 보고해 주면 된다"라 대체인지 병행인지 갈리는데, **채팅에는 요약, 파일에는 전문**으로 잡았다. 즉시 읽을 것과 나중에 감리할 것은 분량이 다르다. 다르게 보시면 고치겠다.

파일명은 `YYYY-MM-DD-<슬러그>-검토.md` / `-완료.md`, 슬러그는 대응 지시서와 맞춘다. 발신 대화창이 자체 명명한 지시서는 그 이름을 그대로 둔다.
