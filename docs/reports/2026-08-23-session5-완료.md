## 2. 레지스트리 가드 통합 — 순서를 지켰습니다

**지우기 전에 세웠습니다.** 최종 메모 §1의 *"이 다섯이 서고 나서 기존 넷을 삭제한다 — 지우고 만들면 그 사이에 커버리지가 빈다"* 를 그대로 이행했습니다.

1. `registry.guard.test.ts` 를 **4회차 기준으로** 먼저 세워 5건 통과 확인 (`NEXT` = 5)
2. 그다음 기존 넷 삭제
3. 그다음 5회차 등록 → 가드가 **`FILES` 한 줄 추가만으로 자동 적응** (`NEXT` 5→6)

3번이 파생 방식이 실제로 작동한다는 실증입니다.

### 흡수한 단언 — 하나도 잃지 않았습니다

| 원래 있던 곳 | 무엇 | 통합 파일에서 |
|---|---|---|
| `session3.test.ts:47` · `session4.test.ts:52` | **객체 동일성**(`toBe`) | `레지스트리가 문안 파일 객체를 그대로 돌려준다` |
| `session2.test.ts:96` | 경계 방어(`0`) | `경계 밖은 null — 0 · 음수 · 다음 회차 · 먼 회차` (음수·먼 회차를 **더했습니다**) |
| `readModel.test.ts:295~297` | `readSelfHighlights` · `anonNoticeText` · `facilitator` 모드 | `읽기 경로 넷이 미등록 회차에서 파손되지 않는다` |

`sessionNo` 만 보면 레지스트리가 복사본을 돌려줘도 통과합니다. **`toBe` 만이 그것을 잡습니다.**

### 파생이 막는 구멍

```ts
const PROBE = Array.from({ length: 12 }, (_, i) => i + 1);
const REGISTERED = PROBE.filter((n) => getCheckinSession(n) !== null);
const NEXT = REGISTERED.length + 1;
```

`it('1부터 빈틈없이 이어진다')` 가 **오타로 6을 건너뛰고 7이 등록되는 경우**를 잡습니다.
손으로 적은 `REGISTERED = [1..5]` 로는 그것이 조용히 통과합니다.
`it('등록 회차 수와 문안 파일 수가 같다')` 가 등록/파일 불일치를 양방향으로 잡습니다.

**회차를 등록할 때 이 파일에서 고칠 것은 `FILES` 한 줄뿐입니다.**

## 6. 착수 중 잡은 것 — 지시서 설명문의 사실 오류 한 건

지시서 §3-3이 3회차 `connector` 를 **`↓ 그 자리에`** 라고 적었으나 실제 값은 **`↓ 그 자리를 만들려면`** 입니다.

산출물에는 영향이 없습니다 — 그 문자열은 지시서의 **설명 문구**이지 5회차 문안이 아닙니다.
다만 제가 그 값을 그대로 비교 단언에 옮겨 적어 테스트가 레드로 떴고, 실제 값으로 고쳤습니다.
`session5.test.ts` 가 이제 3·4·5회차 `connector` 셋을 나란히 잠급니다(교체 · 인과 · 조건).

| ② 지난 걸음 위 | 캡션은 `…한 걸음과 첫 도미노` 인데 **첫 도미노 값이 빠진 채** 두 값만 |

**§10 미리보기 점검을 그대로는 수행하실 수 없습니다.** 지시서 §10이 요구한
*"되비추기 회색 상자"* 와 *"withPrior 를 끄면 되비추기가 사라진다"* 를 확인할 방법이 없습니다.

**참여자 화면은 멀쩡합니다** — `page.tsx` 가 실제 4회차 `answers` 를 봉투로 넘깁니다.
표본만 빈약합니다. 실측상 4회차 10행 중 `step_blocker` 7행 · `domino_what` 8행이 있어
**표본이 실제보다 빈약합니다**(`domino_what` 은 4회차 **필수**라 거의 항상 있습니다).

고치신다면 두 줄입니다.

```diff
 const SAMPLE_BACK1: Record<string, unknown> = {
+  step_blocker: '야근이 늦게 끝나는 수요일',
+  domino_what: '아버지와 매주 한 번 통화하기',
```

### ⓐ 심화 ②의 `placeholder` 둘이 화면에 뜨지 않습니다

**심화 ②의 `placeholder` 둘이 화면에 뜨지 않습니다.**

지시서 §3-6이 지정한 값입니다.

```
domino_if   placeholder: '월요일 아침 사무실에 앉으면'
domino_then placeholder: '그 자료를 30분 먼저 연다'
```

`CheckinCardClient.tsx:486` 의 심화 렌더가 `TextArea` 에 `placeholder` 를 넘기지 않습니다.

```tsx
<TextArea value={str(f.key)} onChange={…} rows={f.key === 'letter_line' ? 4 : 2} ariaLabel={f.label} />
```

**5회차가 처음입니다** — 1~4회차 심화에 `placeholder` 선언이 **0건**이라 그 자리가 필요한 적이 없었습니다.
타입(`CheckinField`)은 `placeholder` 를 허용하므로 선언 자체는 정상이고, 렌더만 무시합니다.

### 고치지 않았습니다

§9 수용 기준이 **`CheckinCardClient.tsx` 의 렌더 경로 변경 0** 을 명시적으로 못 박았습니다.
그 조항은 제 1차 검토가 범위 초과를 지적한 뒤 최종 메모가 세운 가드라, 제 판단으로 넘지 않았습니다.

대신 **상태를 정직하게 남겼습니다** — `session5.ts` 에 주의 주석, `session5.test.ts` 에 명시 단언
(`심화 ②의 placeholder 가 선언돼 있다 — 렌더는 아직 넘기지 않는다`).
선언을 지우지 않은 이유: 지우면 *"지시서가 값을 줬는데 왜 없지"* 를 다음 사람이 다시 묻습니다.

### 고치신다면 한 줄입니다

```diff
- <TextArea value={str(f.key)} onChange={…} rows={f.key === 'letter_line' ? 4 : 2} ariaLabel={f.label} />
+ <TextArea value={str(f.key)} onChange={…} rows={f.key === 'letter_line' ? 4 : 2} placeholder={f.placeholder} ariaLabel={f.label} />
```

1~4회차 심화에 `placeholder` 가 0건이라 **기존 회차 화면은 한 픽셀도 바뀌지 않습니다.**
`CheckinPreviewClient` 는 `CheckinCardClient` 를 재사용하므로 미리보기도 함께 삽니다.

**두 칸 짝에서 예시가 보이지 않으면 `나는` 옆의 빈 상자가 상당히 막막합니다.** 권합니다.

### 이 건이 드러낸 규율 하나

**리터럴 잠금은 선언을 지키지 배달을 지키지 않습니다.**
ⓐ가 그 증거입니다 — 문안 대조도, `copyBaseline` 도, 금지어 검사도 전부 통과하는데
그 값이 화면에 닿지 않았습니다. 세 검사 모두 *선언된 문자열*만 봤기 때문입니다.

### 검증이 함께 잡은 경미 셋 (조치함)

| 지적 | 조치 |
|---|---|
| `session5.ts` 머리말이 `identity` 를 `한 줄 입력`이라 했으나 실물은 2행 상자 | 주석을 `짧은 서술 상자(2행)` 로 정정 |
| `placeholder` 주의 주석이 `domino_if` 에만 붙어 `domino_then` 은 절반만 기록됨 | 둘 다 가리키도록 고침 |
| `architecture.md` ADR-108 의 vitest 수치가 실측과 1 어긋남 | **706** 으로 정정 |

### 검증이 지적했으나 고치지 않은 것

`registry.guard.test.ts` 주석이 *"읽기 경로는 넷"* 이라 했으나 `readModel` 이 회차번호를 받는
내보내기는 다섯입니다(`readAnonSuggestion`·`needLabel` 이 밖). **기존 넷도 그 둘을 지키지 않았으므로
커버리지가 준 것은 아니고**, 최종 메모 §1이 요구한 넷은 그대로 충족합니다.
다만 *"한 곳에 모아 다음 회차에 또 빠지지 않게 한다"* 는 취지에는 구멍이 남습니다 — **6회차 이월 후보**입니다.

`architecture.md` ADR-91 행에 *"2기 시작 전에 바꾸면 저장값이 없어 안전하다"* 가 아직 남아 있습니다.
그쪽은 1·2회차 마음 낱말 **교체**라 ADR-91 R1이 실제로 금지하는 경우이고, 최종 메모 §7이 경고한
*"근거가 틀렸는데 결론이 우연히 맞은 것"* 이 문서에 그대로 서 있습니다. **이번 범위 밖이라 손대지 않았습니다.**
