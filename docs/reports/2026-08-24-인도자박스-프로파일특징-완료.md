## 0. 지시서 검토 — 오류 1 · 반박 1 · 보완수용 1

### 오류 — §3 '확정 사실'의 타입이 실제와 다르다

> 지시서: `vitality: { total: number; band: ...; low: boolean }`

실제 계약은 **`vitality: { score: number; low: boolean }`** 입니다 — `total`도 `band`도 없습니다([scoring.ts:20](src/instruments/futurenow/scoring.ts#L20)). 구간명은 `vitalityZone(score)`가 줍니다.

조건 자체(`≤10`·`≥18`)는 옳아서 **값 접근만 고쳐** 실행했습니다.

### 반박 — 활력 임계를 상수표에 넣지 않았다

§4.1은 임계 열 개를 *"상수로 한 곳에 모아 두면 최박사가 조정하기 쉽다"*고 했고 그 취지는 맞습니다. 그러나 **활력의 `≤10`·`≥18`은 이미 확정된 경계**입니다.

| 곳 | 값 |
|---|---|
| `VITALITY_ZONES` | 시들음 ≤10 · 중간 11~17 · 번성 18~25 (ADR 확정 2026-06-28) |
| `scoring.ts:49` | `low: vitalityScore <= 10` |
| `labels.test` | 위 경계를 잠금 |

여기 사본을 두면 시들음 경계가 **세 곳**이 되고, 하나만 고쳤을 때 **화면의 구간명과 플래그가 어긋납니다.** 조정하기 쉬우라고 만든 상수가 정반대로 작동합니다.

→ **활력만 `vitalityZone()`을 그대로 부르고**, 나머지 여덟 임계는 지시대로 `FLAG_THRESHOLDS` 한 표에 모았습니다. 테스트가 상수표에 활력 키가 **없음**을 단언해 되살아나지 않게 합니다.

### 보완수용 — 문구 둘의 방향이 거꾸로 읽힌다

`gap.B1~B5`는 *"5년 후 완성된 나를 10점이라 할 때 지금의 나는 몇 점"* 이라 **높을수록 이상에 가깝습니다.**

| 지시서 문구 | 문제 | 채택 |
|---|---|---|
| `간격 관계·기여 높음` | 조건(B3·B5 ≥ 7)은 **강점**인데 "간격이 크다(약점)"로 읽힘 | **`관계·기여 점수 높음`** |
| `간격 한 축만 깊이 함몰` | `함몰`이 이미 방향을 말하는데 `간격`을 붙여 이중 | **`한 영역만 깊이 함몰`** |

앞의 것은 관련 원형(따뜻한 표류형 — 관계·기여가 강점)과도 어긋납니다. **정반대로 오독되면 인도자가 반대편 원형 가설을 세웁니다** — 이 기능의 목적이 그대로 무너집니다. 상수표 옆 한 줄이라 되돌리기 쉽습니다.

## 2. 플래그 조건과 임계

```ts
export const FLAG_THRESHOLDS = {
  growEven: 4,       growSpread: 2,    realismLead: 1,   oneThingLow: 2.5,
  gapSink: 3,        warmHigh: 7,
  compassLow: 2,     compassHigh: 4,   compassCount: 2,
} as const;
// 활력 임계는 여기 없다 — VITALITY_ZONES 를 그대로 부른다(§0 반박).
```

표시 순서 **활력 → 준비도 → 간격 → 나침반**, 조건에 맞는 것만.

| 플래그 | 조건 |
|---|---|
| 활력 시들음 구간 / 번성 구간 | `vitalityZone(score)` |
| 준비도 다섯 축 고르게 높음 | `min(GROW) ≥ 4` |
| 준비도 편차 큼 | `max − min ≥ 2` |
| 현실인식이 준비도 중 두드러지게 높음 | `R = max` **이고** `R − 2위 ≥ 1` |
| 정체성이 준비도 중 단독 최저 | 나머지 넷이 **모두** F보다 큼 |
| 원씽 낮음 | `O ≤ 2.5` |
| 한 영역만 깊이 함몰 | 나머지 넷 평균 − 최저 ≥ 3 |
| 관계·기여 점수 높음 | `B3 ≥ 7` **이고** `B5 ≥ 7` |
| 나침반 좌측 쏠림 / 우측 지향 | 각각 2축 이상이 ≤2 / ≥4 |

**주관식(E1~E3)은 쓰지 않습니다** — 감정을 자동 판정하지 않습니다.
