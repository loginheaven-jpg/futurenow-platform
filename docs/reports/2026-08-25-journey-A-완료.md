## 0. 착수 전 확인 — 반박 없음

확정 메모의 인수 기준 중 **재측정이 필요한 것 하나**를 먼저 확인했습니다.

> `□ 1기 데이터로 급락 2건이 잡힌다 (1→2 · 1→4)`

`직전 응답 회차` 정의(같은 사람의 응답을 회차순으로 `LAG`)로 재측정했습니다.

| 구간 | 값 | 낙폭 | 간격 |
|---|---|---|---|
| `1→2` | 8 → 3 | 5 | 인접 |
| `1→4` | 5 → 2 | 3 | 세 회차 건너뜀 |

**정확히 2건, 메모 그대로**입니다. 반박 없이 착수했습니다.

## 2. 계약 확장 둘

```ts
listCohortCheckins(cohortId: string, sessionNo?: number): Promise<CheckinRecord[]>;
listCohortMembers(cohortId: string, onlyParticipants?: boolean): Promise<MemberRef[]>;
```

`ⓑ'` 채택대로 **RPC 에 선택 인자**를 더했습니다. **기본값이 기존 동작**이라 호출부 다섯 중 넷이 무변경입니다.

```sql
p_only_participants boolean DEFAULT false
...
AND (NOT p_only_participants OR u.role = 'user')
```

**구 시그니처를 먼저 `DROP` 했습니다** — 인자 개수가 다르면 오버로드로 둘이 공존합니다. 적용 후 확인:

```
시그니처  cohort_member_directory(uuid,boolean)
함수개수  1        ← 오버로드 없음
auth실행  true     anon실행  false
```

## 3. `true` 로 부르는 곳과 그 회귀

| 호출부 | 인자 | 결과 |
|---|---|---|
| 회차 현황 `checkin/page.tsx:34` | **true** | 명단 11 → **9**(의도된 회귀) |
| 화면 A `member/[userId]/page.tsx` | **true** | 참여자 아닌 `userId` 는 회차 현황으로 되돌림 |
| 차수 상세 · 차수 목록 · 코치 홈 · **리포트 PDF 헤더** | 기본(false) | **무변경** |

리포트 헤더를 기본값으로 둔 것이 핵심입니다 — `role<>'user'` 계정이 1기 사전 체크 응답을 **1건 실제로** 갖고 있어, 기본을 바꿨다면 그 리포트 헤더가 `'참여자'` 로 폴백됐습니다.

회차 현황 명단이 줄어도 **운영자가 자기 갈무리를 잃지 않습니다** — 본인 경로(`/my/cohorts/.../checkin/...`)는 본인 RLS 라 그대로 접근합니다(1기 `coach` 가 실제로 2건을 작성 중입니다).

## 4. 종단 축 — `AXIS_INDEX`

```ts
export const AXIS_INDEX: Record<number, number> = { 1: 0, 2: 1, 3: 0, 4: 3, 5: 0 };
```

테스트가 이 표가 가리키는 라벨을 **문안 원문과 대조**합니다.

| 회차 | 라벨 | 인덱스 |
|---|---|---|
| 1 | 갈망 (pair) | 0 |
| 2 | 인생의 한 문장 | **1** |
| 3 | 지금 가장 바라는 것 | 0 |
| 4 | 인생의 원씽 | **3** |
| 5 | 바꾼 환경 | 0 |

`[0]` 이 왜 안 되는지도 테스트가 함께 못 박습니다(2회차 `[0]`=`영역` · 4회차 `[0]`=`이번에 시작할 프로젝트`).

**주석 정정 둘**을 `index.ts` 에서 함께 했습니다.

- 축: `영역3` → **`바라는 것3`** (`gap_area` 는 `summaryFields` 에 없고 낱말 하나입니다)
- 배속: `남은 시간6 → 정체성 선언7` → **`정체성 선언6`** · `facilitatorBox.defaultOpen` 의 `7회차만` → `6회차만`

> **6회차 착수 시 안내**: `CC_ORDER_checkin_session6.md` §7 의 `Mirror.back` 주석 항목은 **ADR-118 이 이미 반영했습니다. 건너뛰십시오.** 파일 경로는 `slots.ts` 가 아니라 **`index.ts:31`** 입니다.

**`docs/tasks/` 의 지시서 파일은 고치지 않았습니다** — 발주 문서가 수신자 손에 바뀌면 대조 기준이 사라집니다.

`자신감 급락`은 **제출분만** 봅니다(초안 값은 아직 바뀝니다). 그래야 1기 실측 2건과 일치합니다.
