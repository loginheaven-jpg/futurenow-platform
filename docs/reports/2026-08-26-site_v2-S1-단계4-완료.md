## 2. 하나의 픽스처, 두 구현

이 저장소가 반복해서 데인 실패는 **"사본이 둘"** 이다(ADR-112 `CARE_TONE` · ADR-114 활력 임계 ·
ADR-119 문안). 회원 상태에서 그 사본이 생길 자리는 정확히 하나 — **응시 가부를 SQL 과 화면이
각자 알고 있게 되는 순간**이다.

그래서 규칙을 **데이터로 한 번만** 적었다.

```
tests/fixtures/membershipAccess.ts
  ACCESS_TABLE     상태 × 계열 → 응시 가부 (5행)
  PRIORITY_CASES   우선순위 진실표 (9케이스)
```

- **① SQL** — `member_can_assess` · `member_state` 가 이 표를 향해 검증받는다.
- **② 화면** — 단계 5의 표시 매핑이 **같은 표**를 본다. 파일 말미에 물릴 자리를 주석으로 못 박았다.
- **이 표는 런타임 코드가 아니다.** 앱이 import 해 판정하면 그 순간 사본이 셋이 된다.
  판정은 `member_state()` 하나이고 이 파일은 그것을 **재는 자**다.

**픽스처가 스스로 온전한지도 잠갔다**(단위테스트 7건) — 다섯 상태 전수 덮음 · 중복 없음 ·
**열람 열이 없음**(메모 §2-가 확정이 표에 열람이 생기면 무너지므로 *없음*을 단언한다) ·
응시 가능 상태는 `cohort`·`individual` 둘뿐 · 여정을 여는 상태는 `cohort` 하나.

## 4. 자진 신고분 해소 — `toMemberState`

단계 2·3에서 *"테스트 없이 서 있다"* 고 신고한 건을 닫았다.

`src/core/context.ts` 의 모듈 전용 함수라 **테스트가 닿지 못했다.** `src/core/membership.ts` 로 떼어 내고
단위테스트를 걸었다 — 다섯 상태 통과 · **계약 밖 문자열 거부**(`'COHORT'`·`'active'`·`'suspended'`·`''`·
`'individual '`) · **비문자열 거부**(null·숫자·불리언·객체·배열) · 거부 메시지에 받은 값이 실린다.

**판정이 아니라 검증이다** — 값의 뜻을 해석하지 않고 집합 소속만 본다. 파일 머리에 그 경계를 적었다:
*"이 파일에 분기가 늘어나기 시작하면 판정이 두 곳으로 갈라지는 신호다."*

## 5. ⚠ 통합테스트가 이 기기에서 실행 불가 — 진단과 요청

**작성한 14건이 `skip` 으로 남아 있다.** 실행을 시도했고 두 겹으로 막혔다.

| 시도 | 결과 |
|---|---|
| `.env.local` 의 `SUPABASE_DB_URL`(직결 `db.<ref>.supabase.co`) | **DNS 미해석**(`ENOTFOUND`) — Supabase 직결 IPv4 경로가 더는 열려 있지 않다 |
| 풀러 `aws-0-ap-northeast-2` | 테넌트 없음 |
| 풀러 **`aws-1-ap-northeast-2`** | **호스트·테넌트 정상. 그러나 저장된 비밀번호로 인증 실패** |

즉 **올바른 호스트는 `aws-1-ap-northeast-2.pooler.supabase.com`(user `postgres.<ref>`)이고 비밀번호가 낡았다.**
비밀번호는 내가 얻을 수 없다.

**이것이 뜻하는 바**: `RUN_RLS_INTEGRATION=1` 옵트인 경로가 **지금 아무 기기에서도 돌지 않는다.**
`tests/rls.integration.test.ts`(기존 8건 포함)도 마찬가지다 — 파일은 있으나 게이트로 작동하지 않는다.
**"반복 검증 가능"이라는 상태가 아니다.**

> **요청**: `.env.local` 의 `SUPABASE_DB_URL` 을 풀러 문자열로 갱신해 주십시오.
> 형식 — `postgresql://postgres.zdoytzmvcafcebytttrm:<password>@aws-1-ap-northeast-2.pooler.supabase.com:5432/postgres`
> (세션 모드 5432. 트랜잭션 모드 6543 은 `set local role` 과 savepoint 사용 때문에 권하지 않는다.)
> 값을 보고서·커밋에 싣지 않는다. 갱신되면 14건 + 기존 8건을 돌려 결과만 보고한다.

**그래서 증명을 포기하지 않고 통로를 바꿨다** — 같은 62개 단언을 MCP 롤백 트랜잭션으로 실측했다(§3).
같은 DB·같은 함수이고, 다른 것은 접속 경로뿐이다. 다만 **CI 로 반복되는 형태가 아니므로**
env 가 고쳐지기 전까지 이 증명은 *한 번 잰 것*이다. 그 차이를 숨기지 않는다.
