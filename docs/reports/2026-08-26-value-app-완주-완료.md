### 2-2. 가시성 (지휘부 확인 2026-08-26)

Q8 승인은 **"`CoreContext` 에 3종 추가"**였다. 실제로는 **5종**이 됐다.

| 메서드 | 사유 |
|---|---|
| `getMyValueAssessment` | 본인 조회 |
| `saveMyValueProgress` | ← `value_save_progress` |
| `finalizeMyValue` | ← `value_finalize` |
| `patchMyValue` | ← `value_patch` |
| `listCohortValueAssessments` | 인도자 열람 |

**RPC 가 셋이라 쓰기 진입점이 셋 필요했고**(하나로 합치면 확정·잠금 규칙이 한 함수에 뭉쳐 서버 강제가 흐려진다), 여기에 조회 둘이 더해졌다. 3차 검토 N-15 가 예고한 델타이며 **되돌리라 하시면 합치겠다.**

그 밖의 계약 변경은 없다. `/src/core` 는 `/src/instruments` 를 참조하지 않고, 인스트루먼트는 DB 를 모른다(경계 유지).
