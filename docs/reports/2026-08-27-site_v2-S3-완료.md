## 1. returnTo — ①에서 근거를 찾았고, 판단이 갈리지 않았다

지휘부가 *"근거를 찾았는데 판단이 갈리면 멈추고 보고하라"* 고 했다. **갈리지 않았다.**

### ① 근거 (찾음)

`git log -S` 로 도달: **`af6576d`**(Step 2.2 — 인증 가드 일관화).

```ts
loginUrl.search = ''; // 토큰·민감 쿼리 미전파
```

**이 근거는 여전히 유효하다.** `/my/...?access_token=…` 같은 요청이 오면 search 를 통째로 옮길 때
토큰이 **로그인 URL·브라우저 이력·referrer·서버 로그**에 남는다. 지워야 할 이유가 실재한다.

### ② 유지하며 복원 — 근거를 다시 읽었다

> 그 근거는 **"쿼리를 옮기지 마라"이지 "경로를 버려라"가 아니었다.**

경로만 `returnTo` 로 실으면 **민감 쿼리는 한 글자도 전파되지 않으면서** 딥링크 복귀가 산다
(IA 설계철학 원칙 1·2). ②는 ①과 충돌하지 않는다 — 그래서 멈출 사안이 아니었다.

```ts
// proxy.guard.ts — 순수 판정 모듈(테스트 대상)
export function loginRedirectSearch(pathname: string): string
```

**함수가 `pathname` 만 받는다.** 호출부가 실수로 search 를 섞을 방법이 **구조적으로 없다** —
규칙을 주석으로 두지 않고 시그니처가 지키게 했다(ADR-121 이 `ValueCard` 에서 category 를 뺀 것과 같은 사고).

**화이트리스트를 proxy 에서 다시 검사하지 않는다.** 검증은 `loginOutcome → safeReturnTo` 가 이미 한다.
여기서 한 번 더 하면 화이트리스트가 **두 곳**이 되고, 그것이 이 저장소가 반복해서 데인 자리다.
통과 못 하는 경로는 로그인 뒤 `/home` 으로 떨어진다.

**`PROXY_MATCHER` 무변경**(불변식 17).

### ③ 회귀 테스트 4종

경로를 싣는다 · **인자가 하나뿐임을 단언**(search 가 섞일 구조적 불가능성) · 경로가 아니면 빈 쿼리
(`//evil.test/x` 포함) · **왕복이 화이트리스트를 통과함**(두 끝을 묶되 규칙을 복제하지 않는다).

### 1.1 실브라우저 이중 증명 (Vercel 프리뷰 · 새 빌드 `RU2ziScg…`)

`GET /home/assessments?access_token=SHOULD_NOT_LEAK` (미인증)

| 검사 | 결과 |
|---|---|
| `returnTo` | **`/home/assessments`** — 딥링크 복귀 살아남 |
| `SHOULD_NOT_LEAK` 응답 내 출현 | **0회** — ①의 근거 그대로 유지 |

**하나만 봤으면 반쪽이었다.** returnTo 만 봤다면 토큰 유출을 못 봤고, 토큰만 봤다면 복원 실패를 못 봤다.

> **위양성을 한 번 걸렀다.** 첫 두 번의 프리뷰 응답은 `returnTo:null` 이었는데, **배포가 아직
> `BUILDING`** 이라 별칭이 이전 빌드를 가리키고 있었다(빌드 id 로 확인). ADR-120 의 좀비 프로세스
> 위양성과 같은 계열이다 — **응답이 아니라 무엇이 응답했는지를 먼저 확인해야 한다.**

## 2. S-3 체크 허브 `/home/assessments`

| 항목 | 처리 |
|---|---|
| 배치 | **`/home` 아래** — `PROTECTED_PREFIXES` 무증가(IA §2.2 · 불변식 17 무접촉) |
| 여정 · 사전 | 미완 활성 차수가 있으면 `/join?cohort=…` 로 연결, 없으면 "이미 마치셨어요." |
| 여정 · 사후 | **자리만** — 열려 있으면 연결, 아니면 **"6회차를 마친 뒤 열립니다."** |
| 상시 · 가치 | **소속으로 분기** — 활성 차수가 있으면 그 차수 경로, 없으면 `/my/values`(S-2) |
| 상시 · 그림자 | **링크 없음** — §3 참조 |
| 상시 · 사랑의 언어 | 자리만 |
| 고지 | 차수 회원 **"이 결과는 우리 기수 인도자와 함께 봅니다."** · 개인 회원 **"이 결과는 나만 봅니다."** **동의 토글 없음** |
| 게이트 | 자격이 전혀 없으면 목록을 그리기 **전에** `/pending?returnTo=/home/assessments`(CLAUDE §9 게이트-데이터 순서) |
| `safeReturnTo` | `/home/assessments` 를 **라우트와 같은 커밋**에 |

**참여자 화면 규율 유지**(불변식 9·11 · §7.3): 경고색·순위·막대·배지 **0**.
**상태 배지를 두지 않았다** — 닫힌 항목은 색이 아니라 **문장**으로 말한다("승인이 끝나면 열립니다.").

## 3. 그림자(SAIL) — 링크를 걸지 않았다 (판단 필요)

IA §4.5 는 *"허브에 항목을 세우고 SAIL 로 연결한다"* 이고, 발주서가 연결 방식(외부 링크/동일 도메인)을
**현황 확인 후 보고**로 두었다.

**확인 결과: 연결 주소가 저장소·`.env.example` 어디에도 없다.** 임의로 만들면 죽은 링크가 되고,
그것은 `/pending` 에서 S-4 링크를 걸지 않은 것과 같은 이유로 하지 않는다.

→ **자리만 두고 "곧 이 자리에서 이어집니다." 로 적었다.** 주소를 주시면 한 줄이다.
스키마·데이터·코드는 **무접촉**(CLAUDE §4).
