## 0. 먼저 적을 것 — 게이트가 **내 것**을 두 번 잡았다

F-0 때 지휘부가 *"내가 넣은 게이트 ②가 내 발주서의 결함을 잡았다"* 고 적었다.
이번 회차에는 **내가 건 가드가 내 코드를 잡았다.** 순서대로 적는다.

**① 강조 ① 위반 — `SiteGnb` 가 계산하고 있었다.**
`§9.7` 사양 행을 쓰다가 발견했다. `SiteGnb` 가 `usePathname()` 으로 현재 경로를 **스스로 읽고**
`pathname === href || startsWith` 로 판정하고 있었다. 더 나쁜 것은 주석이다 — 파일 머리에
*"내비가 자기 위치를 아는 것은 판정이 아니라 관찰이고, 화면마다 현재 경로를 내려보내면
그것이야말로 사본이 둘이 된다"* 는 **변호를 미리 적어 두었다.**

틀렸다. 라우터도 데이터원이고(§5-4 *"부품에 데이터 접근 금지 — 전부 prop"*),
접두 일치는 명백한 판정이다. 인용한 선례도 **반대쪽**이었다 — `consoleNav(pathname)` 은
pathname 을 **인자로 받는 순수 함수**였지 훅을 안에서 부르는 물건이 아니었다.
`currentPath` prop 으로 바꾸고, 그 변호 문장을 지우는 대신 **틀렸다고 적어 남겼다.**
회귀 테스트 3건을 걸었다(prop 없으면 `aria-current` 0 · 하위 경로도 현재 · 시트 없으면 햄버거 0).

> 아홉 중 **여덟은 처음부터 순수했고 하나가 아니었다.** 강조 ① 이 없었으면 그 하나는
> "내비는 원래 그렇다"로 넘어갔을 것이다.

**② 4폭 캡처가 1px 결함을 잡았다.**
390px 시트에서 회차 칩 **여섯째만 홀로 다음 줄로 내려앉았다.** 산수로 확인했다 —
시트 안쪽 폭 `min(360, 88vw) - 40 = 303px`, 칩 여섯 `44×6 + 8×5 = 304px`. **1px 모자랐다.**
탭 크기(44px)도 시트 폭(88vw)도 줄이지 않았다 — 시트를 넓히면 바깥 탭으로 닫을 자리가
47px→31px 로 좁아진다. **시트 안 간격만** 4px 로 좁혀 한 줄에 세웠다.
캡처를 "찍었다"로 끝냈으면 못 봤다.

**③ 순수성 테스트가 착수 중 세 번 잡았다** — 문자 기호(닫기·햄버거·체크) · 시안 이모지 주석 ·
`max-width: 767px`(§3.1 에 없는 수치) · 시안 hex 가 주석에 남은 것.
`max-width` 건은 `GrowAxis` 를 **모바일 우선으로 다시 쓰게** 만들었다(제약이 설계를 고쳤다).

**④ 그리고 3차에 내가 쓴 사실 오류 하나** — §6 에 따로 적는다. **결정은 손대지 않았다.**

## 6. `design_system.md` §9.6 — **내가 3차에 쓴 사실 오류** (결정은 손대지 않았다)

§9.6 의 사실 표에 이렇게 적혀 있었다:

> | **참여자 앱 하단 탭바** | **시안에도 코드에도 없다.** 이것을 두지 않는다 |

**틀렸다.** 이번에 시안 7화면을 전수해 확인했다:

| 화면 | `.tabbar` |
|---|---|
| A 공개 홈 | **있다** — 5칸(홈·소개·신청·자료실·로그인) |
| **B 로그인 홈** | **있다 — 4칸(홈·내 여정·피드·자료실)** |
| **C 내 여정** | **있다 — 4칸(같음)** |
| **F 진단 홈** | **있다 — 4칸(같음)** |
| **G 승인 대기** | **있다 — 4칸(홈·소식·자료실·계정)** |
| D 딥링크 게이트 · E 시트 | 없다 |

3차 T-1 에서 **A 의 5칸만 보고 v1.4 전체를 단정**했다. `코드에 없다`는 맞고 `시안에 없다`는 틀렸다.

**한 것**: 사실 칸만 고치고 정정 주를 달았다. **결정("두지 않는다")은 그대로 두었다** — 결정은
지휘부의 것이고, 조용히 바꾸지 않는다.
**한 것이 아닌 것**: 근거가 하나 줄었다는 사실을 §11 에 **질의로 올렸다.**
이제 그 결정은 *"시안에도 없다"* 가 아니라 *"시안에는 있으나 채택하지 않았다"* 이며,
그것은 §9.6 첫 문단의 공개 현관 탭바 판단과 **같은 종류**다.

> **질의**: 근거가 하나 줄어든 상태에서 "두지 않는다"를 유지할 것인가,
> F-2·F-3 화면 조립 때 다시 볼 것인가. **무응답 시 유지**로 두고 임의로 만들지 않는다.
