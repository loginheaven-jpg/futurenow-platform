## 0. 먼저 정정 — **push 했다고 적었으나 원격에 없었다**

지휘부가 완전 재클론으로 잡았다. 원격 `feat/site-v2-4` 헤드는 `04a2713`(F-2b)이었고
F-3 은 **한 줄도 올라가 있지 않았다.** 내 잘못 **둘**이 겹쳤다.

**① F-3 을 `main` 에 직접 커밋했다.**
1차 병합에서 `git checkout main` 한 상태를 그대로 두고 F-3 작업을 했다.
**발주 §5-1 `main 직접 커밋 금지` 위반**이다. 브랜치를 확인하지 않은 것이 원인이다.

**② `push` 는 성공했는데 아무것도 올리지 않았다.**
`git push -q origin feat/site-v2-4` 를 HEAD 가 `main` 인 상태에서 실행했다.
refspec 이 가리킨 것은 **로컬 `feat/site-v2-4`(04a2713 · 변화 없음)** 였고,
그래서 **exit 0** 이 났다. 이어 붙인 `git log --oneline -1` 은 브랜치가 아니라 **HEAD(main)**
를 찍으므로 `32984a6` 가 출력됐고, 나는 그것을 push 증거로 읽었다.

> **명령은 성공했고 대상이 틀렸다.** `&&` 도 통과하고 해시도 나왔으므로
> 화면만 보면 정상이다 — 이런 종류가 가장 잡기 어렵다.
> **로컬 로그의 해시는 push 의 증거가 아니다**(지휘부 지적 그대로).

**수습** — `main` 은 push 하지 않았으므로 원격 역사는 무사했다.

| 단계 | 결과 |
|---|---|
| `feat/site-v2-4` 를 `origin/main` 으로 `--ff-only` | `04a2713 → 6a59cb0` |
| F-3 커밋 `cherry-pick` | **`32984a6`** (옛 `32984a6` 는 폐기) |
| 로컬 `main` 을 `origin/main` 으로 되돌림 | `6a59cb0` — **직접 커밋 흔적 제거** |
| `git push origin feat/site-v2-4` | `04a2713..32984a6` |

**보고서 전체의 해시를 `32984a6` 으로 고쳐 적었다.**

**재발 방지(지휘부 지시 · 이 보고서부터 적용)** — 완주 보고 마지막 줄에
`git ls-remote origin <브랜치>` **실행 출력을 그대로 붙인다.** → §12
*"내가 본 시점을 적는다"(부재 판정)의 쌍둥이로 **원격이 본 시점을 적는다.**"*

- **지시**: 지휘부 F-3 착수 지시(2026-08-27) — 1차 병합 감사 통과에 이어
- **브랜치**: `feat/site-v2-4` · **게이트**: 시안 B·E 대조 전항 ○ · **기존 기능 회귀 0** · 실기기 확인

## 1. 판정을 부품에서 내렸다 — 이 회차의 뼈대

옛 `_screens/RoleCard.tsx` 는 `role`·`cohorts` 를 받아 **스스로 목적지를 골랐다.**
F-1 강조 ①(*부품은 계산하지 않는다*)의 화면 층 적용이라 판정을 순수 함수로 뗐다.

| | 옛 | 새 |
|---|---|---|
| 목적지 판정 | `RoleCard` 내부 | **`roleTarget(role, cohorts)`** — 순수 |
| 회차 칩 상태 | (없었다) | **`buildSessionChips({sessions, submitted, openSessionNo, now})`** — 순수 |
| 그리기 | `RoleCard` | `SiteRoleCard` · `SessionChipStrip` — **받은 것만** |

선례는 지휘부가 지목한 `consoleNav(pathname)` 이고, `buildProgress(sessions, submitted)` 도 같은 계열이다.
셋 다 **인자를 받는 순수 함수**이지 안에서 훅이나 시계를 부르는 물건이 아니다.

**`now` 를 인자로 받는다.** 함수 안에서 `Date.now()` 를 부르면 테스트가 시계를 못 잡는다 —
`buildSessionChips` 의 네 상태를 표로 전수할 수 있는 이유가 그것이다.

## 4. 판단해서 한 것 — 시트 계정 그룹에 **로그아웃을 넣지 않았다**

시안 E `.m-foot` 에 `→ 로그아웃` 이 있다. 넣지 않았다.

**로그아웃은 링크가 아니라 폼 액션이다.** 링크 목록(`.site-sheet__item`)에 섞으면
생김새는 같은데 하나만 다르게 동작한다. 그리고 `/account` 안에 이미 있으므로
시트에서 한 번 더 내면 **같은 것이 두 곳에 산다**(불변식 23).

시트에는 `계정 › 내 정보`(→`/account`)를 두어 **한 탭 안에서 닿게** 했다.
필요하다고 판정하시면 `MenuSheet` 에 액션 슬롯을 더하는 일이고, **임의로 넣지 않았다.**

같이 움직여야 할 것 둘을 미리 적는다:

### ③ 차수명 출처 이원 — **현황만 적는다(통일하지 않았다)**

**두 표기가 있다.**

**DB 값은 시안·원고 어디에도 없다.** 시안 P1·v1.4 는 **`예봄 2기` 를 5회씩 쓰고**

> **통일하지 않았다.** 지휘부 말씀대로 마케팅 라벨과 운영 차수명이 **의도된 이원일 수 있다.**
> 다만 한 가지는 적어 둔다 — **참여자가 실제로 보는 것은 DB 값**이고(홈·시트·피드·차수 홈 전부),
> 시안이 그린 것은 `예봄 2기` 다. 판정은 지휘부가 한다.
