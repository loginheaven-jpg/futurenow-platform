## 2. 배포 확인 — **위양성을 다시 내지 않기 위해**

1·2차에서 별칭 응답으로 위양성을 두 번 냈다. 그래서 이번에도 **실브라우저보다 배포 신원을 먼저** 봤다.

```
병합 직후: {"commitShort":"91886ba", "deploymentId":"dpl_HeL6KMTJinLcYZHPQnbB74MNA7Mx"}   ← 아직 옛 배포
전환 후:   {"commitShort":"1bb05f3", "deploymentId":"dpl_F8LzMTNpeDyE44LHr6XSZ7qY3Gec"}   ← 확인
```

10초 간격 폴링 **3회차**에 전환됐다. **전환을 확인한 뒤에 5건을 돌렸다.**
`/api/version`(3차 T-3)이 없었으면 이 판정을 또 추측으로 했을 것이다.

### 3.1 4번을 200 으로 통과시키지 않았다

`curl` 로 받은 초기 HTML 에 **`예봄 2기` 가 0회**였다. 여기서 멈췄다.

원인을 확인하니 `/join` 은 **로딩 셸을 먼저 내려보내고**(`불러오는 중…`), `?code=` 딥링크
자동 진입은 **하이드레이션 후 클라이언트에서** 일어난다(`JoinClient` A5 경로).
**curl 은 그 화면을 볼 수 없다.**

그래서 실제 브라우저(Playwright · JS 실행 · 4초 대기)로 렌더해 눈으로 확인했다:

- 차수 미리보기 자동 진입 — **`퓨처나우2026예봄2기`** · 인도자 `운영자` · **현재 인원 9명** ·
  체크 `퓨처나우 체크` · 예상 시간 `약 5분`
- `SeminarIntro` 3단락 정상
- CTA 둘(`아니에요` · `들어가기`) 정상

> `예봄 2기`(공백 포함)가 0이었던 것도 이것으로 설명된다 — **차수명은 DB 값
> `퓨처나우2026예봄2기`** 이고 `intake.ts` 의 `label`(`예봄 2기`)과 표기가 다르다.
> **결함이 아니라 서로 다른 두 출처다.**

**F-0 토큰 개편이 기존 진입 퍼널을 깨지 않았음**이 이 한 건으로 실증됐다 — 회귀 확인 지점이다.
