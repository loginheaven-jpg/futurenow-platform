## 1. 구간과 커밋

**기준선을 먼저 못 박는다** — 과거에 커밋 수가 두 번 갈렸고 둘 다 범위 차이였다.
4차 구간은 **1차 병합 직전의 `main`** 부터다.

```
$ git rev-parse --short 1bb05f3^1          →  91886ba      (4차 시작 직전 main)
$ git rev-list --count           91886ba..c1d320b  →  39
$ git rev-list --count --no-merges 91886ba..c1d320b →  37
$ git rev-list --count --merges    91886ba..c1d320b →   2
검산: 37 + 2 = 39 ✅   (병합 둘 = 1차 `1bb05f3` · 2차 `774b634`)
```

| 구간 | 범위 | 커밋(병합 제외) |
|---|---|---|
| **1차 병합분** (F-0·F-1·F-2·F-2b) | `91886ba..1bb05f3` | `git rev-list --count --no-merges` → **8** |
| **2차 병합분 + 그 뒤** (F-3·F-4·골드·QA·F-5·결산 전) | `1bb05f3..c1d320b` | → **29** |
| 합 | | 8 + 29 = **37** ✅ |

**마이그레이션 0** — `git log --oneline 91886ba..c1d320b -- supabase/migrations | wc -l` → **0**.
4차는 DB 스키마를 한 줄도 건드리지 않았다(발주 전제 그대로).

## 4. 발견 목록

### 4.1 하네스 다섯 — *"찍히기는 했는데 다른 것을 찍었다"*

넷은 `scripts/shots.mjs` 머리에 **주석으로 고정**돼 있다(지우지 말 것). 다섯째는 오늘 나왔다.

| # | 함정 | 어떻게 드러났나 | 조치 |
|---|---|---|---|
| ① | **`networkidle` 이 아예 안 잡힌다** | Next 가 RSC 프리페치로 연결을 계속 여닫는다. 주 신호로 삼았더니 **44장에 11분을 태우고 미완** | 주 신호는 `load`, `networkidle` 은 보조(`IDLE_MS`) |
| ② | **숨겨진 lazy 이미지는 영영 로드되지 않는다** | `display:none` + `loading="lazy"` 면 `img.complete` 가 끝내 `false`(`/recruit` 카드가 lg 미만) | 이미지 대기에 상한(`IMG_MS`) |
| ③ | **`position:fixed` + 긴 full-page 캡처가 안 끝난다** | `/recruit` 5,947px + 하단 고정 바 | 캡처 상한(`SHOT_MS`) + `animations:'disabled'` |
| ④ | **눌러야 보이는 화면은 URL 이 같아 조용히 다른 것을 찍는다** | 시트가 `/home` 과 같은 주소라 **홈을 두 번 찍고 있었다** | `open` 슬롯 + 실패 기록 |
| ⑤ | **`goBack()` 의 반환값이 거짓을 말한다** | App Router 의 클라이언트 뒤로가기는 문서 내비게이션이 아니라 `null` 이 온다 — **이동은 했는데 "못 갔다"로 읽혔다.** 그대로 믿었으면 *"뒤로가기는 두 번이면 끝"* 이라고 보고할 뻔했다 | **URL 로 판정**하도록 고침(개선 셋 사전 조사) |

**앞선 것 하나 더** — 하네스 요약 블록이 **조용히 안 찍히고 있었다**(치환 실패). 개별 실패는
찍히고 있었으므로 과거의 *"실패 0"* 주장은 참이었으나 **집계 줄이 없었다.** 줄번호 삽입으로 고쳤다.

## 5. ADR-12 판정 이행 (지휘부 지시 그대로)

**⑴ 이력에서 원문을 찾았다** — `architecture.md` 전 리비전 **131 개** 전수 조회.

```
$ git log --all --format=%H -- architecture.md | wc -l   →  131
  (각 리비전에서 '| ADR-12 |' 및 'ADR-12[^0-9]' 탐색)     →  0건
```

인용은 `838e761`(2026-06-27 · 디자인 시스템 v1)이 `design_system.md` 에 `(ADR-12)` 를 적으면서
**처음이자 유일하게** 생겼고, 그 시점 표는 **ADR-11 다음이 곧 ADR-13** 이었다 —
**번호를 먼저 인용하고 행을 쓰지 않았다.**

**⑵ 없으므로 결번이다.** `| ADR-12 | *(결번 — 소급 부여 금지)* |` 행을 적었다.
**행을 지우지 않는다** — 번호를 비워 두면 다음 사람이 다시 쓴다.

**⑶ 문장은 새 번호로 채번했다** — **ADR-133**(브랜드 토큰은 진단이 주입, 중립·의미는 코어 소유).
**내용은 2026-06-27 확정 그대로이고 번호만 새것**이며, 출처를 그 행에 적었다.
`design_system.md` 의 인용 둘(§0-2 · 머리 참조 줄)을 133 으로 옮겼다.

**⑷ 잠금에 결번 처리를 반영했다** — 번호의 상태를 **셋**으로 나눈다.

| 상태 | 뜻 | 테스트가 막는 것 |
|---|---|---|
| 살아 있음 | 행이 있고 인용해도 된다 | 중복 채번 |
| **결번** | 행은 있으나 **뜻이 없다** | **살아 있는 사양이 근거로 인용**하면 실패 · **`VOID_FOREVER` — 한 번 결번이면 영원히 결번**(행을 뜻 있는 행으로 바꾸는 것이 곧 소급 부여) · 사유 필수 |
| 없음 | 행이 없다 | 빈 번호 0(결번도 행으로 적는다) · 미아 참조 0 |

```
$ (실측) 정의 133 · 살아있음 132 · 결번 [12] · 최대 133
관계식: 살아있음 132 + 결번 1 = 정의 133 = 최대 133 ✅
```

**변이로 다섯 경로를 확인했다.** 처음에는 **소급 부여가 통과했다** — 표의 결번 표시만 보니
행을 바꿔치면 멀쩡한 살아 있는 번호로 보였다. 그것이 금지의 핵심이라 `VOID_FOREVER` 를 더한
뒤에야 물었다. 관계식도 첫 판이 **항등식**이라 아무것도 못 잡아 세 값을 따로 세도록 고쳤다.

> **변이 하네스 자체도 한 번 틀렸다** — 되돌리기를 `git checkout` 으로 해서 **아직 커밋 전인
> 내 편집을 지웠다.** 백업본 복원으로 바꿨다. *도구가 재는 것을 먼저 잰다* 는 규율은
> 도구의 **되돌리기**에도 걸린다.

## 9. 브랜치 처리

지휘부 지시대로 **`feat/site-v2-4` 를 남긴다.** 삭제는 5차 안정 후 판단.

```
$ git branch --merged main | grep -c 'feat/site-v2-4'   →  1   (병합 완료 · 삭제해도 유실 없음)
$ git ls-remote --heads origin
1bb995f…  refs/heads/chore/site-v2-3
4744c3d…  refs/heads/feat/site-v2-2
5c5427f…  refs/heads/feat/site-v2-4      ← 남긴다
c1d320b…  refs/heads/main
98f780f…  refs/heads/refactor/site-v2
```

원격 `feat/site-v2-4` 의 끝(`5c5427f`)은 2차 병합 **직전** 커밋이다 — 병합 뒤의 여섯 커밋은
`main` 에만 있다. 브랜치를 되살릴 일이 있으면 `main` 에서 잘라야 한다.
