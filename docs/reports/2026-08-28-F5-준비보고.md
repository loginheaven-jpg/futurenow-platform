**목록이 다섯 곳에 흩어져 있으면 F-5 에서 한 화면이 조용히 빠진다.** 하나로 묶었다.

| 파일 | 무엇 |
|---|---|
| **`scripts/screens.mjs`** | **화면 목록 단일 출처** — 공개 11 · 인증 11 · 폭 4 |
| **`scripts/shots.mjs`** | 모드 넷(`public` · `fixture` · **`auth`** · `all`)으로 그 목록을 찍는다 |

### 두 묶음 — 경계는 **`PROTECTED_PREFIXES` 실측**이다

추측이 아니라 `src/proxy.guard.ts` 의 `['/home','/my','/coach','/admin','/account','/preview','/feed']` 로 갈랐다.

| 묶음 | 화면 | 지금 |
|---|---|---|
| **`public/`** | `/` · `/about` · `/recruit` · `/news` · `/library` · `/contact` · `/login` · `/signup` · `/join` · `/pending` · `/reset` — **11** | **오늘 바로 실라우트 44장** |
| **`auth-fixture/`** | 표시 층 SSR 6종 — `gallery` · `gallery-sheet` · `home` · `home-sheet` · `cohort` · `assess` — **18장** | **QA 계정 대역** |
| **`auth/`** | 위 + `my-cohorts` · `journey` · `feed` · `account` · `coach-console` · `coach-cohort` — **11** | **구현 완료**(§3) · 계정만 오면 실행 |

```
node scripts/shots.mjs public  <출력>     # 서버가 떠 있어야 한다(SHOT_BASE 기본 :3100)
node scripts/shots.mjs fixture <출력>
SHOT_COHORT=<차수 id> node scripts/shots.mjs auth <출력>
node scripts/shots.mjs all     <출력>
```

**실행 확인** — `public` **44장 · 56초 · 실패 0** · `fixture` 18장, **총 62장**.

`screens.mjs` 는 **계정 없이 못 보는 화면 목록**(`AUTH_ONLY_NO_FIXTURE`)도 내보낸다 —
보고서에 그대로 적기 위해서다. **빠뜨린 것과 못 본 것은 다르다.**

## 3. 하네스 `auth` 모드 — **구현 완료** (지휘부 승인 2026-08-28)

**`playwright` 를 devDependency 로 들였다.** 쿠키 합성 안은 취하지 않았다 —
지휘부 판정 그대로, *"Supabase 쿠키 형식에 결합된 자가제작 우회라 형식이 바뀌면 조용히 깨진다."*
**방금 §4-① 에서 겪은 종류의 함정을 다시 심는 일이다.**

### 조건 셋 — 전부 잠갔다

| 조건 | 이행 | 잠금 |
|---|---|---|
| ① `devDependencies` 로만 | `dependencies` 에 없음 | `tests/devDeps.guard.test.ts` |
| ② 버전 고정 | **`playwright: "1.62.1"`** — `^`·`~` 없음 | 정규식으로 단언 |
| ③ 런타임이 import 하지 않음 | `src/` 전수 스캔 **0건** | 주석은 제외하고 실코드만 본다 |

가드는 **하네스가 실제로 그것을 쓰는지도** 본다 — 안 쓰면 의존성을 들일 이유가 없다. **4/4 통과.**

### `auth` 모드 — 화면으로 로그인한다

```
SHOT_COHORT=<QA 차수 id> node scripts/shots.mjs auth <출력>
```

`.env.local` 의 `QA_*` 로 **로그인 화면을 실제로 채워** 세션을 얻고, `user`·`coach` 두 컨텍스트로
각자의 화면을 찍는다. **자격 값은 출력·로그에 남기지 않는다** — 없을 때도 **키 이름만** 말한다.

> 계정이 오기 전에는 실행할 수 없다. **문법·경로는 지금 확정됐고, 남은 것은 실행뿐이다.**

## 4. 발견 넷

### ① 하네스가 **로딩 셸을 찍고 있었다** — 고쳤다

`/library` 를 찍었더니 **`불러오는 중…` 한 줄**만 나왔다. 화면이 빈 것이 아니라
**캡처가 이른 것**이었다 — 서버가 셸을 먼저 내려보내고 하이드레이션 뒤에 본문을 그린다.

처음에는 `--wait-for-timeout=2500` 으로 막았다. **그것도 추측이었다** —
*"2.5초면 되겠지"* 는 느린 화면에서 여전히 셸을 찍는다.
지휘부 지시대로 **로드 상태 대기**로 바꿨다(`playwright` 도입과 같은 커밋):
`load` 를 주 신호로 하고 `networkidle`·폰트·이미지를 보조로 본다.

> **F-5 에서 이대로 갔으면 클라이언트 화면이 전부 빈 껍데기로 남고,
> 사람이 볼 때는 "화면이 비었다"로 읽혔을 것이다.**
> `/join?code=` 위양성(1차 병합)과 같은 계열이다 — **내가 본 시점**의 문제다.

### ①-b 그 수정이 **다음 함정을 열었다** — 상한 셋으로 닫았다

로드 상태 대기로 바꾸자 **`/recruit` 768px 에서 하네스가 멈췄다**(44장에 11분을 태우고 미완).
원인 셋이 겹쳤다:

| 원인 | 실측 |
|---|---|
| `networkidle` 이 **아예 안 잡힌다** | Next 가 RSC 프리페치로 연결을 계속 여닫는다 → 화면마다 상한을 헛되이 태웠다 |
| **숨겨진 lazy 이미지는 영영 로드되지 않는다** | `/recruit` 카드가 lg 미만에서 `display:none` + `loading="lazy"` → `img.complete` 가 끝내 `false` |
| full-page 캡처가 안 끝난다 | 5,947px 높이 + `position: fixed` 하단 바 |

**상한 셋**을 걸어 닫았다 — `networkidle` 보조 1200ms · 이미지 1500ms · **캡처 30초**.
그리고 **실패를 조용히 넘기지 않는다**: 실패한 장은 화면·폭과 함께 찍히고 끝에 모아 알린다.

**결과: 44장 · 56초 · 실패 0.** 11분 미완이던 것이 1분 아래가 됐다.

> **측정 도구를 고치니 그 수정이 새 함정을 열었다.** 고정 대기를 없앤 것은 옳았지만,
> 그 자리에 **상한 없는 대기**를 놓은 것이 문제였다. `/library`(①)와 `/recruit`(①-b)는
> 같은 뿌리다 — **기다림에는 언제나 끝이 있어야 하고, 끝났는지 확인할 수 있어야 한다.**

### ② 공개 화면 **여덟이 아직 옛 골격**이다 — **판정 요청**

`site-gnb`·`site-foot` 존재로 실측했다.

| 화면 | 새 골격 | 비고 |
|---|---|---|
| `/` · `/about` | **○** | F-2·F-2b 에서 교체 |
| `/recruit` | — | **별도 디자인**(카드뉴스 웹판). 옛 골격이 아니라 자기 디자인이고 F-4 에서 2단을 붙였다 |
| `/news` · `/library` · `/contact` · `/login` · `/signup` · `/join` · `/pending` · `/reset` | **✕ 8** | **4차 범위 밖이었다** — 개요 §3 산출물 지도에 없다 |

**개요 §2 의 F-5 게이트는 "전 화면 4폭 통과"** 인데, 이 여덟의 **"통과"가 무엇인지 정해지지 않았다.**

| 안 | 뜻 | 비용 |
|---|---|---|
| **A** | **깨짐 0 만 본다** — 시안이 없으므로 대조하지 않는다 | 0. F-5 그대로 |
| B | GNB·푸터만 씌운다(본문 무접촉) | 화면당 소, 8화면 · 회귀 검증 필요 |
| C | 전면 교체 | 별도 발주 |

**지휘부 판정: A** (2026-08-28) — *"깨짐 0 만 본다. 시안 없는 화면에 대조 기준을 소급 발명하지 않는다."*
B 는 **F-5 후 별건**이다.

#### 후속 발주 후보 — **4차가 다루지 않은 범위를 기록으로 확정한다**

*"1차의 조용히 묻힘 재발 방지"*(지휘부). 이 여덟은 **누락이 아니라 범위 밖**이었고,
그 사실이 여기 적혀 있어야 다음 회차가 다시 발견하지 않는다.

| # | 화면 | 지금 골격 | 후속에서 볼 것 |
|---|---|---|---|
| 1 | `/news` | 옛 | 목록 + 상세(`/news/[id]`)가 한 벌이다 |
| 2 | `/library` | 옛 | 만료 링크 안내 문구가 화면의 절반이다 |
| 3 | `/contact` | 옛 | 문의 폼 — 공개 면 중 유일한 입력 화면 |
| 4 | `/login` | 옛 | **진입 퍼널**. 건드리면 회귀 면적이 크다 |
| 5 | `/signup` | 옛 | 〃 · 가입 폼이 길다(동의·포럼 대조 포함) |
| 6 | `/join` | 옛 | 〃 · 코드 입력 → 미리보기 → 러너 |
| 7 | `/pending` | 옛 | 승인 대기 안내 — 문장이 전부다 |
| 8 | `/reset` · `/reset/confirm` | 옛 | 비밀번호 재설정 2화면 |

> **넷(4·5·6·8)은 진입 퍼널이다.** 손대면 회귀 검증이 따라붙는다 —
> 후속 발주에서 **퍼널과 비-퍼널을 갈라** 보시길 권한다.

### ③ `auth` 모드 — **구현 완료**(§3). 남은 것은 계정뿐이다
