## 1. 불변식 11이 시안을 이겼다 — 판정 반영

시안 C의 `.p-track`/`.p-fill`(연속 채움 막대)를 **불채택**했다.
지휘부 판정 근거를 그대로 코드 주석과 ADR에 옮겨 적었다 —
*"시안 note 스스로 위치 안내일 뿐이라 적었는데 연속 채움 막대는 시각 어휘상 성취 게이지다.
시안이 의도와 형태가 따로 놀았고, 현행 점 표시가 그 의도의 정확한 구현이다."*

**B(칸 분할)는 취하지 않았다** — 현행의 재발명이자 경계선이라는 판정 그대로다.

## 4. 캡처가 **내 회귀 둘**을 잡았다

**① 진행 표시의 `7주 기록` 라벨을 떨어뜨렸다.** 점만 남으면 무엇을 세는지 알 수 없다.
화면에 라벨 슬롯을 복원하고 페이지가 준다 — **회차 수는 여전히 `buildProgress` 가 정한다.**
(타입이 먼저 잡았다. `label` 을 필수로 둔 덕에 픽스처 누락이 `tsc` 에서 드러났다.)

**② 진단 항목의 제목과 보조 문장이 한 줄에 붙었다** — `사전 체크이미 마치셨어요`.
`<span>` 이 inline 이라 그렇다. 블록으로 세웠다.

## 5. 회귀 테스트를 **지우지 않고 옮겼다**

`copyRegression.test.ts` 의 *"일곱 칸 표시가 AppHeader 바로 아래 고정"* 단언이 깨졌다 —
`AppHeader`·`ordered` 가 사라진 이름이기 때문이다. **지키던 셋을 새 구조로 다시 적었다**:

| 지키던 것 | 새 단언 |
|---|---|
| 라벨이 있다 | `page.tsx` 에 `label: '7주 기록'` · 화면에 `progress.label` |
| 회차 수를 박지 않는다 | `buildProgress` 존재 |
| **상태 무관 앵커** — 카드보다 먼저 | `cohort-progress` < `{before ?? null}` < `cohort-today` |
| 경고색 0 | 그대로 + **`p-fill` 0**(막대 부재)를 함께 잠갔다 |

## 7. `/recruit` PC 2단 — **사양 부재로 보류**(판단 요청)

개요 §3 의 `/recruit PC 2단(카드뉴스 활용)` 은 **한 줄이고 배치 사양이 아니다.**
P1~P4 에 recruit 시안이 없다 — **F-2b 가 `/about` 을 발주 §3 사양 승인으로 푼 것과 같은 자리**다.
불변식 20 이 걸리므로 임의로 디자인하지 않았다.

**실측만 올린다**:

| 항목 | 값 |
|---|---|
| `recruit.css` 의 `@media` | **0** — 지금은 폭에 반응하지 않는다(`.rc-wrap` `max-width: 520px` 고정) |
| 카드뉴스 | **13장 · 1080×1080 · 총 2.8MB** · `docs/tasks/cards/` 에 **git 추적 중**(14 파일) |
| 서빙 | Next 는 `docs/` 를 서빙하지 않는다 — **`public/` 반입이 필요**하고 그만큼 저장소에 중복이 붙는다 |
| ISR | `/recruit` `○ 5m` — 이번 회차 **무접촉** |

**필요한 것은 배치 사양 한 줄이다** — 2단에서 좌/우에 무엇을 둘지, 카드뉴스를 어느 자리에
몇 장 어떤 형태로 놓을지. 주시면 그대로 만든다.
