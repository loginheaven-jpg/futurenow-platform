## 2. ★ §2 문장을 흐름으로 읽었다 — **어긋난 자리 넷**

**고치지 않았다. 목록만 낸다.** 문안은 최박사 결재다.

### 어긋남 ⑴ — **소요 시간이 두 화면에서 다르다**

```
① /recruit   「사전 체크 시작하기 · 약 10분 걸립니다. 마치시면 신청이 완료됩니다.」
② /join      「예상 시간 · 약 5분」
```

**앞 화면이 10분이라 하고 뒤 화면이 5분이라 한다.** 참여자는 같은 것을 두 번 다른 값으로 듣는다.
*(표 75건에 이 자리는 없다 — 둘 다 표가 손대지 않은 문장이다.)*

### 어긋남 ⑵ — **금지 기호 대시가 참여자 화면에 뜬다**

```
⑤ /home/assessments   「[QA전환] B — 아직 하지 않으셨어요.」
                      「6회차를 마친 뒤 열립니다.」 위 「마무리 체크」 줄도 같은 틀
```

표 §10.4 가 **대시를 금지**하는데, 이 줄은 `${name} — …` 템플릿이라 **표에 없는 자리**다.
§0.2 대로 손대지 않았다. **표가 이 자리를 몰랐다.**

### 어긋남 ⑶ — **목록의 안내와 자료 화면의 말이 다르다**

```
목록      「인도자에게 열립니다.」          ← 못 여는 이유를 말한다
자료 화면  「찾는 페이지가 없어요.」          ← 없다고 말한다
```

목록은 «권한이 없다» 고 하고, 그 자료의 주소를 직접 열면 «없다» 고 한다.
**보안으로는 옳다**(존재를 알리지 않는다). 다만 **한 사람이 두 말을 듣는다** — 목록에서 이미 존재를 봤기 때문이다.
*(목록이 링크를 걸지 않으므로 평상시엔 닿지 않는다. 주소를 직접 넣었을 때만 생긴다.)*

### 어긋남 ⑷ — **로그인했는데 헤더가 「로그인」이라 한다(잠깐)**

```
/library · / · /news   헤더 오른쪽: 「로그인」 → 「내 홈」
```

세 화면 모두 **처음 한 순간 「로그인」으로 그려졌다가 「내 홈」으로 바뀐다.**
**새 결함이 아니다** — ADR-138 이 ISR 을 지키려고 받아들인 거래이고 문서에 적혀 있다.
그래도 **참여자가 겪는 것**이므로 목록에 넣고, §4 실기기 목록에 올린다.

# 후속 — 지휘부 판정 셋을 이행했다 (2026-08-29 · 같은 브랜치)

## A. ⑵ `assessments` 대시 — **고쳤다**

```
- : pre  ? `${pre.name} — 아직 하지 않으셨어요.`
+ : pre  ? `${pre.name} · 아직 하지 않으셨어요.`
- note: post ? `${post.name} — 지금 하실 수 있어요.` : …
+ note: post ? `${post.name} · 지금 하실 수 있어요.` : …
```

**새 문안을 지은 것이 아니라** 표 §0 이 정한 금지 기호 규칙을 **템플릿에 적용**한 것이다.
**사후 추인 목록에 올린다.**

### 다른 템플릿도 훑었다 — **참여자가 읽는 문자열 중 대시 14건**

인도자·운영자 화면과 리포트는 제외하고, **참여자가 읽는 문자열**만 골랐다:

| 자리 | 문장 |
|---|---|
| `values/copy.ts:100` | 아직 못 찾았어요 **—** 건너뛰기 |
| `copy.ts:39~43` | 일 (Work) **—** 성취와 보람 · 재정 · 관계 · 건강 · 기여 (다섯) |
| `copy.ts:62·67` | [ 나의 인생 조감도 **—** 한 문장 스케치 ] · [ 6주 전의 나에게 **—** 한마디 ] |
| `session4.ts:128` | 인생의 원씽 **—** 세 원이 겹치는 자리 |
| `session5.ts:134` | 오늘 만든 신호를 이번엔 첫 도미노에 걸어 본다면 **—** 만약 |
| `SiteGallery.tsx:92` | 예봄 2기 **—** 9월 20일 (일) 시작 *(시안 갤러리 · `/preview` 전용)* |
| `core/context.ts:246` | 조용히 틀린 값을 보이지 않기 위해 멈췄습니다 **—** 운영자에게 알려 주세요. |

**고치지 않았다** — 지시는 `assessments` 하나였고 나머지는 **훑어서 올리라** 였다.
**판정 주시면 같은 방식(가운뎃점)으로 한 번에 적용하겠다.**

## B. ⑷ ③ 승인 · ⑥ 갈무리 — 걸었다

### ③ 승인 — **화면으로는 못 걷는다**(막힌 자리)

| 잰 것 | 값 |
|---|---|
| 가상 회원을 `pending` 으로 만들었는가 | **O** — `memberships` 에 **새 행**을 넣었다(기존 행 무접촉) |
| QA 인도자로 `/admin/approvals` 접근 | **`/coach` 로 되돌려졌다** |

**결함이 아니라 게이트가 작동한 것이다** — QA 인도자는 **운영자가 아니다**.
승인 큐는 운영자 화면이고, 화면으로 승인을 걸으려면 **실계정 운영자 세션**이 필요하다.
**실계정 무접촉이 걸려 여기서 멈춘다.** 최박사·지휘부 계정으로만 걸을 수 있는 자리다.

### ⑥ 갈무리 — **편집·저장까지 걸었고 제출은 못 했다**

| 단계 | 결과 |
|---|---|
| 회차 일정 넣기 | **O** — `cohort_sessions` 1회차(열림) · **RPC 가 아니라 표에 직접**(↓) |
| 차수 홈 | 「QA 참여자 님의 여정 / PART 1 · GOAL — 과거의 나를 만나다 / 0 / 1 완료 / 오늘의 갈무리」 |
| 갈무리 화면 | 「오늘 꺼낸 갈망을 여기에 적어 둡니다. 7주 기록의 첫 장입니다.」(**C-01 새 문안**) |
| 저장 | **O** — 단추 이름 「갈무리 저장」 · 행이 생겼다 |
| **제출** | **★ 못 갔다** — `submitted_at` 이 비어 있다 |
| 읽기·고치기 | 미제출이라 **읽기 모드가 서지 않는다**(규칙대로) |

**이것은 앱의 결함이 아니라 내 탐침의 한계다.**
갈무리는 필수 칸이 여럿(자유서술·마음 낱말·눈금·짝 문장)인데 탐침이 다 채우지 못했고,
그래서 **결측 게이트**(「채우러 가기」)에 걸렸다. **게이트는 옳게 작동했다.**
`resolveCheckinMode` 가 *미제출 + 열린 회차 → edit* 이므로 읽기 모드가 안 서는 것도 규칙대로다.

→ **사람이 손으로 채우면 되는 자리**이므로 §4 실기기 목록에 넣는다(↓ ㉤).

*(`seed_cohort_sessions` 는 **그 기수의 인도자만** 부를 수 있어(실측 `not authorized to seed sessions`)
 서버 권한 도구로는 못 부른다. 표에 직접 넣었고 **끝에 지웠다** — 관문을 우회한 것이 아니라 관문 밖에서 데이터를 만든 것이다.)*

## C. ⑶ 목록에서 **눌렀을 때** — 어긋나지 않았다
