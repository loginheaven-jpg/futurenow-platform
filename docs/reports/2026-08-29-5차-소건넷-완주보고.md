### 소건 1 — 로그인 체감 수리 (ADR-134) · **완**

| 항 | 파일 | 상태 |
|---|---|---|
| 가 | [login/page.tsx](src/app/login/page.tsx) — 세션 있으면 `redirect()`, 착지는 `loginOutcome` 재사용 | 완 |
| 나 | [LoginClient.tsx](src/app/login/LoginClient.tsx) — `router.push` → **`replace`** | 완 |
| 다 | [LoginForm.tsx](src/app/login/LoginForm.tsx) — `name`·`id` 두 줄 | 완 |
| 라 | [cookiePolicy.ts](src/core/supabase/cookiePolicy.ts) · [client.ts](src/core/supabase/client.ts) · [server.ts](src/core/supabase/server.ts) · [proxy.ts](src/proxy.ts) — `Secure` | 완 |
| 마 | [AccountForm.tsx](src/app/account/AccountForm.tsx) · [AccountClient.tsx](src/app/account/AccountClient.tsx) — 로그인 유지 스위치 | 완 |

**가·나를 둘 다 두는 이유**: 나는 애초에 `/login` 이 히스토리에 남지 않게 하고, 가는
그래도 닿았을 때(북마크·직접 링크·옛 히스토리) 돌려보낸다. 하나만으로는 한쪽 길이 열린 채 남는다.

**라 — `Secure` 는 실측이 근거다.** `@supabase/ssr` 0.12 의 기본값에 `secure` 가 없다:

```
$ cat node_modules/@supabase/ssr/dist/main/utils/constants.js
DEFAULT_COOKIE_OPTIONS = { path:"/", sameSite:"lax", httpOnly:false, maxAge: 400*24*60*60 }
```

**`NODE_ENV` 가 아니라 관측한 프로토콜로 정한다** — `http://localhost` 에 `Secure` 를 붙이면
브라우저가 쿠키를 아예 저장하지 않아 **개발 로그인이 통째로 깨진다.** 프록시 뒤에서는
`x-forwarded-proto` 의 **첫 칸**을 본다.

**마 — 라이브러리 제약을 먼저 읽고 길을 골랐다.**

```
$ sed -n '198,206p' node_modules/@supabase/ssr/dist/main/cookies.js
const setCookieOptions = { ...DEFAULT_COOKIE_OPTIONS, ...options?.cookieOptions,
                           maxAge: DEFAULT_COOKIE_OPTIONS.maxAge };   ← 강제 덮어쓰기
```

**`cookieOptions.maxAge` 로는 세션 쿠키를 만들 수 없다.** 그래서 `cookies` 어댑터를 넘겨
**수명 한 칸만** 지운다. 이름·값·나머지 옵션은 라이브러리가 만들어 건네준 것 그대로이고,
**토큰 형식(base64url·청크)을 읽지도 만들지도 않는다** — 하네스 머리가 경고한
*Supabase 쿠키 형식에 결합된 자가제작 우회*와 구별되는 지점이고, 손대는 층은 웹 표준인 쿠키 헤더 문법이다.

**끈 순간 이미 깔린 쿠키까지 다시 쓴다**(`authCookieRewrites`). 다음 로그인부터 듣는다면
**스위치가 거짓말을 한 것**이 된다.

### 소건 1-바 — 공개 헤더가 세션을 본다 (ADR-138) · **완** · *최박사 승인 추가분*

| 파일 | 상태 |

| [page.tsx](src/app/page.tsx) · [about/page.tsx](src/app/about/page.tsx) — 배선 | 완 |

**문구를 `내 홈` 으로 정한 근거 셋** — 지휘부가 *화면을 보고 정하되 근거를 적으라* 했으므로
실물을 보고 정했다.

| # | 근거 | 실물 |
|---|---|---|
| ⑴ | **자리의 위계.** 나가는 동작을 헤더에서 **가장 강한 자리**에 두면, 돌아온 참여자에게 앱이 권하는 첫 행동이 *나가기* 가 된다 | `.site-gnb__login { color: var(--color-text-on-gold); background: var(--color-accent); font-weight: 700 }` — 골드 면 + 700. 현관의 **유일한 상시 CTA** 다. 골드를 전진 동작에만 쓰는 위계는 §9.7 #15 `BookPanel`(*골드 primary 금지 · 세미나 신청 CTA 전용*)에 이미 서 있다 |
| ⑵ | **증상의 정체.** 필요한 것은 *로그인 상태임을 알리고 **돌아갈 길**을 주는 것*이다. `로그아웃` 도 상태는 알리지만 **제공하는 동작이 원하는 것의 정반대** | 증상이 *로그아웃된 것 같다* 였다(F-5 B행) |
| ⑶ | **로그아웃은 이미 있고 여기엔 없어도 된다.** 현관에 두면 **같은 동작이 두 곳**이 된다(불변식 23) | 어포던스는 멤버 셸 `LogoutButton` 하나. 시트에 **일부러 넣지 않았다** — `memberSheet.ts:65` *"로그아웃은 넣지 않는다 — 폼 액션이라 링크 목록에 섞으면…"*. `내 홈` 을 누르면 곧 그 셸에 닿는다 |

**ISR 을 깨지 않았다** — 이것이 이 항의 진짜 제약이었다.

```
서버에서 cookies() 를 부르면 /(5m)·/about 이 동적이 된다 → 4차 게이트(ISR 무손상)가 깨진다
$ npx next build   →  ○ /  5m · ○ /about · ○ /recruit 5m   (변화 없음)
```

그래서 세션 읽기를 **브라우저로 내렸다**(`useSyncExternalStore` · 서버 스냅샷 = 비로그인이라
정적 HTML 과 같고 **하이드레이션 불일치가 없다**). **대가는 한 프레임 깜빡임**이고 감추지 않는다 —
로그인한 사람에게만, 마운트 뒤 `로그인` → `내 홈` 으로 한 번 바뀐다.

**쿠키 값을 해석하지 않는다** — 이름 접두사만 본다(`isAuthCookieName`). 값 안의 만료 시각을 읽으려면
토큰 형식(base64url·청크)에 결합돼야 하고 **그것이 하네스가 경고한 자가제작 우회**다.
한계: 만료 쿠키가 남으면 `내 홈` 이 보이고 눌렀을 때 `/login` 으로 간다 — **지금과 같은 결과이고
더 나빠지지 않는다.** 게다가 `proxy` 가 매 요청 `getUser()` 로 검증·갱신하고 공개 경로도 그 matcher
안이라(불변식 17) 어긋나는 창이 좁다.

**잠금 둘이 동시에 물었다.** 새 `.tsx` 를 만들자 `designParts.test.ts` 와 `site.purity.test.tsx` 가
*이것이 부품인가* 를 물었다 — **정확한 동작이다.** `PublicGnb` 는 부품이 아니라 화면 층이므로
양쪽에 **사유와 함께** 예외로 등록했다. `designParts` 머리의 *"그 둘은…"* 도 셋이 됐으므로 함께
고쳤다 — **값과 문장이 갈리면 문장이 조용히 거짓이 된다.**

### 소건 2 — 복수 반응 (ADR-135) · **완**

| 층 | 변경 | 상태 |
|---|---|---|
| 표 | [20260829090000_feed_reactions_multi.sql](supabase/migrations/20260829090000_feed_reactions_multi.sql) — PK `(post_id,user_id)` → `(post_id,user_id,emoji)` | 완 |
| RPC | `feed_react` **토글화**(반환 `text[]`) · `feed_post_list` `my_reactions text[]` | 완 |
| 계약 | [domain.ts](src/contracts/domain.ts) `myReactions: FeedEmoji[]` · [core-context.ts](src/contracts/core-context.ts) | 완 |
| 화면 | [reactionState.ts](src/app/feed/reactionState.ts)(순수) · [FeedClient.tsx](src/app/feed/FeedClient.tsx) | 완 |

- **PK 를 넓히는 방향**이라 기존 행이 전부 유효하다 — **데이터 소실 0**. 좁히는 변경이었다면 사전 판정이 필요했다.
- **빈 배열이 무반응**이고 `null` 을 쓰지 않는다. 없음을 두 가지로 표현하면 화면마다 다르게 검사하고 언젠가 한쪽을 빠뜨린다.
- **순서를 고정했다** — 반환·목록 두 경로 모두 `feed_emojis()` 선언 순서. 기준이 없으면 같은 상태가 호출마다 다른 배열로 와서 화면이 깜빡이고 테스트가 흔들린다.
- 낙관적 갱신을 **순수 함수로 뺐다.** 단일일 때는 두 줄이었지만 복수는 집합 연산이고, 인라인이면 경계 조건이 테스트가 닿지 않는 곳에 숨는다. **서버가 준 배열을 진실로 삼는다**(경합 시 추측은 어긋나고 서버 값은 어긋나지 않는다).
- 복수 토글이므로 버튼에 **`aria-pressed`** 를 달았다 — 눌린 상태를 색만으로 말하지 않는다(§9.7 칩과 같은 규율).

| 파일 | 변경 |
|---|---|

**왜 뒤집나** — §4.3 의 근거(*이 필드가 없으면 승인 큐가 판단 불가로 쌓이고, 나중에 필드를 더해도
이미 들어온 신청 건은 영원히 대조할 수 없다*)는 **그대로 유효하고 그 자리를 무엇이 채우느냐만 바뀌었다.**
포럼 이름·연락처를 필수로 두면 포럼을 거치지 않고 온 사람이 가입할 수 없거나 **지어낸다.**
지어낸 값은 대조를 돕는 게 아니라 **운영자를 헷갈리게 한다** — 명단에 없는 이름이 오타인지
남의 것인지 판단할 수 없다. 가입 경위는 **누구나 사실대로 쓸 수 있다.**

**문안과 강제를 함께 뒤집었다.** 어긋나면 *동의는 받았으나 동의한 내용이 아닌 것*이 된다.
사본 둘이 생기기 쉬운 자리라 테스트가 둘을 묶는다(불변식 23 계열).

**하위호환(지휘부 지시 항목)** — 실측으로 세 경우를 갈랐다.

| 기존 pending 행 | 화면이 하는 말 |
|---|---|
| 경위 있음 · 포럼 없음(새 신청) | 경위를 본문으로 · 포럼은 `미기재(선택 항목)` |
| 경위 없음 · 포럼 있음(옛 신청) | `경위 미기재` + **`포럼 정보로 대조해 주세요(양식 개편 전 신청).`** |
| 경위 없음 · 포럼 없음(옛 신청) | `양식 개편 전 신청입니다.` — 없는 것을 지어내지 않는다 |

옛 문구 `명단 대조 안 됨` 은 **실패로 읽혀 승인을 주저하게 만들므로** 걷어냈다.
**처리 버튼은 그대로 산다** — 표시가 바뀌었다고 처리가 막히면 큐가 쌓인다.

부품이 아닌 파일을 하나 더했으므로 표가 무엇을 세는지 문서가 말해야 한다.
그 밖에는 **새 시각 언어를 만들지 않았다**: 스위치는 기존
`ConsentBlock` 과 **같은 치수의 체크박스**(18px·`flexShrink`)이고, 승인 큐·반응 줄은 기존
토큰과 `ui-*` 클래스만 쓴다. 처음에 20px 로 적었다가 기존 패턴과 어긋나 맞췄다(불변식 20).

## 4. 계약 대비 이탈 여부

**이탈 0.** 계약 변경은 **소건 2 하나**이고 지휘부가 **사전 승인**한 그 범위 그대로다 —
`myReaction: FeedEmoji | null` → `myReactions: FeedEmoji[]`, 빈 배열이 무반응.
`reactToFeedPost` 의 반환 타입도 같은 이유로 배열이 됐다(같은 결정의 다른 면이라 별도 승인 사안이 아니라고 판단했다 — 아니면 지적해 주십시오).
그 밖의 `/contracts` 변경은 없다.

## 5. 하네스 주석 — 측정 도구 계열 ⑤⑥ (지휘부 지시)

`scripts/shots.mjs` 머리의 *"이 스택 고유의 함정"* 을 **셋 → 여섯**으로 늘렸다.

- **⑤ `page.goBack()` 의 반환값이 거짓을 말한다** — App Router 의 클라이언트 뒤로가기는
  문서 내비게이션이 아니라 `null` 이 온다. **이동은 했는데 "못 갔다"로 읽힌다.**
  그대로 믿으면 *"뒤로가기는 두 번이면 끝"* 이 나온다(실제로는 넷). → **URL 로 판정한다.**
- **⑥ 되돌리기가 커밋 전 작업을 지운다** — 변이 하네스가 복원을 `git checkout` 으로 했는데
  그 편집이 커밋 전이라 **재는 대상 자체가 사라졌다.** 변이 하나가 통과로 나왔고
  그것은 잠금이 좋아서가 아니라 **원본이 없어서**였다. → 되돌리기는 **백업본 복사**.

⑥ 은 어제 ADR-132 를 만들며 겪은 것이고, ⑤ 와 같은 뿌리라 함께 실었다 —
**측정 도구를 먼저 재는 일은 도구의 되돌리기에도 걸린다.**

## 6. 이번에 내가 틀린 것

- **`useEffect` 안에서 `setState`** 로 스위치 초기값을 읽었다. 린트가 *연쇄 렌더*로 잡았고
  `useSyncExternalStore` 로 바꿨다(서버 스냅샷 = 기본 켬이라 SSR 불일치도 없다). **린트가 맞았다.**
- **체크박스를 20px 로** 새로 그렸다. 기존 `ConsentBlock` 이 18px 이었다 — 불변식 20 의
  *새 시각 언어를 만들지 않는다* 에 걸린다. 맞췄다.
- **순수 함수 테스트 입력이 자기모순**이었다. `before=['👏']` 인데 시작 집계가 `{}`(아무도 안 눌렀다)라
  실패했는데, **함수가 맞고 입력이 틀린 것**이었다. 아귀가 맞는 입력으로 고쳤다.
