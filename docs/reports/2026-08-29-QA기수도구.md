## 1. 도구 — `scripts/qaCohort.mjs`

```
up      기수 둘(QAAAA·QABBB) + 가상 회원 셋을 세운다
status  지금 무엇이 서 있는가
check   ③④ 를 잰다(화면 + 데이터)
switch  기수 전환·격리를 화면으로 잰다
down    전부 치우고 0 을 확인한다
```

**표식은 세 겹이다** — 이름(`[QA전환]`)·코드(`QAAAA`·`QABBB`)·이메일(`@qa.invalid`).
하나만 보면 치우다 놓친다.

**실기수는 코드가 막는다**:

```js
const FORBIDDEN_CODES = ['ZR4KB', 'HMT7Z'];
// down 에서 그 코드를 만나면 → '★ 멈춘다 — 실기수를 지우려 한다'
```

## 2. ③ 참여자 화면 — **표식이 아니라 화면으로 쟀다**

QA 기수 둘과 가상 회원 셋이 **서 있는 동안** 실브라우저로:

| 화면 | `[QA` | `qa.invalid` |
|---|---|---|
| 모집 랜딩 `/recruit` | **0** | **0** |
| 공개 현관 `/` | **0** | **0** |
| 서가 `/library` | **0** | **0** |

집계도 함께 봤다 — **`cohort_seats_taken('ZR4KB') = 8`**, QA 를 세운 상태에서도 그대로다.
(모집 집계는 **기수 코드**로 세므로 다른 코드의 기수는 애초에 들어오지 않는다 — 그 사실을 화면과 값 둘로 확인했다.)

## 3. ④ 가상 회원 — **양방향으로 갈린다**

| 방향 | 값 |
|---|---|
| **넣을 때** — QA 기수 등록 | **5건**(QA 참여자 2 + 가상 3) |
| **거를 때** — 가상 회원이 QA 밖 기수에 | **0건** |

## 4. ① 무접촉 — 전후 대조

| 값 | 세우기 전 | 치운 뒤 |
|---|---|---|
| `cohort_seats_taken('ZR4KB')` | 8 | **8** |
| `cohort_seats_taken('HMT7Z')` | 9 | **9** |
| `seminar` 기수 수 | 3 | **3** |
| `enrollments` 총 | 29 | **29** |
| `auth.users` 총 | 26 | **26** |

**행 수가 아니라 값으로 봤다** — 집계 함수 둘은 «누가 몇 명인가» 를 다시 계산한 값이다.

## 5. ★ 기수 전환 — **그동안 못 쟀던 것을 끝냈다**

피드 잔여 실측에서 *「QA 계정이 기수 하나라 전환 자체가 없다」* 로 남겼던 자리다.

```
전환 칩 3개: ["[QA전환] B", "[QA전환] A", "[QA] 검증 전용"]
A 기수에 글 하나 남김
B 로 전환 — A 의 글이 보이는가: 아니오 — 격리 정상
A 로 되돌아가면 다시 보이는가(대조군): O — 격리다
```

**대조군이 있다** — B 에서 안 보이는 것이 «격리» 인지 «사라짐» 인지 가른다.
되돌아가서 보이므로 **격리**다. 검증 글 4개는 치웠고 QA 기수에 남은 글 **0**.

### ★ 이 측정에서 탐침이 **두 번** 틀렸다

**앱이 아니라 창이 틀렸다.** 두 번 다 «누출» 로 보였고 두 번 다 내 도구였다.

| # | 무엇이 틀렸나 | 어떻게 드러났나 |
|---|---|---|
| 1 | `hasText: 'A'` 가 **「[QA전환] B」에도 걸렸다** — 「QA」의 A 때문이다. 두 클릭이 **같은 칩**으로 갔다 | 두 화면의 `aria-current` 와 URL 이 **똑같았다** |
| 2 | 전환이 **끝나기 전에** 쟀다. `settle()` 은 떠나온 화면에서도 즉시 참이다 | 좁혀 보니 A 는 글 0, B 에만 있었다 |

처방을 도구에 박았다 — **정확 일치 선택자** + **선택 표시가 목표와 같아질 때까지 기다린다**.
그리고 판정을 **글 단위**로 좁혔다(본문 전체는 입력창까지 걸린다 · ⑨-b).

**세 번째로 같은 자리다**(오늘만: 로딩 셸 · `/recruit` 의 「체험」 · 이번 둘).
**⑨-c 를 세운 그 회차에 ⑨-a·⑨-b 를 또 밟았다** — 조항이 있다고 안 밟는 것이 아니다.
