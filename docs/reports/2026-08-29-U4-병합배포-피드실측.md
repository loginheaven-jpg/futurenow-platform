## 1. ① `/signup` — ㉮ 채택, 표기를 실물에 맞췄다

**화면은 한 글자도 바꾸지 않았다.** 표에 `flow` 아래 한 칸을 두었다.

```ts
exit?: { label: string; href: string; why: string }

'/signup': { kind: 'bar', variant: 'flow', title: '회원가입', menu: false,
  exit: { label: '처음으로', href: '/',
          why: '가입을 그만두는 사람이 갈 곳. GNB 가 서지 않아(실측 로고 0) 이 문이 유일한 출구다.' } }
```

**잠금을 문자열에서 계약으로 옮겼다.** 옛 잠금은 표의 한 줄을 정규식으로 쟀다.
이제 `SCREEN_CHROME['/signup'].exit` 을 읽고 **화면에 그 문이 실제로 있는지**까지 잰다.

**물려 봤다**(조항 ⑪):

| 변이 | 결과 |
|---|---|
| 표에서 `exit` 삭제 | **레드** — 「되돌아가는 문 선언이 사라졌다」 |
| 화면에서 「처음으로」 삭제 | **레드** — 「선언은 남고 문이 사라졌다」 |
| 원복 | 초록 |

## 4. ④ 피드 잔여 실측 — QA 차수(`[QA] 검증 전용`) 안에서만

**실기수 무접촉.** 쓰기 직전마다 **관문**을 두었다 — 기수가 QA 가 아니면 **던지고 멈춘다.**
관문이 실제로 두 번 물었다(기수 이름이 화면에 없을 때 · 참여자 신원을 확인 못 했을 때).
참여자 쪽 신원은 **방금 QA 에 올린 글이 그 화면에 보이는가**로 대조했다 — 추측이 아니다.

| 단계 | 결과 |
|---|---|
| 인도자가 첫 글을 올린다 | **O** |
| 사진을 올린다 | **O** — 미리보기 → 글 안 이미지 확인 |
| 참여자가 반응 **둘을 함께** 단다 | **O** — `aria-pressed=true` 둘 동시(복수 선택 정상) |
| 댓글을 단다 | **O** |
| 기수를 전환한다 | **불가 — 잴 수 없었다**(↓) |
| 다른 기수 글이 안 보인다 | **부분 실측**(↓) |

### 막힌 자리 하나 — 기수 전환을 화면으로 못 잰다

**QA 인도자·QA 참여자 둘 다 속한 기수가 하나다**(`[QA] 검증 전용`).
전환 nav 는 `cohorts.length > 1` 일 때만 서므로 **전환이라는 동작 자체가 화면에 없다.**

**잴 수 있는 만큼은 쟀다** — 속하지 않은 기수 id 를 인자로 넣어 보았다:

```
/feed?cohort=00000000-0000-4000-8000-000000000001
  → 글 6건 (= 자기 기수 글 그대로) · 남의 글 0
```

**인자가 문이 아니다.** 정본이 그것을 말한다 — `feed/page.tsx:49`

```ts
const cohorts = await ctx.listFeedCohorts();          // 자기 기수만
const selected = cohorts.find((c) => c.cohortId === sp.cohort) ?? cohorts[0];
```

인자는 **자기 기수 중에서 고르기만 한다.** 속하지 않은 기수는 애초에 목록에 없다.

**그래도 «다른 기수 글이 안 보인다»의 화면 실측은 아니다.** 하려면 **QA 차수를 하나 더** 만들고
QA 참여자를 양쪽에 넣어야 한다. **차수 개설은 운영 데이터를 늘리는 일이라 자기 안대로 가지 않고 올린다.**

### 걸으며 함께 확인된 것 둘

- **이중 제출 가드가 실제로 문다** — 사진 처리 중 「올리기」가 `disabled` 다.
  내 탐침이 그것을 안 기다려 한 번 실패했고, **앱이 옳고 탐침이 틀렸다.**
- **댓글 달린 글을 지우면 묘비가 남는다** — 「지워진 글이에요.」 + 댓글 수 유지(soft delete).

### 뒷정리

걸으며 만든 글은 **`[검증 …]` 표식이 붙은 것만** 지웠다. 원래 있던 글은 건드리지 않았다.
남은 것: 원래 글 1 + 묘비 1(내가 댓글을 단 글이라 삭제해도 묘비가 남는다).
