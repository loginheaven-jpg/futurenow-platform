## 2. 백틱 후속 — **65건 전체 diff 를 양방향으로**

지휘부 지적이 정확했다 — *「백틱을 먹은 자리가 하나였다는 것은 다른 것도 먹었을 수 있다는 뜻」*.
문자열만 보지 않고 **코드가 상한 자리**도 함께 봤다.

```
적용 대상 65건
① 새 문장이 안 들어간 것      0건
② 옛 문장이 남은 것          0건
③ 표로 설명되지 않는 바뀐 줄   0건
④ 코드가 상한 자리           0건
```

### ★ 이 0 을 그대로 믿지 않았다 — 물려 보니 **자가 안 물었다**

첫 판에서 변이 둘을 먹였는데 **둘 다 못 잡았다.** 원인은 자였다:

| 무엇이 틀렸나 | 어떻게 드러났나 |
|---|---|
| `git diff BASE..HEAD` 로 **커밋 간**만 봤다 | 작업 트리에 심은 변이가 **보이지 않았다** |
| 변이 자체가 안 심어진 회차가 있었다 | **변이 성립을 먼저 확인하지 않았다**(계열 ⑧) |

`git diff BASE`(작업 트리 포함)로 고치고 **변이 성립을 먼저 확인**한 뒤 다시 물렸다:

| 변이 | 결과 |
|---|---|
| 템플릿 리터럴 백틱을 다시 먹임 | **④ 1건으로 잡음** |
| 표에 없는 문자열(`과거와 미래의 나`)을 고침 | **③ 2건으로 잡음** |
| 표에 있는 문장을 조사만 바꿈 | **①②로 잡음** |
| 원복 | 0 |

**「0」은 자를 물린 뒤의 0 이다.**
