## 1. 손으로 옮기지 않았다

표의 제1원칙이 *「대체문장을 그대로 넣는다. 조사 하나 바꾸지 않는다」* 다.
63곳을 손으로 옮기면 **옮겨 적는 순간 ⑵ 를 ⑴ 처럼 다루는 일**이 된다.
그래서 `scripts/applyCopyTable.mjs` 를 지어 **표에서 읽어 그대로** 넣었다.

| 방식 | 건수 |
|---|---|
| 도구가 자동으로 | **59** |
| 손으로(사유 있음) | **4** — H-05·J-04·J-10·D-14 |
| 원고 재추출 | **1** — S-02 |
| 코드 직접 | **1** — S-03 |

**손으로 넣은 넷의 사유**:
- **H-05 · J-10** — 코드는 `교회·기관`(공백 없음), 표는 `교회 · 기관`. **표의 문장을 그대로** 넣었다.
- **J-04** — JSX 두 줄이 한 문단이었다. 대체문장이 한 문장이므로 **둘째 줄이 사라진다**(표가 그렇게 정했다).
- **D-14** — 「D-12 와 동일하게」라는 **참조 행**이라 도구가 판단하지 않고 손으로 옮겼다.

**수가 아니라 정체로 확인했다** — 늘어난 21이 전부 표의 대체문장이고 사라진 21이 전부 표의 현재문장이다.
**딴 것이 섞이지 않았다.** (지휘부 조건 *「다르면 멈춰라」* 는 «설명되지 않는 차이» 를 가리키고, 그것은 0이다.)
