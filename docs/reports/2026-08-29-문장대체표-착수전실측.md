## ① 기준 커밋 대조 — **76/76**

`scripts/copyTableAudit.mjs` 를 지어 자리마다 셋을 쟀다:
⑴ 파일이 실재하는가 ⑵ **현재문장이 그 파일에 있는가** ⑶ 표가 적은 행 번호가 맞는가.

```
표에서 읽은 항목 76건
① 파일이 없거나 위치를 못 읽음   0건
② 현재문장이 저장소에 없다        0건
③ 행 번호가 어긋난다             0건
```

**「같은 일이 또 있다고 보고 재라」는 지시대로 쟀고, 이번에는 없었다.**

76/76 은 **네 번 고친 뒤의 값**이다. 고치기 전 값들은 전부 거짓이었다:

**그래서 물려 봤다** — 76/76 이 「무엇이든 통과시키는 자」가 아님을 확인해야 했다:

## ④ `copyBaseline.json` 재생성 — **델타 0**

**생성기가 없었다.** 손으로 만든 스냅샷이라 「재생성하면 무엇이 들어올지」를 아무도 몰랐다.
그래서 `scripts/regenCopyBaseline.mjs` 를 지어 **추출 규칙을 `copyRegression.test.ts` 와 같게** 옮기고,
**문장을 하나도 고치지 않은 지금** 재생성해 대조했다:

```
회차     지금  재생성  늘어남  사라짐
session1     62      62       0       0
session2     85      85       0       0
session3     84      84       0       0
session4     89      89       0       0
session5     84      84       0       0
합계 404건 · 늘어남 0 · 사라짐 0
```

**404건은 표 §9.1 이 적은 수와 같다.**
**지금 파일은 추출의 산물이다** — 재생성이 딴것을 쓸어 오지 않는다.

→ 개편 뒤 재생성하면 **차이가 곧 표의 갈무리 23건**이어야 한다. 그보다 많으면 딴 것이 섞인 것이고,
   이 도구가 그 차이를 **줄 단위로** 낸다(`--verify` 는 쓰지 않고 대조만 한다).
