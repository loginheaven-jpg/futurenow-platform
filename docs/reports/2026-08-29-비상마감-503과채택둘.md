# ② RSC 503 — 한 줄로 닫는다 · 그리고 채택된 둘

> 2026-08-29 · `main` 위에서 실측 · **실기수 무접촉**(화면 열기까지만)

---

## 1. ★ 503 은 **앱 쪽 원인이 아니다** — 닫는다

| 잰 것 | 값 |
|---|---|
| 앱 코드에 503 을 내는 자리 | **0** (`grep -rn 503 src/` → 이번 사고를 적은 **주석 둘**뿐) |
| 미들웨어(`proxy.ts`)가 낼 수 있는 응답 | `next()` · `redirect()` **둘뿐** — 503 을 만들 수 없다 |
| 운영 런타임 로그 **5xx**(24시간) | **0건** — 함수까지 닿은 요청 중 실패가 **하나도 없다** |
| 지금 프리페치 60회(동시 6) | **60/60 이 200** · 중앙 122ms · 최대 805ms |
| 브라우저 클릭 72회 중 4xx·5xx | **0건** |

**앱은 503 을 낼 수 없고, 함수까지 닿은 실패는 0이다.** 그러므로 그 503 은
**함수 앞(플랫폼)에서 끊긴 응답**이다 — 런타임 로그에 남지 않는 자리가 정확히 거기다.
**앱 쪽 원인이 아니므로 손대지 않는다.**

*(플랫폼 쪽 사유까지는 우리 도구로 못 가른다. 그것을 «모른다» 로 남긴다 —
 hobby 플랜의 순간 동시성 한도가 유력하나 **확인하지 못한 것을 원인으로 적지 않는다.**)*

## 2. 참여자 체감 — **차이가 없다**(수로 한 줄)

클릭 → 「이 모임에 들어갑니다」가 실제로 설 때까지(로딩 셸이 아니라 실물), 각 5회:

| | 중앙 | 최소 | 최대 |
|---|---|---|---|
| 프리페치 정상 | **382ms** | 361 | 1008 |
| **프리페치를 전부 503 으로 막음** | **389ms** | 375 | 475 |

**차이 7ms — 잡음 수준이다.** 프리페치가 죽으면 라우터가 하드 내비게이션으로 떨어지고,
그 비용이 참여자에게 닿지 않는다. **막을 것이 아니라 밝힐 것이었다는 판단이 맞았다.**

## 3. `code` 가 빠진 `/join?_rsc=` — 프레임워크다(재확인)

`/recruit` 의 join 링크는 **셋 · 전부 `?code=ZR4KB`**, bare 링크 **0**.
그 요청은 `?code=` 프리페치와 **같은 `_rsc` 값**을 달고 나가는 라우터의 껍데기 프리페치다.
**우리 코드가 만들지 않았고 해롭지도 않다.**

## 4. 채택된 둘 — 넣었다

### ㉠ 캡처 목록에 딥링크 한 줄

```js
{ name: 'join-code', path: '/join?code=ZR4KB', note: '딥링크 — 차수 미리보기 단계' },
```

U-4 는 `/join` **첫 단계만** 찍어 `?code=` 경로를 한 번도 열지 않았다 — 이번 구멍의 절반이다.
4폭 캡처로 **미리보기 단계가 실제로 서는 것**을 확인했다(제목바 「이 모임에 들어갑니다」·기수 이름·인원).
**열기만 한다** — 캡처는 「들어가기」를 누르지 않는다.

### ㉡ `postdeploy` 에 재호출 상한

```
O /join?code= 재호출 상한   POST 1회 / 6초 (상한 3)
```

기존 4번 항목은 **200 과 크기만** 봤다. 이번 사고는 **200 을 내면서 무한히 다시 부르는** 것이었다 —
**판정의 근거가 판정하려는 것보다 좁았다.** 그래서 **횟수를 센다.**

**물려 봤다**(조항 ⑪):

| 변이 | 결과 |
|---|---|
| 상한을 0 으로(정상도 초과하게) | **X 실패** — 판정이 실제로 수를 본다 |
| `playwright` 를 못 찾게(도구 부재) | **X 실패** — *못 잰 것*을 통과로 읽지 않는다 |
| 원복 | O 통과 |

### 넣지 않은 것

**「버튼을 여러 시점에 눌러 본다」는 넣지 않았다**(지휘부 지시).
근거가 오측이었고, **없는 결함에 잠금을 걸면 잠금이 아무것도 증명하지 못한다.**
