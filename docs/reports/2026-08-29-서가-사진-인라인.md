# 서가 사진 인라인 — 「피드처럼」의 뜻 셋 중 하나

**발주**: 최박사 판정 셋(2026-08-29) — ① 전체공개는 로그아웃해도 보인다 · ② 등급 뜻을 적어도 좋으나 간략히 ·
③ 썸네일/원본은 「자네가 판단하여 사용성 저해하지 않는 선에서 진행」.

**요구가 하나가 아니었다** — 「피드처럼」이 뜻하는 것은 **반응 아이콘 · 전체공개시 사진 · 컨텐츠 막바로 노출** 셋이다.
셋은 범위도 위험도 다르므로 갈라서 다뤘다.

| 요구 | 범위 | 이 회차에 |
|---|---|---|
| 컨텐츠 막바로 노출(글) | **0** | **이미 되어 있었다** — 목록이 `description` 을 제목 아래 그린다. 할 일 없음 |
| 전체공개시 사진 | A 확장 | **지었다** |
| 반응 아이콘 | **B 전체** | **짓지 않았다** — 별도 발주 |

## 1. 착수 전 실측 — 판정의 전제를 먼저 물었다

### ⑴ 판정 ①은 성립한다(대조 쌍)

`library_can_view` 에서 `public` 갈래가 **로그인 검사보다 위**에 있다는 것을 코드로 읽고,
**실제로 로그아웃 요청을 넣어** 확인했다 — 정책이 그렇다고 프록시가 흘리는 것은 아니고,
저장소 RLS 가 `anon` 을 어떻게 보는지는 **다른 층**이기 때문이다(⑨-c).

| 잰 것 | 값 |
|---|---|
| 로그아웃 · `public` 파일 | **200 · image/png · 21365 bytes** |
| 로그아웃 · `forum` 파일 | **404 · 0 bytes** |
| 로그아웃 목록 | `public`(can_view=true) · `forum`(can_view=false) 둘 다 **선다** |

**대조 쌍이 갈렸으므로 잰 것이 있다.** 그리고 목록에는 **못 보는 자료도 서기 때문에**
사진 조건에 `can_view` 를 곱하지 않으면 **표지 사진이 샌다** — 이것이 설계의 급소가 됐다.

### ⑵ 판정 ③의 전제가 깨졌다 — 썸네일이 실재하지 않는다

저장소 변환을 **실제로 불러 봤다**:

| 잰 것 | 값 |
|---|---|
| `download(path, { transform: { width: 400 } })` | **★ `feature not enabled for this tenant`** |
| `download(path)` (원본) | 21365 bytes · image/png |

**「썸네일로 간다」고 적었으면 없는 것을 근거로 적은 것이다.**

### ⑶ 그래서 무엇을 골랐나

| 후보 | 판정 |
|---|---|
| 저장소 변환 썸네일 | **불가**(위 실측) |
| 서버 `sharp` 리사이즈 | **안 함** — `package.json` 에 `sharp` 가 **없다**(실측). 새 런타임 의존이 생긴다 |
| **mimetype + 크기 상한 + `loading=lazy`** | **채택** — 새 의존성 0 · 새 라우트 0 · 관문 그대로 |

**상한 위의 사진은 안 보이는 것이 아니라 한 번 더 누른다.**

### ⑷ 상한을 무엇으로 정했나

| 잰 것 | 값 |
|---|---|
| `library_items` 에 mime·size 열 | **없다** |
| `storage.objects.metadata` | `mimetype`·`size` **둘 다 있다** |
| 실물 자료 표본 | `image/jpeg` · **2 958 554 bytes(2.96MB)** |

**5MB** 로 정했다. 표본이 2.96MB 이므로 실사진 대부분이 통과하고, 그 위는 눌러서 본다.

**확장자로 파생하지 않았다** — mimetype 은 올릴 때 실제로 붙은 값이고 확장자는 올린 사람이 짓는다
(성질은 파생하지 말고 실측으로 정한다 · 승격 2026-08-29).

### ⑸ 곁가지 — B 표 다섯에 한 겹이 모자란다

| 잰 것 | 값 |
|---|---|
| `authenticated` — 정책 0 | **0행** |
| **정책 하나 만들면** | **1행** ← 변이 성립 |

RLS 켜짐 + 정책 0 이라 **지금은 막힌다.** 그러나 `anon`·`authenticated` **테이블 권한이 남아 있어**
정책 하나에 곧바로 열린다. `library_items` 는 A 에서 `REVOKE` 까지 했다.
→ **B 발주서 첫 줄이 `REVOKE … FROM public, anon, authenticated`** 여야 같은 두 겹이 된다.

## 2. 지은 것

### 뼈대를 한 겹 더 닫았다

앞선 정리에서 ㉮(경로만 내고 화면이 따로 청구 — 피드 방식)를 권고했으나,
**서가는 프록시 라우트가 이미 있어 경로마저 필요 없었다.**

목록이 받는 것은 **`photo` 라는 참·거짓 한 칸**이고 화면이 프록시 주소를 조립한다.
그래서 서가 A §4 「목록에 주소 칸이 없다」가 **그대로 산다** — 피드보다 한 겹 닫혀 있다.

```
photo = can_view  AND  kind='file'  AND  mimetype LIKE 'image/%'  AND  size <= 상한
```

`library_can_view` 를 **한 번만** 부르고(LATERAL) 두 값이 함께 쓴다 — 두 번 부르면 갈릴 자리가 생긴다(불변식 23).

### 상한은 사본이 하나다

DB 함수 `library_inline_photo_max_bytes()` **한 곳**에만 산다.
화면은 그 숫자를 **모른다**(RPC 가 참·거짓으로 답하므로 알 필요가 없다).
잠금이 **TS 어디에도 그 숫자가 없음**을 잰다.

### 등급 뜻 한 줄(판정 ②)

`LIBRARY_TIER_NOTE` 를 이름표와 같은 자리에 두고 화면이 읽는다.

| 등급 | 문장 |
|---|---|
| 전체 공개 | 로그인하지 않은 사람도 봅니다. |
| 포럼회원 | 로그인한 포럼회원이 봅니다. |
| 인도자 | 인도자만 봅니다. |

**※ 이 세 문장은 제가 지었습니다 — 결재를 청합니다.**
「적어도 좋으나 간략히」라는 지침에 따랐고, 표에 없던 문장이므로 명시합니다.

## 6. 계약 대비 이탈

**`/src/contracts/domain.ts` 의 `LibraryItem` 에 `photo: boolean` 을 더했습니다** —
불변식 3(계약 변경은 지휘부 승인 후)에 걸리는 항목이므로 명시합니다.

- **방향은 견고화다** — 주소도 경로도 아닌 **참·거짓 한 칸**이고,
  §4 「목록에 주소 칸이 없다」가 그대로 산다(잠금이 그것을 잰다).
- 이 기능은 계약 변경 없이는 불가능하고, 지휘부 지시가 「자네가 판단하여 진행」이었습니다.
- **사후 추인을 청합니다.**

## 9. 배포 후 실측 (지휘부 조건 — 배포 전과 같아야 한다)

**적용 확인**(라이브):

| 잰 것 | 값 |
|---|---|
| 시그니처 | `… created_at timestamp with time zone, photo boolean)` |
| 상한 함수 | **5242880** |
| 권한 | `anon, authenticated, postgres, service_role` — **`PUBLIC` 없음**(의도) |
| 호출 | 정상 |
| 원장 | `20260829135632` — **★ 파일명(`20260902090001`)과 다르다.** 도구가 자체 타임스탬프를 붙였다. 두 문장 다 `create or replace`·`drop if exists` 라 다시 돌아도 멱등이다 |

**배포 확인**: 200 을 통과로 보지 않고 **결재 문안이 실제 번들에 실렸는지**로 판정했다(24회째에 확인).
조건으로 끝나고 상한이 있으며 넘기면 시끄럽게 실패한다.

**대조 쌍 넷 — 전부 갈렸다**:

| 자료 | can_view | photo | 로그아웃 프록시 | 화면이 그리는가 |
|---|---|---|---|---|
| 전체공개 · 상한 안 | true | **true** | **200 · 21365B** | **O 실렸다** |
| 회원 전용 | false | false | **404** | 없다 |
| 인도자 전용 | false | false | **404** | 없다 |
| 전체공개 · **상한 위** | true | **false** | 200 · 6312821B | **없다** |

**★ 급소 — `can_view=false` 인데 `photo=true` 인 자료: 0.** 표지 사진이 새지 않는다.

**배포 전과 같다** — 배포 전 실측도 `public` 200 · `forum` 404 였다.

**상한 위 자료의 뜻을 확인했다** — 목록에 **안 그려지되 프록시로는 열린다.**
「안 보이는 것이 아니라 한 번 더 누른다」가 실물에서 그대로다.

**뒤처리**: 만든 자료 4개 전부 삭제 · 남은 실측 자료 **0** · 남은 probe 객체 **0**.

**도구가 한 번 걸렸다** — 저장소 키에 한글을 넣어 `Invalid key` 가 났다.
**화면에 뜨는 이름과 저장 경로는 다른 것이다.** 경로만 ASCII 로 고쳤다.

| 용건 낱말 제거(`로그인하지 않은` 삭제) | 1 줄 | **레드 2건** |
| 낱말 상자에 사본 부활 | 1 줄 | **레드** |
| 화면이 문장을 직접 박음 | 1 줄 | **레드 2건** |
| 원복 | — | **초록 29/29** |

**원복이 한 번 안 됐다** — `git checkout` 이 *커밋된* 상태로 되돌렸는데 거기엔 사본이 있었다.
「원복 확인: 1 줄」이 그것을 말했고, **값을 찍어 두었기 때문에** 보였다.

## 11. 푸시 전에 잡은 것

**편집이 조용히 실패했다.** `replace` 가 매치되지 않았는데 「화면 갱신」만 찍혔다 —
**명령은 성공했고 대상이 틀렸다.** `verify.mjs` 가 `exit 1`(tsc TS2305)로 잡았고,
그때 eslint 도 4→5 로 올라 있었다. **푸시 전이었다.**

고친 뒤 **값으로** 확인했다(0 곳 / 1 곳 / 1 곳) — 「갱신」이라는 말이 아니라 숫자로.
