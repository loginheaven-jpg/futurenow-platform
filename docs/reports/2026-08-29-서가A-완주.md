## 1. ★ 짓다가 잡은 것 넷

### ㉠ 로고를 없앨 뻔했다 — `/library` 를 `bar` 로 두면

표에 `bar` 로 넣으면 공개 껍데기가 **GNB 와 푸터를 그리지 않는다.** 그러면 **로고가 사라진다.**
U-4 §5 에서 「처음으로」를 걷을 때 **«로고가 그 자리를 대신한다»** 를 근거로 삼았으므로,
그것은 **그 화면의 출구를 없애는 일**이었다. `gnb` 로 바로잡고 화면 제목은 본문 `h1` 이 든다.

**잡은 것은 잠금이 아니라 근거였다** — 표 잠금은 `bar` 를 문제 삼지 않는다.
U-4 에서 «왜 걷어도 되는가» 를 적어 둔 것이 여기서 값을 냈다.

### ㉡ `library_upsert` 가 `'member'` 를 박고 있었다 (예행에서 발견)

저장소에 **부르는 곳이 0** 인 고아 함수인데 `('public','member','coach')` 를 하드코딩하고 있었다.
개명하면 **`'forum'` 은 스스로 거절하고 `'member'` 는 새 CHECK 에 걸려 양쪽으로 막힌다.**
**지우지 않고 함께 고쳤다** — 부르는 곳이 없다고 지우면 없어지는 것을 만드는 일이다.
(함께 `created_by` 도 채웠다. 그전에는 NULL 로 들어가 확정 ⑤·⑥ 이 성립하지 않았다.)

### ㉢ `REVOKE … FROM anon` 은 `PUBLIC` 실행권을 걷지 못한다

새 함수에는 기본으로 `=X`(PUBLIC EXECUTE)가 붙는다. `anon` 에게서 거두려면 **`PUBLIC` 에서** 거둬야 한다.
예행 출력의 ACL 을 읽다가 잡았고 `REVOKE … FROM PUBLIC` 을 먼저 두었다.

### ㉣ 1차 결함이 발주 진단보다 넓었다

발주는 «`member` 권한이 **로그인 전원**에게 열려 있다» 고 했으나, 표 정책은 `tier='member'` 뿐이라
**로그인조차 보지 않았다** — 익명에게 회원 자료의 **메타데이터**(제목·설명·경로)가 열려 있었다.
행이 0이라 피해자는 없었고, 개명과 함께 닫혔다.

## 7. §9 마이그레이션 안전 — 넷 전항

| # | 확인 |
|---|---|
| ㉠ 옛 정의를 라이브에서 받았는가 | **O** — `pg_get_functiondef` · 시그니처는 `pg_get_function_identity_arguments` |
| ㉡ 예행에서 시그니처·본문이 복구되는가 | **O** |
| ㉢ **권한이 복구되는가** | **O** — 다만 **승계가 아니라 `postgres` 의 기본 권한** 덕이었다. 그래서 **`GRANT` 를 명시로** 적었다 |
| ㉣ 부르는 곳 전수 | **정책 하나**(`storage.objects / library_objects_select`). `CASCADE` 를 쓰지 않고 **정책을 먼저** 지웠다 |

**변이가 성립했는지 먼저 확인했다**(계열 ⑧): drop 뒤 함수 0 · 정책 0.
**롤백 문을 먼저 열었다** — `20260901090000_library_v2_a_rollback.sql`(적용하지 않는 파일).

**적용 순서에 대한 판단**: 이 마이그레이션은 **좁히는 변경**(표 SELECT 회수)을 포함한다.
규율은 «좁히는 변경은 코드가 먼저» 이나 **새 코드가 새 RPC 를 부르므로 코드 먼저가 불가능**했다.
둘을 견주면 — **적용 먼저**면 옛 코드가 빈 목록으로 저하하고(`catch(() => [])`),
**배포 먼저**면 새 코드가 없는 RPC 를 불러 **오류**가 난다. **빈 목록이 오류보다 가볍다.**
그리고 **행이 0이라 보이는 차이가 없다.** 적용 → 배포 순으로 갔고 그 사이는 몇 분이었다.

**기존 자료 대조**: `library_items` **0행** · `storage.objects(library)` **0개** — **대조할 값이 없다.**
형식은 준비돼 있다(전후 `select *` 를 `full outer join` · 행 수 비교는 쓰지 않는다).

1. **운영자 삭제 화면은 B** 다. RPC(`library_delete`)는 섰고 부르는 화면이 없다 — 지금은 SQL 로만 지운다.
2. **B 용 표 다섯은 정책 0** 이라 아무도 못 읽는다. B 에서 정책을 지을 때 **물려 봐야** 한다.

4. `/library/[id]` 제목도 **SSR 원문에 없다**(ADR-162 와 같은 성질) — 손대지 않았다.
