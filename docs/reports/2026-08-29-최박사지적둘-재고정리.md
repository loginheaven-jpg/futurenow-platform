# 하나 · 운영자 승인 메뉴의 화면상 진입 경로

## 답 — **문은 있다. 다만 회원 홈에는 없다.**

| 어디에 | 있는가 |
|---|---|
| **콘솔 껍데기의 메뉴 시트**(`/admin`·`/coach` 에서 햄버거) | **O 있다** — 「**운영**」 묶음 아래 「**가입 승인**」 → `/admin/approvals` |
| 콘솔 **탭 줄** | 없다 — 탭은 「이 기수」 문맥만 든다(U-3 확정) |
| **회원 홈(`/home`)의 시트** | **없다** — 여정·진단·자료·계정 넷뿐이다 |
| 회원 홈의 **역할 카드** | 「**본부**」 → `/admin` (「승인·회원·차수를 관리합니다.」) |

### 그래서 실제 경로는 이렇다

```
로그인 → /home  →  [본부] 카드 눌러 /admin  →  햄버거  →  운영 / 가입 승인
                    (1)                        (2)      (3)
```

**주소를 외워 치는 수밖에 없는 상태는 아니다.** 다만 **세 번 눌러야 닿고**,
그 중 **첫 두 번은 승인이라는 낱말이 화면에 없다** — 「본부」 카드의 부제에만 「승인」이 들어 있다.

## 어떻게 쟀나 — **운영자 세션 없이 잰 이유를 밝힌다**

운영자 계정은 **실계정**(최박사·지휘부)이라 무접촉 원칙에 걸린다. 그래서 세 겹으로 쟀다:

| 창 | 무엇을 봤나 | 결과 |
|---|---|---|
| ⑴ 메뉴를 만드는 **순수 함수** `consoleNav({role:'admin'})` | 데이터에 있는가 | `운영/가입 승인→/admin/approvals` **있다** |
| ⑵ **메뉴 시트를 실제로 렌더**(`MenuSheet open`) | 화면에 그려지는가 | **그려진다** — 링크·이름·묶음 셋 다 |
| ⑶ 회원 홈 시트(`buildMemberSheet`) · 역할 카드(`roleTargets('admin')`) | 홈에서 닿는가 | 시트에 **없다** · 카드로 「본부」까지만 |

### ★ 이 측정에서 자가 한 번 틀렸다

처음에 `ConsoleShell` 을 SSR 로 그려 「승인 링크 **없다**」가 나왔다.
**시트가 닫혀 있었기 때문이다** — `MenuSheet` 는 `if (!open) return null` 이다.
**정적 창으로 런타임 행동을 재려 한 것**(⑨-c)이고, 열어서 다시 재니 있었다.
**「없다」를 그대로 보고했으면 없는 결함을 만들 뻔했다.**

# 둘 · 서가 목록의 UX — 재고 정리 (착수하지 않았다)

## 1. 지금 무엇이 다른가 — 실측

| | **피드** | **서가** |
|---|---|---|
| 목록이 내는 것 | `photoPath`(**경로**) · 본문 · 반응 · 댓글 수 | 제목 · 설명 · 등급 · 소속 · 작성자 · `canView` |
| **주소** | **목록에 없다** — 화면이 «보이는 만큼만» 따로 받는다 | **없다**(타입에 칸조차 없다) |
| 이미지 | **목록에서 인라인으로 보인다** | 안 보인다 |
| 여는 법 | 그 자리에서 본다 | **개별 화면으로 가야 한다** |

### ★ 급소 하나를 바로잡는다

**피드도 목록에 주소를 싣지 않는다.** 계약에 그렇게 적혀 있다:

```ts
photoPath: string | null; // 서명 URL 이 아니다. 화면이 보이는 만큼만 따로 발급한다(S-4 §2.2 선례)
```

그리고 `FeedClient` 가 목록을 갈아끼울 때마다 **아직 안 받은 경로만** 모아
`signFeedPhotosAction(missing)` 으로 받는다.

**그러므로 「피드처럼 보이게」가 곧 「목록이 주소를 낸다」는 뜻이 아니다.**
피드는 **경로만 받고 화면이 따로 청구**한다 — 이 구별이 이번 정리의 중심이다.

## 2. 뼈대와 어긋나는가 — **어긋나지 않는다**

서가 A 의 뼈대는 「목록은 제목과 권한만 말한다 · 자료 화면 전체가 관문이다 · 주소는 관문을 지난 사람에게만 간다」다.

- 전체공개 자료에서는 **「관문을 지난 사람」이 곧 「모든 사람」**이다. 감출 것이 없다.
- 그리고 **피드 방식(경로만 주고 화면이 따로 청구)**을 쓰면 **주소는 여전히 목록에 없다.**
  → 뼈대의 세 문장이 **모두 그대로 산다.**

**지휘부 판단과 같다.** 다만 조건이 붙는다 — ↓ §3.

## 3. ★ 값이 큰 자리 — **판정이 어디서 일어나는가**

지금은 목록 RPC 가 주소를 아예 안 내서 **새는 위험이 0** 이다.
목록이 무엇이든 내기 시작하면 **전체공개 판정이 목록에서 일어난다.** 그 판정이 한 번 틀리면
**회원 전용 자료의 주소가 목록에 실린다.**

### 그래서 두 길 중 하나를 고른다

| | ㉮ **경로만 주고 화면이 따로 청구**(피드 방식) | ㉯ 목록이 표시용 주소를 직접 낸다 |
|---|---|---|
| 판정이 서는 곳 | **발급 시점의 서버**(한 곳) | **목록 RPC**(새 자리) |
| 목록 응답에 주소 | **없다**(오늘과 같다) | 있다 |
| 틀렸을 때 | 발급이 거절된다 | **주소가 이미 실려 나갔다** |
| 기존 관용구 | **있다**(피드가 쓴다) | 없다 |

**㉮ 를 권고한다.** 판정을 새 자리에 만들지 않고, 이미 있는 관용구를 쓴다.
*(㉮ 에서도 목록은 「이 자료가 전체공개인가」를 내야 한다 — 그러나 그것은 **주소가 아니라 등급**이고
 이미 `tier` 로 나가고 있다. 늘어나는 것은 **경로 한 칸**뿐이고, 그 경로만으로는 파일이 열리지 않는다.)*

## 4. 대조 쌍 — **무엇을 어떻게 확인할 것인가**

착수하면 이것부터 짓는다. **넣어 보고 안 나오는지**를 넷으로 본다:

| 넣는 것 | 목록 응답에 경로가 | 화면에 이미지가 |
|---|---|---|
| **전체공개(`public`)** 자료 | **나온다** | 보인다 |
| **회원 전용(`forum`)** 자료 | **안 나온다** | 안 보인다 |
| **회기 자료**(`cohort_id` 있음) | **안 나온다** | 안 보인다 |
| **가려진 자료**(`hidden_at`) | **안 나온다** | 안 보인다 |
| **인도자 전용(`coach`)** 자료 | **안 나온다** | 안 보인다 |

그리고 **대조군** — 전체공개를 회원 전용으로 바꾸면 **경로가 사라지는가**(변이가 성립했는지 확인 포함).
그리고 **실물 시험** — 목록에 실린 경로를 **로그아웃 상태에서 직접 열면 막히는가**(오늘의 프록시 시험과 같은 형식).

## 5. 함께 정할 것 셋

| # | 물음 | 정리 |
|---|---|---|
| 1 | **썸네일만인가 원본까지인가** | **썸네일 권고.** 목록에 원본을 실으면 50MB 자료가 목록에서 다운로드된다. 피드는 이미 클라이언트 리사이즈본만 올린다 |
| 2 | **파일이 이미지가 아니면** | PDF·문서는 **미리보기가 없다.** 제목 줄만 남는다 — 지금과 같다. **이미지인 것만 달라진다** |
| 3 | **외부 링크는** | 주소가 **이미 목록에 낼 수 있는 값**이다(관문 밖의 남의 서버다). 다만 **링크 미리보기를 우리가 가져오면** 외부 요청이 생긴다 — **주소 글자만 보이는 쪽을 권고**한다 |

화면이 이미지를 그린다. **발주 범위 밖이라 착수하지 않았다.**

## 보유 — 「피드처럼」의 뜻이 좁혀졌다(최박사, 2026-08-29)

> 「피드처럼 보이게 하고 싶다는 것은 **반응아이콘, 전체공개시 사진, 컨텐츠 막바로 노출** 이런 것들이다.」

앞 절은 **주소 노출** 한 축만 봤다. 뜻이 셋으로 갈렸으므로 **셋을 따로 잰다.**
세 요구는 **범위도 위험도 서로 다르다** — 하나로 묶어 판정하면 안 된다.

### 피드 글 한 장이 그리는 것(실측 · `FeedClient.tsx` 순서대로)

| 순서 | 무엇 | 서가에 지금 |
|---|---|---|
| ① | 글쓴이 이름 · 시각 · (본인/인도자면) 지우기 | **있다** — 배지 줄에 작성자 |
| ② | **본문**(`post.body`, 줄바꿈 보존) | **있다** — `i.description` 을 제목 아래 |
| ③ | **사진**(`photoPath` → 화면이 따로 청구) | **없다** |
| ④ | **이모지 넷**(수는 보이되 정렬에 안 씀 · 불변식 11) | **없다** |

### 셋으로 갈라 본 범위

| 요구 | 지금 | 범위 | 무엇이 필요한가 |
|---|---|---|---|
| **컨텐츠 막바로 노출**(글) | **이미 된다** | **0** | `library_list()` 가 `description` 을 내고 목록이 제목 아래 그린다. **할 일이 없다** |
| **전체공개시 사진** | 안 된다 | **A 확장** | 목록이 경로를 알아야 한다 — 앞 절 ㉮(경로만 + 화면이 따로 청구) |
| **반응 아이콘** | 안 된다 | **B 전체** | 표는 서 있으나 **정책 0 · RPC 0 · 화면 0** |

**「컨텐츠 막바로 노출」이 이미 되어 있다**는 것이 이 절의 첫 소득이다.
셋을 한 덩이로 발주하면 **이미 있는 것을 다시 짓는다.**

### 반응 아이콘 — 표는 섰고, **정책이 유일한 관문이다**(실측)

`library_reactions` 를 포함한 B 표 다섯은 **RLS 켜짐 · 정책 0** 이다.
그런데 **`anon`·`authenticated` 테이블 권한이 남아 있다** — `library_items` 는 A 에서
`REVOKE … FROM public` 까지 했는데 **B 표 다섯은 안 했다.**

물려 봤다(트랜잭션 안, 롤백):

| 잰 것 | 값 |
|---|---|
| `postgres` 가 보는 행 | 1 |
| `authenticated` — 정책 0 | **0** |
| `anon` — 정책 0 | **0** |
| **`authenticated` — 정책 하나 만들면** | **1** ← 변이 성립 |

**지금은 막힌다.** RLS 켜짐 + 정책 0 이 모든 행을 거부하므로 GRANT 가 남아 있어도 0행이다.
**그러나 그 GRANT 는 잠들어 있는 것이지 없는 것이 아니다** — 정책을 **하나** 만드는 순간
그 표가 곧바로 열린다(위 넷째 줄). 즉 **B 를 지을 때는 정책이 유일한 관문**이고,
A 처럼 「권한도 닫고 정책도 닫는」 두 겹이 **아니다.**

→ B 발주 시 **첫 줄이 `REVOKE … FROM public, anon, authenticated`** 여야 한다.
   그러면 A 와 같은 두 겹이 되고, 정책을 잘못 써도 한 겹이 남는다.

### 전체공개시 사진 — **「전체공개」가 로그인 밖까지다**(판정 필요)

`library_can_view` 의 갈래 순서에서 `public` 은 **로그인 검사보다 위**에 있다:

```
if r.hidden_at is not null then …            -- 가려진 것 먼저
if r.tier = 'public' then return true;       -- ★ 여기서 끝난다
if v_uid is null then return false;          -- 로그인 검사는 그 아래
```

**뜻**: 전체공개 자료는 **로그인하지 않은 사람도 본다.** 지금은 목록에 제목·설명만 서므로
그것이 곧 「공개 글 한 줄」이었다. **사진을 인라인으로 걸면 그 사진이 인터넷에 공개된다** —
검색엔진·링크 공유·이미지 저장 전부 포함이다.

이것은 결함이 아니라 **`public` 이라는 등급의 정의 그대로**다. 다만 **올리는 사람이
그 뜻을 알고 고르는가**는 다른 문제다. 지금 올리기 화면의 동의 문구는 파일이 공개된다는
말은 하되 **로그인 밖까지라는 말은 하지 않는다.**

**판정거리 셋(문안은 한 글자도 짓지 않았다 — 최박사 결재 사항):**

1. 전체공개 사진을 **로그아웃 상태에서도** 인라인으로 보일 것인가, **로그인한 사람에게만** 보일 것인가
   (등급은 그대로 두고 **사진만** 로그인 위로 올릴 수 있다)
2. 올리기 화면 등급 선택에 **「전체공개」의 뜻을 적을 것인가**
3. **썸네일만** 낼 것인가 원본을 낼 것인가 — 50MB 원본이 목록에서 내려오면 목록이 무거워진다(권고: 썸네일)

### 어느 것도 뼈대를 건드리지 않는다

| 뼈대 | 셋을 다 해도 |
|---|---|
| 표 직접 SELECT 0 · RPC 로만 읽는다 | 그대로 — 사진 경로도 RPC 가 낸다 |
| 목록이 주소를 내지 않는다 | 그대로 — **㉮ 는 경로를 내지 주소를 내지 않는다**(피드와 같다) |
| 판정은 `library_can_view` 하나 | 그대로 — 반응도 같은 함수를 부른다 |
