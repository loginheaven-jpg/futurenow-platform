# 감리 이행 — 기본 권한 잠금 · 여섯 훑기 · 하네스 둘

**화면은 건드리지 않았다.** 잠금과 조항 일이다. 서가 0 · 실기수 무접촉.

---

## 하나. 목록을 외우지 않고 `pg_default_acl` 을 읽는다

**지휘부 판정 그대로다** — 「표를 걷어라」도 「표와 함수를 걷어라」도 틀리다.
**목록을 코드에 적으면 다음 종류가 나올 때 또 놓친다.** 이번에 **함수**가 그랬다.

### 실측 — 종류 셋 × 소유자 둘

| 소유자 | 종류 | 기본 권한 |
|---|---|---|
| `postgres` | **표** | `anon=arwdDxtm · authenticated=arwdDxtm` |
| `postgres` | **함수** | `anon=X · authenticated=X` |
| `postgres` | **시퀀스** | **`anon=rwU · authenticated=rwU`** |
| `supabase_admin` | 표 · 함수 · 시퀀스 | 같은 모양 |

**지휘부가 짚은 셋째가 실재한다.** `public` 에 시퀀스는 **0개**라 지금은 무해하나,
누가 `serial` 컬럼을 하나 쓰는 순간 시퀀스가 생기고 **거기에 권한이 자동으로 붙는다.**

### 잠금 — `tests/defaultPrivileges.integration.test.ts`

| 무엇을 묻나 | 어떻게 |
|---|---|
| 종류 목록 | **박지 않고 `pg_default_acl` 을 읽어서 그 자리에서 만든다**(따라가야 하는 값 ⑴) |
| 소유자 | **둘 이상인지** 확인한다 — 하나로 줄면 잠금도 좁아진다 |
| 표 | 서가 표 **여섯**이 두 역할 모두에서 걷혔는가(`has_table_privilege`) |
| 함수 | `library%` 중 **일부러 연 여섯**을 뺀 나머지에 `anon` 실행권이 없는가 |
| **시퀀스** | `public` 의 모든 시퀀스에 두 역할 권한이 없는가 — **지금 0개여도 잠금은 선다** |
| **전제** | 새로 만들면 **실제로 붙는지**를 트랜잭션 안에서 확인한다(롤백) — 안 붙으면 위 전부가 «막을 것이 없는 초록» 이다 |

### 물려 봤다

| 변이 | 심어졌나 | 결과 |
|---|---|---|
| 표 하나에 `authenticated` SELECT 되돌림 | true | **레드** |
| **`serial` 컬럼을 하나 만든다**(셋째 종류) | anon 이 시퀀스를 **쓸 수 있다**=true | **레드 2건** |
| 원복 | 시퀀스 0 · 권한 걷힘 | **초록 3/3** |

## 둘. 여섯 잠금을 「있는가」 / 「그것뿐인가」로 훑었다

**찾는 법이 정확했다.** 「있는가」로 묻는 자리 **열둘**을 뽑아 하나씩 봤다.

| # | 잠금 | 무엇을 묻고 있었나 | 판정 |
|---|---|---|---|
| 1 | 목록 정렬 | ~~포함하는가~~ → **절 전체가 그것뿐인가** | **이미 조였다**(어제) |
| 2 | 화면 정렬 | `sort(` 가 **없는가** | 「없는가」는 「있는가」의 반대라 같은 약점이 없다 |
| 3 | 크기 그리기 | 막대·게이지가 **없는가** | 〃 |
| 4 | 가리기 한 자리 | 화면·코어가 **안 가리는가** | 〃 |
| **5** | **규칙이 하나인가** | ~~어떤 갈래가 있는가~~ → **갈래가 넷을 넘지 않는가** | **★ 조였다** |
| 6 | 밖에서 `author_id` | 정확한 문장이 **있는가** | 문장이 곧 동작이라 유지 |
| **7** | **목록 이름 가리기** | ~~부르는가~~ → **부르고 + 원본을 내지 않는가** | **★ 조였다** |
| 8 | 표 다섯 revoke | 문장이 **있는가** | **사실 검사는 §하나 로 옮겼다**(`has_table_privilege`) |
| 9 | 함수 두 겹 | 이름 집합에 **있는가** | 〃 |
| 10 | anon 이 둘뿐 | **길이가 2인가** | 이미 「그것뿐인가」 |
| 12 | 롤백 전수 | **빠진 것이 0인가** | 이미 「그것뿐인가」 |
| **13** | **신고 `is_admin`** | ~~부르는가~~ → **`if not … then raise` 로 막는가** | **★ 조였다** |
| 14 | 신고자 없음 | 타입에 **없는가** | 「없는가」 |
| 15~20 | 문안 | `toBe` 로 **글자 그대로인가** | 이미 「그것뿐인가」 |

**조인 셋을 물려 봤다** — 지휘부가 든 예 ②가 그대로 재현됐다:

| 변이 | 심어졌나 | 결과 |
|---|---|---|
| `is_admin` 을 **부르되 `perform` 만 하고 결과를 버린다** | 호출은 **여전히 있다** | **레드** |
| `mask_name` 을 **부르되 원본 `u.name` 을 낸다** | 1 | **레드** |
| 이름 가리기에 **영문 갈래를 하나 더한다**(예외) | 1 | **레드** |
| 원복 | — | **초록 19/19** |

**「부르는가」로 물었으면 셋 다 초록이었다.**

## 셋. 하네스 조항 둘

### 계열 ⑫ — 긴 것을 한 줄에 실어 보내지 않는다

전달 사고 **여섯 중 셋이 같은 자리**였다(정규식 제어문자 · `grep` 자모 범위 · heredoc EOF).
셋 다 **긴 것을 한 줄에 실어 보낸 자리**다.

**처방**: 파일에 쓰고 **경로만** 넘긴다 · 긴 정규식은 **문자열 메서드로** 간다 ·
찾는 것은 **문자 범위가 아니라 찾는 문자열 그대로** 쓴다.

**「잦은 것이 맞다」는 여전히 맞다** — 다만 **넷째부터는 도구가 잡았고 처음 셋은 사람이 눈으로 잡았다.**

### 계열 ⑬ — 「있는가」로 묻는 잣대는 전부 의심 대상이다

> **있다는 것은 그것뿐인가를 말하지 않고, 그것이 이기는가를 말하지 않는다.**

겪은 셋이 전부 이 모양이다:
`order by created_at` 이 포함돼도 **앞에 다른 키가 있을 수 있다** ·
게이트 호출이 포함돼도 **결과를 무시할 수 있다** ·
문장이 포함돼도 **사실이 아닐 수 있다**.

**처방은 하나 — 절 전체 · 반환값 · 사실 자체로 조인다. 그리고 반드시 심어 본다.**
