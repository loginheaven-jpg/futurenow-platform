**최박사 결재 아홉 · 지휘부 비판 검토 반영분**. 착수전실측 7항을 먼저 재고 시작했다.

## 1. 착수 전 실측 — 7항 (발주 §3)

| # | 잰 것 | 값 |
|---|---|---|
| ⑴ | B 표 다섯 권한 | **전부 `anon=SELECT · authenticated=SIUD`** · 정책 0 · RLS 켜짐 |
| ⑵ | **default privileges 가 참인가** | **참이다** — 임시 표를 만드니 `anon=SI · authenticated=SIUD` 가 **자동으로 붙었다**(롤백) |
| ⑶ | 피드 RPC 시그니처(정본에서) | `feed_react(uuid,text)→text[]` · `feed_comment_create(uuid,text)→uuid` · `feed_comment_list(uuid)→TABLE(...)` · `feed_comment_delete(uuid)→void` · `feed_emojis()→text[]` |
| ⑷ | `library_can_view` | `(p_id uuid)→boolean · SECURITY DEFINER` — **부를 수 있다** |
| ⑸ | **묘비가 필요한가** | **아니다** — FK 가 이미 `CASCADE`(자료를 지우면 댓글·반응·신고가 함께 사라진다). `comments.author_id` 는 `SET NULL` |
| ⑹ | 로그아웃이 서가 RPC 를 부를 수 있는가 | `library_list`·`library_can_view` **가능**(목록이 이미 그렇게 돈다) |
| ⑺ | 새 문안에 금지 기호·어휘 | **0 / 11** |

## 2. ★ 첫 줄이 권한이었고 — **내가 반만 걷었다**

발주서 §0 이 셋을 적었는데 **③이 그 자리에서 값을 냈다.**

| # | 무엇 | 값 |
|---|---|---|
| ① | A 가 B 표를 걷었나 | **안 걷었다.** A 파일에 `revoke` 가 한 줄도 없다(`library_items` 에만 있다) |
| ② | 함수 권한이 별개인가 | **그렇다. 그리고 함수에도 default privileges 가 있다** — `pg_default_acl` 에 `anon=X` |
| ③ | 걷혔는지 재는 잠금 | **이것이 결함을 잡았다** |

**내 본문은 `revoke … from public` 만 했다.** 그것은 PUBLIC 만 걷고, **`anon` 에 따로 붙은 것은 못 걷는다.**
`has_function_privilege('anon', …)` 이 **열둘 중 열에 `true`** 를 냈다.

**A 는 두 겹으로 걷었다** — `from public` **과** `from anon`(`library_v2_a.sql` 255·271행).
그 형태를 따라 보정분(`20260903090002`)을 냈다.

**대조군이 진단을 세웠다**: A 의 `library_can_upload`·`library_hide` 와 피드의 `feed_comment_list` 는
ACL 에 **`anon` 이 없고**, 내 새 함수만 **있었다.**

**보정 뒤**: `anon` 이 부를 수 있는 `library` 함수는 **여섯**(그중 B 가 더한 건 `library_comment_list` 하나) ·
표 다섯 **전부 걷힘** · `library_mask_name` 은 **`service_role` 만**.

## 3. ★ 롤백 예행이 함수 둘을 잡았다

본문에 **나중에 더한** `library_my_reactions`·`library_report_mine` 을 롤백에 옮겨 적지 않았다.
**서가 A 에서 `service_role` 이 빠진 것과 정확히 같은 형태**이고, 발주 §4 가 「처음부터 막는다」고 한 그 자리다.

**예행이 없었으면 롤백이 반만 되돌렸을 것이다.** 이제 잠금이 **본문 생성 함수와 롤백 `drop` 을 전수 대조**한다 — **12 대 12**.

### 예행 결과(§4 ㄷ)

| 잰 것 | 값 |
|---|---|
| ① 시그니처 원문대로 | **true** |
| ② 본문 원문대로(공백 접어) | **true** |
| ③ 권한 원문대로 | **true** — `anon,authenticated,postgres,service_role` |
| ④ B 함수 남은 것 | **(없음)** |

## 4. 이름 가리기 — 층 하나 · 규칙 하나

**가리기는 `library_mask_name` 하나에만 산다.** 부르는 쪽은 「보는 사람이 로그인했는가」만 넘긴다 —
**가려지지 않은 이름이 애초에 브라우저로 가지 않는다.**

**규칙도 하나다**: 앞 한 글자를 남기고 나머지를 가리되 **마지막 한 글자는 남긴다.**

| 모양 | 결과 |
|---|---|
| 한 글자 | 그대로(가리면 남는 것이 없다) |
| 두 글자 | `김미` → `김*` |
| 세 글자 | `김민수` → `김*수` |
| 네 글자 | `남궁민수` → `남**수` |
| 영문 | `Sarah` → `S***h` |
| 공백 든 것 | `Kim Minsu` → `K*******u` |

**여섯이 한 규칙에서 떨어진다. 예외가 없다**(결재 ⑻ — 예외는 나중에 낡는다).

### 실물 대조 쌍

| | 이름 |
|---|---|
| 로그아웃 | **가려짐** |
| 로그인(대조군) | **그대로** |

**★ 한 번 헛돌았다.** 예행이 `auth.uid()` 를 못 세워 **둘 다 가려져 보였고**, 그대로 읽었으면
「로그인인데 가려진다」는 **없는 결함**을 보고할 뻔했다. `request.jwt.claims` 를 실제로 세우자 갈렸다 —
**계열 ⑦: 도구가 대상을 재지 못했다.**

## 5. ★ 순위 잠금이 한 번 놓쳤다

`order by cm.n desc, i.created_at desc` 를 심었더니 **초록**이었다.
잣대가 「`i.created_at desc` 를 **포함**하는가」와 「낱말 셋이 없는가」만 물었기 때문이다.

**포함은 정렬키가 하나임을 말하지 않는다.** 절 전체가 그것뿐인지로 조이자 붉어졌다.
**감리 ① 때와 같은 형태**(한 방향만 재는 자)이고, **물려 보지 않았으면 몰랐다.**

## 8. 안 한 것

**태그**(§1 B-4 · 답이 없다) · **알림**(코어 소관 · `alerts` 부르는 코어 메서드 0건) ·
**대댓글**(묘비 규칙이 따라온다) · **신고 자동 처리**(코드가 판정하지 않는다) ·
**반응 수 정렬**(§0-2) · **목록에 주소·경로**(§5).

**태그 표 둘은 빈 채로 남고 `plan.md` 에 사유를 남겼다** — 「쓰지 않는 표가 왜 있나」로 지우지 않게.
**권한은 다섯을 한자리에서 걷었다** — 쓰지 않는 표라고 남겨 두면 그것이 섞이는 자리다.
