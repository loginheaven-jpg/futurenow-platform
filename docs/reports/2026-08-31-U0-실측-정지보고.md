## 1. 어긋남 넷

### ⑴ `/home` 은 헤더를 **직접 그리지 않습니다** → 19 → 18

`src/app/home/page.tsx` 에서 `AppHeader`·`SiteGnb` 는 **9행 주석에만** 있습니다.

```
9://   `AppHeader` → `SiteGnb variant="member"` + `MenuSheet`, `RoleCard` → `SiteRoleCard`,
```

`import` 문은 하나도 없습니다. **평범한 `grep` 이 주석을 함께 센 것**으로 보입니다 —
`/` 와 `/about` 의 `SiteGnb` 도 같은 이유(주석 한 줄)로 잡혔습니다.

### ⑵ 부품 이름이 셋 어긋납니다

| 라우트 | 발주 | **실측(import 문)** |
|---|---|---|
| `/` | SiteGnb | **PublicGnb** |
| `/about` | SiteGnb | **PublicGnb** |
| `/home` | AppHeader + PublicGnb | **직접 import 없음** |

### ⑶ ★ **잠금이 7개 라우트를 그냥 통과시킵니다** — 이것이 핵심입니다

`page.tsx` 의 import 만 재면, **한 단계 아래 화면이 그리는 것**은 안 걸립니다.

```
/coach                      CoachInfoGate.tsx : AppHeader
/home                       HomeScreen.tsx : SiteGnb · ConsentGate.tsx : AppHeader
/home/assessments           AssessmentsScreen.tsx : SiteGnb
/my/cohorts/[cohortId]      CohortHomeScreen.tsx : SiteGnb
/preview/console            ConsoleHome · CreateCohort · CohortDetail · AllCohorts : AppHeader
/preview/entry              CodeInput · CohortPreview · AuthGate · StartGuide : AppHeader
/preview/site               SiteGallery.tsx : SiteGnb
```

**`/home` 이 그 예입니다.** 발주가 예외로 등록하려던 화면인데, 잠금은 그것을 못 봅니다 —
예외로 넣어도 **아무것도 막지 않는 예외**가 되고, 나중에 지워도 레드가 안 납니다.
*목록이 비면 완성* 이라는 지표가 **`/home` 을 지운 순간 거짓이 됩니다.**

### ⑷ 무헤더 13개 중 하나가 무헤더가 아닙니다

`/my/cohorts/[cohortId]` 는 `CohortHomeScreen.tsx` 가 `SiteGnb` 를 그립니다.
나머지 **12개는 실측과 일치**합니다.

그리고 발주 목록에 **없던 무헤더 7개**가 더 있습니다 — 대부분 콘솔입니다:

```
/admin  /admin/approvals  /coach/cohorts  /coach/new  /coach/cohort/[cohortId]
/preview  /preview/report
```

콘솔 화면 다수가 **지금 헤더가 없다**는 사실은 U-3 범위에 영향이 있어 함께 올립니다.

## 3. 판단 필요 — 셋

**Q1. 잠금의 대상을 무엇으로 하시겠습니까.**
`page.tsx` 만 재면 (2)의 7개가 새고, 그중 `/home` 은 발주가 예외로 잡으려던 화면입니다.
제안: **`src/app` 아래 모든 `.tsx`** 를 재고, 헤더 부품 파일 자신(`AppHeader`·`SiteGnb`·
`PublicGnb`)과 껍데기(U-1 이후의 `layout`)만 면제합니다. 그러면 예외 목록이
**18 → 25**(라우트 기준 18 + 7)로 늘지만 **지표가 참이 됩니다.**

**Q2. `/preview` 계열을 예외로 둘지 아예 대상에서 뺄지.**
그 계열은 파일 첫 줄에 *운영 라우트 아님* 이라 선언돼 있습니다(`PROTECTED_PREFIXES` 밖).
껍데기 규약의 대상이 아니라면 **면제**가 맞고, 그러면 (2)가 7 → 4로 줄어 예외는 22개가 됩니다.
**제 안은 면제**입니다 — 시안 갤러리에 운영 껍데기를 강제하면 갤러리가 못 씁니다.

**Q3. 무헤더 목록을 실측대로 고쳐 박을까요.**
`/my/cohorts/[cohortId]` 를 빼고, 콘솔 7개를 더하면 19개입니다.
