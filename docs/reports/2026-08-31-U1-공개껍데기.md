## 1. 최박사가 짚으신 것 — 틀이 없었다

실체가 밝혀진 그대로였습니다. **색과 글자는 제대로 쓰고 있었고, 없는 것은 틀**이었습니다.
`/library` 가 이제 상단바와 푸터를 갖습니다(캡처 확인).

```
/ /about /library /news /contact /recruit /login /reset /reset/confirm
  → 전부 gnb=1 · foot=1 (실브라우저 HTML)
```

rename 41건 · 걸리는 참조 셋은 전부 import 한 줄

## 3. ★ ISR 무손상 — **미리 안 것과 잰 것은 다르다**

```
/         ○  Revalidate 5m      (전과 같음)
/recruit  ○  Revalidate 5m      (전과 같음)
/about    ○                      (전과 같음)
```

껍데기가 서버에서 `cookies()` 를 부르지 않기 때문입니다 — ADR-138 방식을 **자리만 옮겼습니다.**
근거를 `PublicShell` 머리에 적었고, **한 프레임 깜빡임이 함께 옮겨진다**는 사실도 적었습니다.
이미 배포되어 실기기에서 확인된 동작이라 **새 결함이 아니고**, 적어 두지 않으면 다음 사람이
새 결함으로 오해합니다.

---

## 4. ★ 라우트 표 대조 — **조건 하나가 깨졌습니다**

```
47행 → 47행 · 렌더 방식/캐시 변경 0
사라진 URL: /recruit/opengraph-image.png
새   URL: /recruit/opengraph-image-squcfl.png
```

Next 가 정적 메타데이터 라우트에 **파일 경로에서 뽑은 해시**를 붙이고, 이동이 그 해시를 바꿉니다.

**발주 조건 「URL 이 하나도 안 바뀌었는지」가 여기서 깨졌으므로 그대로 보고합니다.**
새 스크레이프는 정상이지만 **옛 URL 을 물고 있는 카톡 캐시는 404** 가 됩니다 —
`/recruit` 은 카톡으로 도는 링크라 그냥 넘길 자리가 아닙니다.

**고치는 길 둘** — ⑴ `next.config` 에 옛 URL → 새 URL 리다이렉트 한 줄
⑵ `/recruit` 만 그룹 밖에 두기(그러면 껍데기를 못 씀). **⑴ 을 권하나 손대지 않았습니다.**

## 5. `/join`·`/signup` 보류 — 코드에 닿아 보니 달랐습니다

지휘부가 (가) 함께 이관을 승인하셨으나, 그 `AppHeader` 는 **껍데기가 아니었습니다.**

```
CodeInput      <AppHeader variant="sub" title="참여 코드" />
ProfileForm    <AppHeader variant="sub" title="잠깐, 몇 가지만" subtitle="…" />
AuthGate       <AppHeader variant={onBack ? 'sub' : 'flow'} title=… onBack={…} />
```

**단계 제목**과 **뒤로 제어**를 함께 싣고 있습니다. 걷으면 내용과 동작이 사라집니다.
제목은 기존 `t-h1` 관용구로 옮길 수 있으나(`/library`·`/contact` 가 그 패턴입니다),
**뒤로 제어를 대신할 관용구가 저장소에 없습니다** — 만들면 불변식 20 입니다.

그래서 두 화면을 그룹 **밖에 두어 지금과 똑같이** 두었고(`git mv` 로 되돌림),
예외 목록에 **사유와 함께** 남겼습니다. 판정 주시면 잇겠습니다.

## 6. 도구가 또 덜 봤습니다

스캐너가 `layout` 을 따라가지 않아 U-1 뒤에 **`/`·`/about` 을 무헤더로 셌습니다.**
레이아웃 사슬을 함께 보게 고쳤습니다 — **덜 보면 없는 것을 없다고 한다**의 두 번째 사례입니다.

**헤더 두 줄 실측도 한 번 거짓말했습니다.** 첫 탐침이 껍데기 내부 사슬
(`PublicShell → PublicGnb → SiteGnb`)을 화면으로 세어 **거짓 5건**을 냈습니다.
면제 집합으로 다시 재어 **0** 을 확인했습니다.

---

## 7. 단언을 지우지 않고 옮겼습니다

화면 테스트가 재던 헤더·푸터 링크는 `PublicShell.test.tsx` 로 올리고,
화면에는 **더는 그리지 않는다**는 회귀 잠금을 남겼습니다.
지웠으면 *로그인 문이 있는가* 를 **아무도 재지 않게** 됐을 것입니다.

## 8. 만들지 않고 올리는 것 둘 (시안 대조)

- **모바일에 메뉴 여는 자리가 없습니다.** 버거는 `sheet` prop 이 있을 때만 뜨고 껍데기는
  넘기지 않습니다. 768 미만에서 내비는 **푸터만** 듭니다.
  **U-1 이전과 같은 동작이라 지어내지 않았습니다.**
- **`/library` 본문의 `처음으로` 링크**가 로고와 겹칩니다. *목적지를 바꾸지 말라*는 조항이라 두었습니다.

## 9. 수용 기준 대조

```
□ tsc 0 · eslint 0 error          → 0 / 0 errors (warning 2 · 5차 이전부터)
□ vitest 통과·스킵·총             → 1282 통과 / 69 스킵 / 총 1351
□ build 성공                      → 성공
□ ★ ISR 무손상                    → / · /recruit 5m 유지 (§3)
□ ★ 미인증 렌더 회귀 0            → 4폭 캡처 대조 · 눈 확인 (§1)
□ 무헤더 12 → 2                   → **13 → 5** (실측 · 보류 둘과 비공개 셋이 남는다)
□ 예외에서 빠지고 잠금 그린        → U-1 7 → 5 · 잠금 10 통과
□ 4폭 캡처 12화면                 → 11화면 × 4폭 = 44장 · 넘침 0
□ 헤더 두 줄 0                    → 0 (§6)
□ 보고서 push + ls-remote         → §11
□ 발주 조항 대 구현 표            → §0
```

`무헤더 12 → 2` 는 발주 초안의 수이고, **실측 기준은 13 → 5** 입니다.
남는 다섯은 `/admin/approvals`(콘솔 · U-3) · `/c/[code]/[session]` · `/c/[code]/values`(회원 · U-2) ·
`/preview` · `/preview/report`(면제 계열)입니다.
