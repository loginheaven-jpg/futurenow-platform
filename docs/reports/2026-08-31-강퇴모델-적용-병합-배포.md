## 1. 적용 — 되돌리는 문을 먼저 열었다

```
[되돌리는 문] 라이브에서 받았다 (is_admin 267B · decide_membership 1556B)
[롤백 예행] 적용됨 is_super_admin 생김 → 되돌림 정의 원문 일치 O → 라이브 무변경 O
[적용]     장부 {"version":"20260831110000","name":"admin_hold"}
```

### 검증 (실측 2026-08-31)

```
(1) 승급  loginheaven  status=individual valid_until=null decided_by=null note="운영자 상시 자격 — 잠금 대비"
          okaimhigh    status=individual valid_until=null decided_by=null note=(같음)
    판정  loginheaven → individual · okaimhigh → cohort        ← 새 단언대로
(3) is_super_admin  super=true · other=false
    대조 쌍 보류 후  super=true other=false                     O
    ★ pending 인 채로 is_admin=true                             O 조건이 옳다
(5) 재귀 없음  member_state(보류된 운영자)=expired
(6) 슈퍼어드민 대상 42501 · 일반 회원 보류(운영자) 통과
(7) banned_until=infinity → 되돌리면 null · 세션 4 → 0
(8) expired 저장 행 0 · 잠긴 계정 0
```

**문장 순서 확인**: 승급 두 행의 `decision_note` 가 마이그레이션 것이고, 그 시점에 이미
`is_admin` 이 조건을 보고 있었다면 **`pending` 이던 슈퍼어드민이 그 사이에 잠겼을 것**이다.
잠기지 않았으므로 순서가 지켜졌다 — 아래 변이가 그것을 한 번 더 못 박는다.

### 변이 — 안전망이 실제로 산다

```
변이 전 · 정의에 individual false          (기대 false)
대조군  현 조건 · pending super=true       (기대 true)
변이 후 · 정의에 individual true           ← 변이가 성립했다
변이 · pending super=false                 ← 승급이 없었다면 잠겼을 것이다
변이 · 승급된 둘  super=true other=true    O 안전망이 산다
```

**첫 변이 시도는 성립 확인 문자열의 공백이 달라 `false` 를 냈다.**
문자열이 아니라 **동작 대조**로 다시 쟀다 — 계열 ⑧ 이 저에게 걸린 자리다.

## 2. 못 쟀던 것을 쟀다 — 액세스 토큰 잔여 노출

QA 테스트 계정으로만 쟀고 **실계정은 건드리지 않았다.** 원상 복구까지 확인했다.

```
로그인 O · 토큰 잔여 3599초
  대조군(잠그기 전)  getUser=통과 · cohorts=1행 · feed_posts=1행
  보류 뒤(옛 토큰)   getUser=거절(500) · cohorts=0행 · feed_posts=0행
원상 복구 · banned=null O · status=individual O · note=null O
```

**앱 진입은 즉시 닫히고**(`currentUser()`·미들웨어가 둘 다 `getUser()` = GoTrue 왕복),
**`member_state` 를 보는 데이터 경로도 즉시 닫힌다.**

**첫 시도는 제 시험이 불완전했다** — `decide_membership` 의 셋 중 둘만 재현하고
`memberships` 를 빼서 `cohorts` 1행이 나왔다. **그것은 구멍이 아니라 잘못 잰 것**이었고
진짜 경로로 다시 쟀다.

### 그래도 **미실측으로 남는 것**

`member_state` 를 보지 않는 **51개 쓰기 정책의 자기·코치 경로**(ADR-152).
재려면 **실기수를 UPDATE 해야 해서 하지 않았다** — 경계가 측정보다 우선했다.
**확인하지 않은 것을 안전하다고 적지 않는다.**
