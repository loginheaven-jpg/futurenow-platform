## 2. ★ 조건 — **슈퍼어드민이 실제로 `pending` 이다**

```
loginheaven@gmail.com  role=admin  stored=pending  활성 세미나 없음 → member_state=pending
okaimhigh@gmail.com    role=admin  stored=(행 없음) 활성 세미나 있음 → member_state=cohort
```

*승인된 회원만 통과* 로 썼으면 **슈퍼어드민이 첫 희생자가 되고 그를 풀 사람이 없습니다.**
`<> 'expired'` 형태로 썼고, 그 문장을 **마이그레이션 주석과 테스트 양쪽**에 남겼습니다.
`pending 운영자가 통과한다` 를 **별도 테스트로** 두어 조건이 조용히 바뀌면 레드가 납니다.

---

## 3. 순서와 잠기는 창

파일은 **① 승급 → ② `is_super_admin` → ③ `is_admin` → ④ `decide_membership`** 입니다.
조건을 먼저 걸고 승급을 나중에 두면 **그 사이에 잠기는 창**이 생깁니다.
`toolGate` 가 **문자열 위치로 그 순서를 잽니다** — 순서가 뒤집히면 레드입니다.

승급은 **이메일이 아니라 id 로** 심고 **잡힌 수가 2가 아니면 `RAISE` 로 멈춥니다.**
`decided_by` 는 NULL 입니다 — 사람이 누른 결정이 아니라 마이그레이션이고,
아무 운영자 id 를 적으면 **기록이 그가 승인한 것처럼 거짓말을 합니다.**

---

## 4. 재귀 · 권한 — **셋 다 조회로 확인했다**

`is_admin` 이 `member_state` 를 부를 수 없습니다. **`member_state` 가 이미 `is_admin` 을 부릅니다.**
저장값을 직접 읽고, 그 등가(`ADR-147` 만료 산출 폐지에 기댄다)를 통합테스트가 잠급니다.

계정 잠금은 추측할 자리가 많아 전부 쟀습니다.

```
banned_until 컬럼      실재 (timestamptz)
auth.users             supabase_auth_admin 소유 · RLS 켜짐 · 정책 0개
postgres               rolbypassrls = true    → DEFINER 로 쓸 수 있다
```

**보류가 아닌 결정으로 바꾸면 잠금을 함께 풉니다.** 풀지 않으면 상태만 돌아오고
로그인은 계속 막혀 *되돌렸는데 안 된다* 가 남습니다. 테스트가 **푸는 것까지** 잽니다.

로그인 번역은 `user_banned`(auth-js `ErrorCode` 에 실재 — 정본 확인)를 봅니다.
**코드가 이기고 메시지는 보조**입니다 — 문자열로만 재면 서버 판이 바뀔 때 조용히 깨집니다.

---

## 5. 보고할 것 셋

**⑴ 지휘부 검증 지시 한 줄이 실측과 어긋납니다.**
*운영자 둘의 `member_state` 가 `individual` 인지* — **한 명은 `cohort` 가 나옵니다.**
활성 세미나에 있고 판정 우선순위가 `held > expired > cohort > 저장` 이기 때문이며 **정상**입니다.
단언을 *저장이 `individual` 이고 판정이 `expired`·`pending` 이 아니다* 로 바꿨습니다.

**⑵ 보류를 거는 화면이 없습니다.**
오늘 UI 는 `individual`·`held` 뿐이라 확인 화면을 붙일 자리가 없습니다.
그래서 내용을 **순수 모듈**(`holdConfirm.ts` · 8 테스트)로만 냈고 **버튼·배선은 만들지 않았습니다.**
지시 주시면 잇겠습니다.

**⑶ 문구 둘이 다릅니다.**

```
로그인       회원자격이 보류되었습니다. 운영자에게 문의하십시오.
내 정보·글쓰기 이용이 보류되었습니다. 운영자에게 문의해 주십시오.
```

**둘 다 최박사 원문**이고 자리가 다릅니다. **임의로 합치지 않았습니다.**

## 6. 확인 화면 — 넷을 다 담았다

`holdConfirm.ts` (지휘부 초안 · **최박사 확정 전** — 파일과 테스트가 그 사실을 표시).

대상 · 잃는 것(운영자면 문장이 다르다) · **근거 메모 필수** · 되돌리는 법.
**공백만 적은 것은 막습니다** — 통과시키면 규칙이 형식만 남고,
사람이 *스페이스 하나를 누르는 법*을 배웁니다. 그것이 이 확인이 막으려던 바로 그 일입니다.
**일반 회원 보류에도 같은 확인**을 겁니다. 서버 가드를 대신하지 않습니다.
