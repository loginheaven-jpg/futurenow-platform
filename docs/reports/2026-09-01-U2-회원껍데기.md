## 1. 요구하신 여섯

**① 표 잠금이 무는가** — 변이 둘로 확인.

```
라우트 하나를 표에서 뺌 → 레드 «표에 없는 라우트»
flow 에 메뉴를 닮       → 레드 «일부러 없앤 출구가 되살아난다»
```

**② flow 둘에 메뉴가 안 달렸는가** — `menu: false` + 잠금 + **대조군**(그 밖에는 메뉴가 있다).
`MemberShell.test.tsx` 가 `/my/values` 렌더에 `site-gnb__burger` 가 없음을 잰다.

**③ 모바일 390 메뉴** — **회원 열림 · 공개 미완.**
`/account`·`/home` 390 캡처에서 헤더 하나 + 햄버거 확인.
공개는 §6.

**④ 무접촉 diff 0**

```
ConsentGate.tsx 0 · MemberHome.tsx 0 · CheckinPrompt.tsx 0 · AppHeader.tsx 0
```

`AppHeader` 를 안 고친 것이 요점입니다 — 메뉴 단추를 **기존 `action` 슬롯**에 넣었습니다.

**⑤ `/join` U-4 복귀 · `/signup` 실측**

```
/join    step === 분기 여덟 (resolving code preview auth start profile runner done) → U-4
/signup  step 상태 0 · AuthGate 하나                                              → U-2 에 남음
```

`/signup` 은 표가 들고 **공개 껍데기가 같은 표를 읽어** 제목 바를 그립니다.
`flow` 라 **푸터도 안 그립니다** — 푸터의 링크가 곧 출구입니다.

**⑥ 무헤더 · 헤더 두 줄 · 캡처**

```
무헤더 5 → 5   (회원 13이 헤더를 얻었고 /c/* 둘이 새로 대기로 남는다)
헤더 두 줄 0   (실브라우저 <header> 1 · 공개 5라우트 + 인증 8화면)
```

앞 보고의 제목 다섯이 틀렸습니다(터미널이 한글을 깨뜨린 출력을 옮겨 적었습니다).

| 앞 보고 | **실물** |
|---|---|

## 3. ConsentGate — 면제가 아니라 **바깥**

판정대로 `(member)/layout` 이 **동의 미완이면 껍데기를 두르지 않습니다.**
고치는 자리가 부품이 아니라 layout 이 되어 **`ConsentGate` diff 0** 이고,
§2(걷기)와 §4(무접촉)가 함께 지켜집니다. 시트 조회도 그때는 돌지 않습니다.

잠금은 **문자열이 아니라 사실**을 잽니다 — layout 에 그 분기가 있는가.

## 5. `/c/[code]/*` — 표에 두되 「껍데기 없음」

빼면 잠금이 그 라우트를 안 세고 **다음 사람이 왜 없는지도 못 봅니다.**
사유를 값 옆에 적었고, 실측을 붙였습니다.

```
/c/[code]/[session]  redirect 2 + <p> 셋 (예: `코드를 찾을 수 없어요.`)
/c/[code]/values     redirect 2 + Notice 둘
```

**그리는 것이 있으므로 제목 문안이 필요하고, 참여자가 읽는 문장이라 최박사 결재입니다.**

---

## 6. 미완 하나 — 공개 모바일 메뉴

배선은 열어 두었습니다(`PublicGnb` 가 `sheet` 를 받아 `SiteGnb` 로 넘깁니다).
막힌 곳은 **문안**입니다.

```
MenuSheet  name: string        (필수)  ← 익명 방문자에게 이름이 없다
           MenuGroup.title     (필수)  ← 공개 내비 묶음에 이름이 없다
```

`SITE_ORG` 를 이름으로 쓰는 안까지 만들어 봤으나 **묶음 제목이 또 남았고**,
둘 다 지어내면 불변식 20 이라 **멈췄습니다.** 회원 쪽 시트는 이 회차에 껍데기로 올라갔습니다.

→ **판단 필요**: 공개 시트의 머리 이름과 묶음 제목. 또는 공개는 시트 대신 다른 방식.
