## 1. ★ 「합친다」가 아니라 「라우트는 둘, 조립은 하나」입니다

**회기 홈 라우트를 지울 수 없습니다** — `returnTo` 화이트리스트에 등재돼 있어(ADR-176)
지우면 **통과한 딥링크가 404** 가 됩니다. 회기가 둘 이상인 사람도 그 회기를 볼 자리가 필요합니다.

그래서 **조립을 `dashboard.tsx` 로 뽑고 두 화면이 같은 함수를 부르게** 했습니다(사본 아님 · 불변식 23).

### 1.1 살아남는 주소가 `/home` 인 이유 셋 (의논 §1 실측)

| | |
|---|---|
| ⓐ | **회기가 0인 사람**(가입 대기·개인 회원·종료자)은 회기 홈 라우트에 머물 수 없습니다 — 그들의 유일한 집이 `/home` 입니다 |
| ⓑ | **파라미터 없는 착지가 반드시 하나 필요합니다** — `redirect('/home')` 14곳 등이 **회기 id 를 만들 수 없는 상태**에서 홈으로 보냅니다. **20여 곳을 안 고쳤습니다** |
| ⓒ | 역할 카드 「내 회기로 가기」의 **자기참조**가 사라집니다 |

### 1.2 겸직자는 카드 여럿을 그대로 봅니다

ADR-173 의 case 3·4 를 여기서 뒤집지 않았습니다.
판정은 **파생하지 않고 표시로** 합니다(`RoleTarget.participant`) — `href` 로 유추하면 U-4 형태입니다.

**`landingFor` 에서 참여자 분기가 사라졌습니다** — 홈이 곧 그 화면이라 보낼 곳이 자기 자신입니다.
**지시 case 1 은 그대로 지켜지고 왕복이 하나 줍니다.**

## 2. 바꾼 것

| | 무엇 |
|---|---|
| ⑴ | 「나의 기록」 네 줄 → **버튼 셋**. **서가는 회기와 무관해 시트로** 갔습니다 |
| ⑵ | 동행 피드에 **내가 마지막으로 쓴 날** 병기. 쓴 적이 없으면 **옛 곁말 그대로**(없는 말을 짓지 않습니다) |
| ⑶ | 옛 **「진단 카드」를 없앴습니다** — 그 안의 세 링크가 전부 버튼과 중복이었습니다 |
| ⑷ | **시트에 출구**를 냈습니다 — 서비스 현관·내 홈·콘솔·본부 |
| ⑸ | `/home` 고유 다섯(소식·내 세미나·내 리포트·코드 참여·운영)을 **시트와 역할 카드로** |

**ADR-80 순서 규칙은 지킵니다** — 사전 미완이면 진단 버튼만 오늘 카드 위로 올리고
**버튼 줄에서는 뺍니다**(같은 문이 두 번 서지 않게).

### 2.1 ★ 회차 칩은 **한 글자도 안 고쳤습니다**

지시(「참여한 회차 색깔변화, 갈무리완료하면 체크」)를 `SessionChipStrip` 이 **이미 그대로** 그리고 있었습니다.

```
done    네이비 면 + 체크 SVG      ← 갈무리 완료
current 골드 면                   ← 지금 열린 회차
open    기본 면                   ← 열렸던 회차
locked  점선 + 회색(감추지 않음)   ← 아직 안 열림
```

**의미색을 안 써서 불변식 9 안전**이고, 진행 표시는 막대가 아니라 **불변식 11 안전**입니다.
**새 부품 0**(불변식 20).

## 3. ★★ 함께 사라진 것 — 중복 둘과 표기 오류 하나

| | 무엇 | 어떻게 |
|---|---|---|
| 중복 ① | 운영자·인도자가 `/coach`·`/admin` 을 **한 화면에서 두 번** 봤습니다(역할 카드 + 「운영」 구획) | 「운영」 구획을 걷었습니다. **승인 대기 건수는 역할 카드로 옮겨 잃지 않았습니다** |
| 중복 ② | 회기 홈에서 `journey`·`feed`·`report` 가 **두 번씩** 있었습니다 | 진단 카드를 없애 하나로 |
| 표기 오류 | **「참여 중 1 · 완료 1」** — `N` 은 보관 포함 전체, `M` 은 **사전 진단 완료**라 **같은 회기를 두 번 셌습니다**(첨부 화면이 그 상태였습니다) | 그 줄이 시트의 「내 세미나」가 되면서 **수를 세지 않습니다** |

## 4. ★ 어휘 — 「회기」

**새로 지은 말이 아닙니다.** 최박사 원문이 이미 씁니다 —
*「참여자는 **회기** 기간동안 도구를 사용할 수 있다」*(`PARTICIPANT_LEAD` 주석).
그러니 **없던 말을 만드는 것이 아니라 쓰던 말로 맞추는 것**입니다.

`COHORT_WORD` 를 **단일 출처**로 두고 참여자 대면 회원 영역 **일곱 자리**를 바꿨습니다
(산출 : `rg "기수" src/app/\(member\) src/app/_lib/memberSheet.ts`).

### 4.1 ★ 바꾸지 않은 자리 셋 — **일부러입니다**

| | 왜 |
|---|---|
| **모집 랜딩**(`recruit/*`) · **갈무리 문항**(`session6`) | **결재 문안**입니다. 한쪽만 바꾸면 **신청할 때 본 말과 앱이 달라집니다** — ADR-171 ② 가 회차 이름에서 같은 이유로 멈춘 선례입니다 |
| **인도자 콘솔**(「기수 대시보드」·「이 기수」) | 지시 맥락이 참여자 홈이었습니다 |
| **회기명 데이터**(`예봄 2기`) | 문안이 아니라 **값**입니다 |

**잠금이 「일부러 안 바꿨다」를 적어 둡니다** — 다음 사람이 결손으로 보고 손대지 않게.
**전면 확정을 원하시면 발주를 청합니다**(산출 명령은 `membershipVocab.ts` 주석에 있습니다).

## 5. ★ ADR-180 — 날짜는 이미 있었습니다

`feed_posts.created_at` 에 있었고 **없던 것은 집계 경로**뿐입니다(앱은 테이블을 직접 안 봅니다 · 불변식 4).

★ **기존 `last_post_at` 과 다른 것입니다.** `feed_my_cohorts` 의 그 칸은 **author 필터가 없어**
「누구든 쓴 마지막 글」입니다(정본 확인). 새 함수는 `author_id = auth.uid()` 가 있어 **「내가 쓴」**입니다.
「나의 기록」 아래 버튼이므로 **내 것**이 맞습니다. **이름이 비슷해 섞이기 쉬워 잠금이 둘의 차이를 잽니다.**

### 5.1 실물로 물려 봤습니다 (롤백 트랜잭션 · 신원을 바꿔 가며)

```
작성자로 물음   → 2026-08-27 23:36:10.860669+00   (기대값과 일치)
남으로 물음     → null                             (누출 0)
```

적용 전에도 **롤백 안에서 세워 카탈로그로 확인**했습니다 —
반환형 `timestamptz` · `security definer` · `authenticated` 실행 가능 · **`anon` 불가**
(`revoke ... from PUBLIC` 은 anon 을 지우지 않습니다).

## 6. ★★ 배포해서 잡은 것 — 시트에 문이 둘이었습니다

배포하고 눈으로 보니 시트에 **「내 홈」과 「내 회기」가 나란히** 섰습니다.
**이제 둘이 같은 화면**입니다 — **이번 회차가 없앤 바로 그 결함**입니다.

홈이 대시보드일 때 「내 회기」를 빼도록 고쳤고, 판정은 `roleTarget` 한 곳에서 옵니다.
**겸직자에게는 그대로 둡니다**(그 사람의 홈은 카드 화면이므로).

### 8.1 ★ 하나가 처음에 안 물었습니다

「홈이 대시보드를 그리는가」를 **「이름이 있는가」로** 물었더니 **수입 줄에 남아** 부름을 지워도 초록이었습니다(⑬).
**부르는가**(`return renderCohortDashboard(`)로 바꾸자 붉어집니다.

### 8.2 ★ 옛 잠금 열둘을 **새 사실로 옮겨 적었습니다**(지우지 않았습니다)

특히 `MemberHome` 잠금 일곱은 **「사라졌는가」가 아니라 「옮겨 갔는가」**를 재도록 다시 썼습니다 —
지우면 그 문들이 다음 회차에 조용히 사라져도 아무도 모릅니다.

### 8.3 린트 억제 주석에서 두 번 걸렸습니다

`eslint-disable-next-line` 은 **바로 앞줄**에 있어야 듣습니다. 설명을 사이에 끼웠다가 끊겼고,
객체를 여러 줄로 펼치자 그 줄이 또 내려갔습니다. **둘 다 그 자리에서 잡았습니다.**

## 10. ★ 판단을 청합니다

1. **어휘 전면 확정** — 모집 랜딩·갈무리 문항·인도자 콘솔까지 「회기」로 갈지. **결재 문안이라 멈췄습니다.**
2. **회기가 둘 이상인 참여자** — 지금은 홈이 **활성 회기 하나일 때만** 대시보드입니다.
   활성이 둘이면 옛 카드 화면입니다. **기수 전환 UI 는 이번 범위에 넣지 않았습니다**(의논 §3-②).
3. **「참여한 회차」의 색 구분** — `open`(열렸던 회차)이 기본 면이라 구분이 약합니다.
   더 뚜렷하게 하려면 **디자인 변경**이라 결재를 청합니다(불변식 20).
4. **회기 0인 사람의 홈** — 지금은 옛 화면 그대로입니다. `getMyMemberState()` 를 홈으로 끌어올려
   `pending`·`held`·`individual` 을 구별하는 일은 **다음 회차**로 남겼습니다(의논 §3-③).
