## 2. 설계 — 판정을 한 곳에 뒀습니다

`landingFor(targets)` 가 `roleTargets` **산출을 그대로 셉니다.**
「막바로 갈 것인가」를 다른 데서 다시 정하면 카드 규칙이 바뀌는 날 한쪽만 고쳐집니다(불변식 23).

```
카드가 1장이고 폴백이 아니면 → 그 주소
그 밖에는                    → 홈에서 고른다
```

### 2.1 ★ 폴백은 거점이 아닙니다

기수 없는 참여자의 카드는 「체크 보기」 한 장입니다. **그것으로 건너뛰면 자기 자리가 아닌 곳에
떨어지고** `/home` 의 타일·소식·갈무리 재촉을 영영 못 봅니다.

그래서 `RoleTarget` 에 **`fallback` 칸을 명시로** 뒀습니다.
`href` 를 보고 「`/home/assessments` 면 폴백」이라 유추하면 **U-4 형태**입니다 —
*성질을 파생하지 말고 만든 자리가 표시한다.*
잠금이 그것을 잽니다 — **같은 주소라도 표시가 없으면 거점으로 봅니다.**

### 2.2 운영자에게 인도자 카드 — 없던 문을 만든 것이 아닙니다

운영자는 전부터 `/coach` 에서 **전 차수를 봅니다**(ADR-74). `role` 이 단일값이라
`role === 'coach'` 가 안 걸려 **홈에 그 길만 없었습니다** — 권한은 있는데 문패가 없었습니다.

`who` 는 이 카드에서 **언제나 「인도자」**이고(참여자 카드가 역할과 무관하게 「참여자」인 것과 같은 규칙)
`sub` 만 갈립니다 — 운영자는 자기 차수가 아니라 전부를 봅니다.

## 3. ★★ 배포해서 잡은 것 — 정적 잠금 열넷이 전부 초록인 채로 화면이 멈춰 있었다

처음에는 `/home?from=login` 으로 보내고 **`/home` 이 서버에서 `redirect()`** 하게 만들었습니다.
잠금 열넷이 초록이고 네 지표도 전항 통과였습니다.

**배포해서 실제로 로그인해 보니 「불러오는 중…」에서 멈췄습니다.**
`router.replace()` 로 들어온 뒤 서버 컴포넌트가 다시 리다이렉트하자
`loading.tsx` 가 뜬 채 클라이언트 라우터가 따라가지 못했습니다.
**`/home` 도 `/coach` 도 직접 열면 멀쩡했습니다** — 리다이렉트 그 자체가 멈춘 것입니다.

→ **리다이렉트를 없앴습니다.** `loginLandingAction` 이 갈 곳을 먼저 알려주고 **한 번만** 이동합니다.
부수 이득 셋 — URL 에 `?from=login` 이 안 남고, `/home` 이 분기를 안 갖고, 되돌아오는 사람이 홈에 머뭅니다.

**`returnTo` 는 묻지도 않습니다** — 링크로 정해진 목적지를 물어보면 그 답이 링크를 덮을 수 있습니다.

잠금도 뒤집었습니다 — 「표지를 읽는가」에서 **「홈일 때만 묻는가 · 홈에 리다이렉트가 없는가」**로.

### 3.1 자를 한 번 잘못 썼습니다

고친 뒤 다시 쟀더니 또 「불러오는 중」이 찍혔습니다. **그건 제 자가 이르게 잰 것**이었습니다 —
고정 시점에 읽었고 그 순간은 지나가는 상태였습니다.
**조건으로 기다리고 상한을 두자**(§11 기다림 조항) case 1·2 가 정상으로 나왔습니다.

```
O case2 인도자 → /coach                      그려짐  「콘솔 / 내 정보 / 진행 중 차수」
O case1 참여자 → /my/cohorts/d0623814…       그려짐  「QA 참여자 님의 여정 / PART 2 · REALITY」
O 「내 홈」 직접 → /home                       그려짐  「인도자 / 인도자 콘솔」
O returnTo=/feed → /feed  (0.8초)            그려짐
```

## 5. ★ 별건 — `returnTo=/home/assessments` 로 로그인하면 못 들어갑니다

**제 변경과 무관한 기존 결함**입니다. 이번에 재다가 발견했습니다.

```
returnTo=/home/assessments   ★ 60초 안 이동 → /login?returnTo=%2Fhome%2Fassessments
returnTo=/feed               이동함 (0.8초) → /feed
```

**같은 화면이 다른 길로는 멀쩡합니다** — 직접 열기 0.6초, 로그인 뒤 링크로 이동 0.6초.
**로그인 직후에만** 막힙니다.

원인은 `/home/assessments/page.tsx:28` 의 `if (!me) redirect('/login')` 로 보입니다 —
로그인 직후 **세션이 서버에 반영되기 전**에 그 화면이 미인증으로 보고 되돌립니다.

**제 변경 경로는 이것을 안 지납니다** — `returnTo` 가 있으면 `outcome.redirect === LOGIN_HOME` 이
거짓이라 액션을 부르지 않고, `router.replace(outcome.redirect)` 는 **변경 전과 글자 그대로 같습니다.**

**영향** : 「진단」 메뉴를 비로그인으로 누른 뒤 로그인하면 **그 자리에 멈춥니다.**
공개 메뉴 여섯 중 하나이므로 실사용 경로입니다. **별건 발주를 청합니다.**
