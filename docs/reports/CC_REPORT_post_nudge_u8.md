## 1. 착수 전 실측 — **막는 것이 셋이었다**

「독려를 붙인다」로 시작했는데, 흐름을 재 보니 **독려를 시작할 수 없는 상태**였다.

1. **인도자가 「누가 아직 안 했는지」 볼 수 없었다.**
   `buildCohortRoster` 는 **wave 를 안 가른다** — `listResponses` 에 `wave` 를 안 넘기므로
   **사전만 낸 사람도 「응답 완료」**로 들어간다. 마무리가 열려도 3숫자·3묶음은 마무리에 대해
   아무 말도 하지 않았다.
2. **주소가 사본 넷이었다.** `/join?cohort=…&wave=post` 를 참여자 홈·체크 허브·내 세미나·
   회기 대시보드가 **각자 손으로** 적고 있었다.
3. **딥링크가 로그아웃에서 조용히 끊겼다.** `getCohortMeta` 의 `null` 을 「가입자가 아니다」로만
   읽어 **코드 입력 화면으로 떨어뜨렸다.** `null` 의 뜻은 둘인데(비회원 / **미로그인** — RLS 가 막는다)
   하나로 읽은 것이다. **마무리 안내는 카톡으로 온다** — 받는 사람이 로그인돼 있을 이유가 없다.

## 2. 독려의 축 셋

| 축 | 어디 | 상태 |
|---|---|---|
| **참여자 화면 넷** | `/home` · 체크 허브 · 내 세미나 · 회기 대시보드 | 기존 — 개시하면 **저절로** 뜬다 |
| **인도자가 보내는 안내** | 회기 대시보드 「안내 보내기」 | **신규** |
| **미완료 명단** | 회기 대시보드 「마무리 체크」 구획 | **신규** |

**문안을 새로 짓지 않았다.** 인도자가 보내는 안내는 참여자 홈이 쓰는 확정 두 줄
(「마무리 체크가 열렸어요」 · 「{회기명} · 세미나를 마친 지금의 나를 담아 주세요.」)을
`_vocab/postNudge` 에서 **그대로 읽는다** — 카톡에서 읽는 말과 로그인해서 보는 말이 같아야 한다.
**새 문안은 버튼 라벨 「안내 보내기」 하나뿐**이고 **최박사 재가 대상**이다
(복사 피드백은 기존 「링크 복사됨 ✓」 재사용).

## 3. 실측 (배포본 `b7b44db` · QA 회기)

**① 로그아웃 딥링크** — `/join?cohort={id}&wave=post` 를 로그아웃 상태로 열었다.
- **전**: 코드 입력 화면(딥링크가 조용히 끊겼다)
- **후**: 「들어가기 / 처음이에요 / 계정이 있어요 / 이메일 / 비밀번호」 = **로그인 화면** ✓
  로그인하면 `resumeCohort` 가 다시 풀어 곧장 시작으로 간다.

**② 인도자 대시보드** — QA 회기에서 실제로 「마무리 체크 개시」를 눌렀다.
- 개시 **전**: 독려 구획 **없음** ✓
- 개시 **후**: 「마무리 체크 · **0 / 1 완료** · 아직 안 함 — **QA 참여자** · [안내 보내기]」 ✓
- 자리는 「그룹 리포트 보기」와 명단 사이. **새 부품 0**(이 화면이 이미 쓰는 `Group`·`Button`).

**③ 참여자 화면 셋** — 개시 직후 로그인해 확인했다.
| 화면 | 보이는 것 |
|---|---|
| `/home` | 「마무리 체크 · 이어 하기」 |
| `/home/assessments` | 「마무리 체크 · [QA] 검증 전용 · **지금 하실 수 있어요.** · 시작」 |
| `/my/cohorts` | 「마무리 체크 · 이어 하기」 |

셋 다 링크가 `wave=post` 로 실려 있다(실측).

> **QA 회기의 마무리 체크를 열었다.** `open_post_wave` 는 단방향(닫는 RPC 가 없다)이라
> 되돌리지 않는다 — 그 회기의 이름이 「검증 전용」이고 이번 검증이 정확히 그것이었다.
> 실기수(ZR4KB·HMT7Z)는 열지 않았다.

## 6. 판단 사항

1. **버튼 라벨 「안내 보내기」** — 이번 회차에 새로 지은 유일한 문안. **최박사 재가.**
2. **한 화면에 「아직 안 함」이 두 뜻**으로 선다 — 마무리 구획의 것(마무리 미완)과
   명단 묶음의 것(응답 0). 묶음 제목이 각각 감싸고 있어 읽기는 갈리지만 **낱말은 같다.**
3. **참여자 대시보드의 「이어 하기」** — 마무리를 **한 번도 시작 안 한** 사람에게도 「이어 하기」다.
   사전 미완과 같은 갈래를 쓴 결과다. 지휘부가 정한 문안이라 손대지 않았다.
4. **알림은 여전히 자동으로 가지 않는다** — `open_post_wave` 는 `post_opened_at` 만 세운다.
   푸시·메일을 붙일지는 별도 결정 사항이다(지금은 인도자가 「안내 보내기」로 보낸다).
5. **`MemberHome` 의 골드 배너**는 회기가 하나뿐인 참여자에게는 안 뜬다 —
   그 사람의 `/home` 은 **회기 대시보드**이기 때문이다(ADR-181). 대시보드의 버튼이 그 자리를 든다.
