## 1. 반박 셋 — 이대로 하면 안 되는 것

### 1.1 ★★ `.ui-btn`·`.ui-card` 전역 재정의 — **31개 화면이 오염됩니다**

지시서 §3.5 가 `site.css` 에 `.ui-btn` · `.ui-btn--primary` · `.ui-btn--ghost` · `.ui-card` 를
**새로 정의**합니다. 그런데 이 넷은 **`src/core/ui/ui.css` 의 코어 소유 부품**입니다.

| 실측 | 값 |
|---|---|
| `.ui-btn` 을 쓰는 화면 | **31** |
| `.ui-card` 를 쓰는 화면 | **10** |
| `site.css` 를 import 하는 **참여자 화면** | `HomeScreen` · `CohortHomeScreen` · `AssessmentsScreen` |

Next.js 에서 CSS import 는 **전역**입니다. 그러므로 `site.css` 에 `.ui-btn` 을 다시 쓰면
**공개 사이트만이 아니라 참여자 홈·차수 홈·진단 허브·코치 콘솔까지** 골드 그라디언트 버튼이 됩니다.

그리고 그것은 **색 역할 모델을 뒤집습니다.** `design_system.md` §1.5 :

> **네이비 = 앱의 틀 / 골드 = 참여자의 흔적.**
> · 네이비(`--color-primary`) : 헤더·화면 제목·블록 헤딩·**주요/보조 버튼**
> · 골드(`--color-accent`) : **선택**(도트·세그먼트·체크)·진행바·슬라이더 값

지시서의 `.ui-btn--primary { background: linear-gradient(gold) }` 는 **주요 버튼을 골드로** 만듭니다.
`ui.css` 머리가 그 이유까지 적어 두었습니다 — *「색 역할 모델(§1.5): primary = 네이비(앱의 틀).
accent(골드)는 선택·진행 전용」*.

**제안** : 히어로 안에서만 사는 이름을 씁니다 — `.site-hero__btn` 또는 `.hero-cta`.
공용 부품을 히어로 사정으로 고치지 않습니다. 히어로가 특별해 보여야 한다면 **그 자리에서** 특별하게 합니다.

### 1.2 ★★ 6주 여정·GROW 문안 교체 — **사본이 갈립니다**

지시서 §3.2 가 `WEEK_CELLS` 여섯과 `GROW_ROWS` 다섯을 통째로 바꿉니다.
그런데 그 문안은 **한 곳에만 살지 않습니다.**

**⑴ 갈무리 카드와 사본입니다.** 전수 대조(실측) :

| 회차 | 공개 사이트 | 갈무리 카드(참여자가 실제로 보는 것) | |
|---|---|---|---|
| 1 | 과거의 나를 만나다 | 과거의 나를 만나다 | **완전 동일** |
| 2 | 미래의 나를 만나다 | 미래의 나를 만나다 | **완전 동일** |
| 3 | 직면하고 다시 짜다 | 현재를 직면하고, 습관을 다시 짜다 | 같은 뜻 |
| 4 | 펼치고 하나를 고르다 | 옵션을 펼치고, 하나를 선택하다 | 같은 뜻 |
| 5 | 의지가 아닌 환경 | 의지가 아니라 설계 | 같은 뜻 |
| 6 | 끝에서 오늘을 보다 | 끝에서부터 오늘을 다시 보다 | 같은 뜻 |

지시서는 **공개 쪽만** `잃어버린 꿈을 찾다`·`꿈의 모습을 그리다`… 로 바꿉니다.
그러면 **신청하러 온 사람이 본 이름과 참여한 뒤 카드에 뜨는 이름이 달라집니다.**
갈무리 문안은 최박사 결재분이고 `copyBaseline.json` 이 글자 단위로 잠급니다.

**⑵ `존재가치 선언문` 은 세 곳에 있습니다.** 지시서는 `나의 존재가치 선언` 으로 바꾸는데,
그 낱말이 **모집 랜딩 결재 문안**에도 박혀 있습니다 —
`recruit.test.ts:463` 이 *「손에 남는 것 · **존재가치 선언문**, 인생 조감도, 단 하나의 도미노, 환경 설계도.」*
를 글자로 잠급니다. 가치 카드 문안(`values/copy.test.ts`)도 같은 낱말을 씁니다.

**⑶ `/about` 이 조용히 바뀝니다.** `WEEK_CELLS` 는 `/` 와 `/about` **둘 다** 씁니다
(`programCopy.ts` 머리가 *「각 페이지가 배열을 따로 들면 회차 이름이 바뀔 때 한쪽만 고쳐진다」*
라고 그 이유를 적어 두었습니다). 지시서 §1 의 변경 범위 표에 **`/about` 이 없습니다** —
바뀔 화면이 표에 없습니다.

**⑷ 이 프로젝트의 문안 규율.** 신설 문안이 **최소 스무 줄**입니다 —
히어로 4 + 카드 3장 × 3 + 6주 여정 6 + GROW `desc` 5 + 아이콘 피처 3
(`소수 정예 그룹` · `실전 중심 커리큘럼` · `지속 가능한 성장`).
「문안을 한 글자도 만들지 마라 — 최박사 결재다」가 이 저장소의 규율입니다.

**제안** : 문안은 **별건 결재**로 뺍니다. 이번 회차는 **구조·시각**만 합니다.
문안이 결재되면 `programCopy.ts` 한 곳만 고치면 두 화면이 함께 따라갑니다 —
그 구조가 이미 그러라고 만들어져 있습니다.


## 2. 보완 넷 — 빠졌거나 어긋난 것

### 2.1 `design_system.md` §9.7 부품 사양과 갈립니다

부품 표에 **`SiteHero` 와 `GrowAxis` 사양이 이미 확정돼 있습니다.**

| 항목 | 확정 사양(§9.7) | 지시서 | 판정 |
|---|---|---|---|
| 헤드라인 | **52px(lg↑) / 26px** | **64px** | 어긋남 |
| 2단 비율 | `1.05:0.95` | `1.05fr 0.95fr` | **같음** |
| 배경 | `surface-inverse` 150deg | 이미지 + 오버레이 | 사양 개정 필요 |
| 슬롯 | eyebrow·헤드라인·lead·CTA 0~2 | **`features` 신설** | 사양 개정 필요 |
| `SiteHero` 금지 | **빈 슬롯을 자리로 남기지 않는다** | — | 지켜야 함 |
| `GrowAxis` 라벨 | `--color-accent` **36px(md↑)** | **80px 원형** | 어긋남 |
| `GrowAxis` md↓ | **가로 5점 트랙** | 1023px↓ 가로 스크롤 | 유사·확인 필요 |

**불변식 20** 은 *「`design_system.md` 확정 전 UI 를 임의로 디자인하지 않는다」* 입니다.
여기는 **확정이 없는 자리가 아니라 확정이 있는데 다른 자리**라, 임의 시행이 아니라 **사양 개정**이 먼저입니다.

**제안** : 지휘부가 §9.7 #1·#2 를 개정해 주시면 그대로 짓겠습니다.
개정 없이 가려면 「이번 시안이 §9.7 을 대체한다」는 한 줄이 필요합니다 — 그것이 곧 개정입니다.

### 2.2 기존 잠금 **둘을 깨뜨립니다** — 지시서에 그 말이 없습니다

`src/app/(public)/page.test.tsx` 가 지금 이것을 잠급니다 :

| 줄 | 단언 | 지시서가 바꾸는 것 |
|---|---|---|
| `:19` | `expect(html).toContain('참여 신청')` | → `지금 시작하기` |
| `:34` | `expect(html).toContain('프로그램 소개')` | → `6주 여정 살펴보기` |

같은 말이 한 화면에 둘입니다. 지시서의 `지금 시작하기` 는 **그 중복을 없앱니다** — 이건 개선입니다.

## 3. 제안하는 진행 — 둘로 가릅니다

| 회차 | 범위 | 막는 것 |
|---|---|---|
| **A. 구조·시각** (지금) | 배경(최적화) · 원형 노드 · 아이콘 피처 슬롯 · CTA 화살표·호버 · 카드 상단 골드선 | 문안은 **한 글자도 안 바꾼다**. 공용 `.ui-btn` 을 **안 건드린다** |
| **B. 문안** (결재 뒤) | 히어로 4 · 카드 3×3 · 6주 여정 6 · GROW desc 5 · 피처 3 | 갈무리·모집·가치 카드와 **함께** 본다. `/about` 도 같이 바뀐다고 적는다 |

**왜 가르나** : 구조는 되돌리기 쉽고 문안은 어렵습니다. 문안은 세 곳(공개·갈무리·모집)에 걸쳐 있고
한 곳만 바꾸면 **사람이 다른 이름을 두 번 봅니다.** 그리고 A 만으로도 「장면이 없다」는
본래 문제가 풀립니다 — 지금 부족한 것은 낱말이 아니라 **배경과 형태**입니다.

**A 를 먼저 하면 B 가 쉬워집니다.** 문안 자리가 이미 서 있으므로 결재 나온 글자를 넣기만 하면 됩니다.

## 4. 판단을 청합니다 — 넷

1. **회차를 A/B 로 가를까요, 한 번에 갈까요.** 한 번에 가면 문안 스무 줄의 결재가 선행되어야 합니다.
2. **`design_system.md` §9.7 #1·#2 개정**(52→64px · `features` 슬롯 · 배경 이미지 · `GrowAxis` 원형 노드)을
   지휘부가 확정해 주십시오. 그것이 있어야 불변식 20 을 안 어깁니다.
3. **공용 `.ui-btn` 은 안 건드리는 것으로 확정**해 주십시오. 히어로 전용 이름으로 짓겠습니다.
   (공용 버튼을 정말 바꾸실 뜻이면 그것은 **전 사이트 개편**이라 별건입니다.)
4. **배경 이미지 목표 용량**을 정해 주십시오. 제안 — **WebP 200KB 이하 · 폭 2벌**.
   원본 5.7MB 를 그대로 쓰지 않겠습니다.

**아직 아무것도 고치지 않았습니다.** 답을 주시면 그대로 짓겠습니다.
