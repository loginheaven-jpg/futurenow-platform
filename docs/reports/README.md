# docs/reports — 검토·설계·완료 보고서

클로드코드(클코1)가 지휘부에 올리는 보고서를 여기에 `.md` 로 둔다.
**지휘부 지시(2026-08-26): 모든 보고는 이 폴더에 파일로 남기고 GitHub 에 push 한다.**
채팅 보고는 요약, 이 폴더는 **전문**이다 — 지휘부가 fresh clone 으로 감리할 때 읽는 자리.

## 세 종류

| 종류 | 언제 | 파일명 |
|---|---|---|
| **검토 보고서** | 지시서를 받고 착수 전. 반박·보완수용·수용 | `YYYY-MM-DD-<슬러그>-검토.md` |
| **설계 보고서** | 지시서가 **구현 전 합의**를 요구할 때(예: `CC_ORDER_site_v2.md` §13-3). 스키마·계약·판정 규칙을 확정받는다 | `YYYY-MM-DD-<슬러그>-설계.md` |
| **완료 보고서** | 작업을 마치고. `CLAUDE.md` §11 규격 | `YYYY-MM-DD-<슬러그>-완료.md` |

슬러그는 대응하는 `docs/tasks/` 지시서와 맞춘다.

> **접미사 규약이 실제와 어긋나 있었다(3차 T-6 정정).** 위 셋만 적어 두었으나 실측하니
> `-완료`(27)·`-검토`(11) 밖에 **여덟 종이 더 있다** — `-완주`·`-초안`·`-실브라우저`·`-성능감사`
> ·`-목차보고`·`-메모검토`·`-리포트패널`·`-설계보고`. 특히 **설계 보고서가 `-설계`와 `-설계보고`
> 두 형태**로 쓰였다.
>
> **파일을 바꾸지 않고 규약을 실제에 맞춘다.** 이름을 되돌리면 커밋 메시지와 다른 보고서가
> 가리키는 경로가 끊긴다 — 얻는 것보다 잃는 것이 크다. 대신 규칙을 이렇게 적는다:
>
> **접미사는 그 보고가 무엇인지 말하는 한 자유롭다.** 위 셋은 표준형이고, 한 발주가 여러 덩이로
> 나뉘면 덩이 이름을 그대로 쓴다(`-T2-리포트패널`·`-실브라우저`). **읽는 사람이 파일명만 보고
> 무엇인지 알면 된다** — 그것이 접미사의 유일한 일이다.

> **여러 단계로 나뉜 발주는 단계마다 완료 보고를 낸다** — `…-<단계>-완료.md`.
> 위 세 종류만 열거해 두었더니 **단계 보고가 어디에도 속하지 않는 것처럼 읽혀 채팅으로만 보고한 일이 실제로 발생했다**(2026-08-26 `site_v2` 0단계).
> **판정이 필요한 사항이 채팅 스크롤백에만 있으면 지휘부가 클론했을 때 읽을 수 없다.** 채팅은 요약이고 이 폴더가 전문이라는 원칙에 단계 보고도 예외가 아니다.

## 완료 보고서에 반드시 담을 것 (`CLAUDE.md` §11)

1. 변경 파일 목록과 각 항목 상태(완·부분·보류)
2. 검증 결과 — `tsc`·eslint·테스트 수. 보안은 **역할별 실측 여부**
3. `architecture.md` 정합(ADR 번호). 사양 변화가 없으면 **"문서 델타 0 + 사유"** 를 명시
4. 계약(`/contracts`) 대비 이탈 여부와 사유
5. 막힌 지점·판단 필요 사항
6. 커밋 해시

## 규율

- **개인을 지목할 수 있는 형태를 넣지 않는다**(`architecture.md` §6.0 · ADR-99). 이 폴더는 **공개 저장소**에 올라간다.
  금지 대상은 **실명·연락처, 그리고 실명이나 식별 가능한 속성과 결합된 발언 원문**이다.
  실측 수치·집계·문안, 그리고 **이름과 분리된 발언 원문**은 된다. 결합 여부가 애매하면 먼저 보고한다.
- **상주 QA 계정은 "픽스처 잔여 0"의 명시적 예외다**(지휘부 지정 2026-08-27). 통합·실브라우저 검증은
  트랜잭션 롤백으로 잔여를 0 으로 두는 것이 규칙이나, 세션이 필요한 검증(로그인 뒤 화면)은 롤백으로 만들 수 없다.
  그래서 **차수 미소속 · `individual` · `decision_note` 에 "QA 검증 전용"** 을 명시한 계정 하나를 상주시킨다.
  픽스처가 아니라 **상주 자산**이므로 검증 후 지우지 않고, 실측 보고에서 그 계정을 잔여로 세지 않는다.
  **자격 증명은 저장소·보고서·커밋에 싣지 않는다** — 지휘부가 별도 경로로 전달한다.
- **미조치 보안 취약점 보고서는 이 폴더에 두지 않는다** — 공격 지도를 공개하는 것이 된다.
  비공개 폴더에 두고, 조치가 끝난 뒤 요약본만 옮긴다.
  수치를 적을 때는 **분자·분모의 기준과 기준 시점**을 함께 적는다(ADR-94 §6 — 과거 `6 vs 7` 혼선 재발 방지).
