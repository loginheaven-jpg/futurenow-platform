ORDER `qa_accounts` — QA 상주 계정 구축 (실기기 검증 기반)
발주 2026-08-27 · 지휘부(최박사 + Claude) · F-3 게이트 잔여 칸(실기기 확인)을 닫는 기반 작업 브랜치: 코드 변경이 생기면 `feat/site-v2-4` 안에서 · 마이그레이션 0 원칙(필요 시 중단·보고)
0. 세 확정 (클코1이 청한 명세)
0.1 환경 — 프로덕션 Supabase다
별도 프로젝트는 만들지 않는다. 실기기 검증의 목적이 실제 배포된 것을 재는 것인데, 별도 환경은 배포·데이터·마이그레이션이 갈라져 검증 대상이 아닌 것을 검증하게 된다. 격리는 환경이 아니라 계정·차수 수준에서 한다(§1).
0.2 집계 오염 — 원칙은 "오염 방지"가 아니라 "오염 0"이다
`cohort_seats_taken`은 코드 단위 집계이고 공개 노출은 `/recruit`의 `ZR4KB`뿐이다(라이브 확인). 따라서 QA 계정이 실기수(`ZR4KB`·`HMT7Z`)에 등록하지 않으면 오염이 구조적으로 0이다.
금지 셋 — ① 실기수 등록 금지 ② 실기수 갈무리·피드·가치카드에 쓰기 금지 ③ 실계정·실기수 데이터 수정 금지. QA의 발자국은 QA 차수 안에만 남는다.
0.3 비밀번호 — 평문이 대화창·저장소·보고서에 닿지 않는다
클코1의 제안을 그대로 채택한다 — 생성·비밀번호 설정은 최박사가 직접, 클코1은 받은 자격으로 확인만. 전달 경로는 하나다:
단계 누가 무엇을 생성 최박사 `/signup`으로 계정 생성(§1) · 비밀번호는 본인만 안다 전달 최박사 클코1 작업 PC의 `.env.local`에 직접 입력 — `QA_USER_EMAIL` `QA_USER_PASSWORD` `QA_COACH_EMAIL` `QA_COACH_PASSWORD` 사용 클코1 env에서 읽어 로그인 자격 확인·검증 하네스 구동. 값을 출력·로그·커밋·보고서에 싣지 않는다 확인 클코1 `.gitignore`가 `.env.local`을 막는지 재확인 후 착수(기존 확인이 있어도 다시)
노출 의심 시 처리도 정한다 — 최박사가 Supabase 대시보드에서 해당 계정 비밀번호를 재설정하면 끝이다. 재설정이 값싼 구조이므로 자격 수명에 부담을 두지 않는다.
1. 구성 — 계정 둘 + QA 전용 차수 하나
인증 뒤 화면이 두 층(참여자·콘솔)이므로 계정도 둘이다. 실기수·실코치 계정을 빌리지 않는다.
항목 qa-user qa-coach 이메일 `qa.user@futurenow.test` 계열(최박사 수신 가능 주소로 치환 가능) `qa.coach@…` 동일 role `user` (기본) `coach` — 최박사(admin)가 부여(자가승격 방지 체계 그대로) membership `individual` — 승인 큐에서 최박사가 승인 · `decision_note` "QA 검증 전용" 필수 동일 소속 QA 전용 차수에 등록 QA 전용 차수의 소유 코치
QA 전용 차수 — 운영자 화면에서 신설한다. 이름에 `[QA]` 접두. 실기수 목록과 한눈에 갈리게.

* `kind` 처리는 설계 보고 사항이다(§2). 신설 차수가 `DEFAULT 'seminar'`를 받으면 회원 판정·피드 생성에 걸리는데, `kind` 컬럼은 1차에서 UPDATE 권한이 회수됐다 — 전환 경로 (기존 admin RPC 유무 · 없다면 지휘부 승인 하 단건 SQL)를 실측해 제안하라.
* `decision_note` "QA 검증 전용"은 "픽스처 잔여 0" 원칙의 명시적 예외다(3차 결정 재확인). QA 계정·차수는 잔여가 아니라 상주 자산이며, 그 사실이 note로 저장소 밖 DB에 남는다.


3. 하지 말 것

1. 클코1의 DB 직접 쓰기 0 — 계정·승인·role·차수 전부 기존 화면·RPC로 최박사가 한다
2. 실기수 등록·실데이터 수정 금지(§0.2) — 검증 편의로 `cohort_seats_taken` 노출 코드를 건드리지 않는다
3. 자격 값의 출력·로그·커밋·보고서 게재 금지(§0.3)
4. 마이그레이션 0 — kind 전환이 단건 SQL로 결론 나면 지휘부 승인 후 실행하고 실행문을 보고서에 남긴다(비밀 아님)
5. QA 계정으로 실기수 피드·갈무리를 읽는 것은 허용되지 않는다 — 애초에 소속이 없어 구조적으로 막히지만, 우회를 시도하지 않는다
