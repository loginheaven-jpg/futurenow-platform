# CC ORDER - 원응답 페이지 재배열 + 문항 코드 부여

> 발신: 지휘부(최박사 + Claude) · 수신: 클로드코드(클코1)
> 작성: 2026-07-16
> 감사 기준 커밋: `e392b28` (main HEAD). 이 커밋에서 분기할 것.
> 선행: ORDER v2 Phase 2(원응답 페이지, `RawAnswers.tsx`)가 이미 병합됨. 이 지시는 그 컴포넌트만 손본다.

---

## 1. 배경 (왜 이 수정을 하는가)

인도자 가이드로 원응답을 대조할 때 두 가지 불편이 확인됐다.

1. **순서 불일치.** 원응답 페이지는 진단지 구조 순서(나침반 → 지금의 나 → 믿음 → 간격 → 주관식)로 뜬다. 그러나 가이드의 읽기 흐름은 **활력 → 나침반 → 준비도 → 간격 → 언어 → 숨은 층**이다. 특히 '지금의 나' 섹션이 활력(A)·준비도(C)·함정(D) 문항을 문항 번호순으로 뒤섞어, 인도자가 "활력 문항이 어디 있지" 하며 찾아야 한다.
2. **코드 부재.** 가이드는 각 문항을 A2·NAV1·C5·D1 같은 코드로 부른다. 원응답에는 코드가 없어, 인도자가 가이드의 'A2'를 원응답에서 찾으려면 문장으로 대조해야 한다.

두 불편을 함께 푼다 - 원응답을 **가이드 지표 순서로 재배열**하고, 각 문항에 **코드 라벨을 부여**한다.

---

## 2. 절대 건드리지 말 것 (경계)

1. **`RawAnswers.tsx` 외 변경 없음.** 채점·데이터·라우팅 불변. `scoring.ts`·`interpretation.ts`·참여자 경로(`MirrorView`·`participantMirror`) 무변경.
2. **코드는 참여자에게 노출되지 않는다.** 원응답 페이지는 코치 전용(참여자 `role==='user'` 리다이렉트)이라 코드 표시가 안전하다. 코드를 참여자 미러·참여자 경로에 배선하지 않는다.
3. **코드는 문항 원문을 대체하지 않고 '추가'한다.** ORDER v2 §4.2의 "코드 덤프가 아니라 문항 원문" 원칙은 유지된다 - 코드는 매칭용 작은 라벨로 문항 원문 옆에 붙을 뿐, 원문·응답 표시는 그대로다.
4. **파생 점수·역채점 표기 없음.** 원응답은 여전히 원문+응답만. 역채점 여부·활력 지수·GROW 축값을 이 페이지에 넣지 않는다(기존 원칙 유지).

## 3. 구현 지시 (`RawAnswers.tsx`)

### 3.1 섹션 순서를 가이드 지표 순서로 재배열

현재 6개 그룹을 아래 7개 그룹·순서로 바꾼다.

| 순 | 그룹 제목 | 코드(이 순서로 렌더) | 비고 |
|---|---|---|---|
| 1 | 들어가며 · 인생 조감도 | (INTRO 자유서술) | 도입 맥락, 맨 위 유지 |
| 2 | 활력 | A1 · A3 · A2 · A5 · A4 | 생기(A1·A3) 뒤 마모(A2·A5·A4) 순 |
| 3 | 나침반 | NAV1 · NAV2 · NAV3 · NAV4 | bipolar, 기존 표시 유지 |
| 4 | 준비도 (GROW+F) | C2 · C1 · C3 · C4 · C6 · C5 · C8 · C7 · C9 | **축 짝 순서**(조감도·현실인식·원씽·피드백·정체성) |
| 5 | 다섯 영역의 간격 | B1 · B2 · B3 · B4 · B5 | 기존 유지 |
| 6 | 참여자의 언어 | E1 · E2 · E3 | 기존 '나에게 묻는 시간' → 제목만 이대로 두거나 '참여자의 언어'로 통일(택1) |
| 7 | 숨은 층 · 인도자 참고 | D1 · D2 · D3 · F1 · F2 | **함정(D)+믿음(F)을 끝으로 모음** |

핵심 변경 두 가지.

- **기존 '지금의 나'(A·C·D 혼합) 그룹을 해체**한다. A는 '활력'(그룹2)으로, C는 '준비도'(그룹4)로, D는 '숨은 층'(그룹7)으로 분리한다. `NOW_CODES`(현재 `itemPrompts` 키에서 A·C·D 필터)는 더 이상 쓰지 않는다.
- **준비도(그룹4)는 축 짝 순서**로 배열한다: 조감도(C2·C1) · 현실인식(C3·C4) · 원씽(C6·C5) · 피드백(C8·C7) · 정체성(C9). 코드 번호순(C1~C9)이 아니라 이 순서다. 가이드 준비도 표와 1:1로 맞추기 위함이다.
- **믿음(F1·F2)을 중간에서 그룹7로 이동**해 함정(D)과 함께 '숨은 층'으로 묶는다.

### 3.2 각 문항에 코드 라벨 부여

`Item` 컴포넌트(또는 각 문항 렌더)에 코드 라벨을 문항 원문 앞이나 옆에 작게 표시한다.

- 표시 예: **`A2`** · "열심히 살고는 있지만, 제자리걸음이라는 느낌이 든다." → 매우 그렇다 (5/5)
- 스타일: 작은 모노스페이스 태그(`t-caption` 또는 유사), `--color-text-secondary` 정도의 절제된 색. 문항 원문이 주(主), 코드는 보조.
- 대상: 전 문항(A·NAV·C·B·E·D·F). INTRO 자유서술은 코드 없음.
- (선택) 진단 문항 번호(문5·문7 등)도 함께 보이고 싶으면 `A2 · 문7` 형태로 병기 가능. 기본은 코드만. 이 선택지는 최박사 확인 후 반영.

### 3.3 그룹4 축 라벨 (선택·권장)

준비도 그룹 안에서 축별 소구분(조감도·현실인식·원씽·피드백·정체성)을 얇은 소제목으로 넣으면 매칭이 더 쉬워진다. 강의 어휘이나 코치 전용 페이지라 무방하다. 넣을지는 최박사 확인. 넣지 않아도 3.1의 짝 순서 + 3.2의 코드만으로 매칭은 된다.

## 4. 인수 기준 (테스트)

1. **순서.** `RawAnswers` 렌더에서 그룹이 활력 → 나침반 → 준비도 → 간격 → 언어 → 숨은 층(들어가며 맨 위) 순으로 나오고, 준비도 내부가 C2·C1·C3·C4·C6·C5·C8·C7·C9 순임을 단언.
2. **코드 표시.** 각 문항에 코드(A2·NAV1·C5·D1·B1·E1·F1)가 렌더됨을 단언.
3. **A·C·D 분리.** '지금의 나' 그룹이 사라지고, A는 활력·C는 준비도·D는 숨은 층 그룹에 속함을 단언.
4. **믿음 이동.** F1·F2가 숨은 층 그룹(끝)에 있음을 단언.
5. **참여자 미노출 회귀.** 참여자 미러·`MirrorView`에 코드(A2·D1 등)와 원응답이 없음을 단언(기존 가드 유지).
6. **원문 유지.** 코드 추가에도 문항 원문·응답 표시가 그대로임을 단언(코드 덤프 아님).
