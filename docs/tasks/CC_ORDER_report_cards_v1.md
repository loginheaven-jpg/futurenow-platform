> 발신: 지휘부(최박사 + Claude) · 수신: 클로드코드(클코1)
> 작성: 2026-07-16

> 첨부: `readiness_growf_badges.html` (배지 시안 - 색·배치의 구현 기준)

## 1. 배경 (왜 이 수정을 하는가)

두 가지 리포트 화면 개선이다. 둘 다 코치 리포트 1면의 시각 카드에 관한 것이다.

**개선 1 - 카드 좌우 교환.** 리포트 1면은 2×2 카드다. 현재 아래 행이 왼쪽 '다섯 영역의 간격', 오른쪽 '준비도(GROW+F)'로 배치돼 있다. 그러나 가이드의 해석 순서는 **활력 → 나침반 → 준비도 → 간격**이다. 아래 행 좌우를 바꿔 **준비도를 왼쪽, 간격을 오른쪽**으로 놓으면, 카드를 왼→오·위→아래로 읽는 동선이 해석 순서와 정확히 일치한다.

```
현재                          목표
[활력]     [나침반]           [활력]     [나침반]
[간격]     [준비도]     →      [준비도]   [간격]
```

**개선 2 - 준비도 카드에 GROWF 이니셜 배지.** 준비도 다섯 축 왼쪽에 G·R·O·W·F 이니셜 배지를 붙인다. GROW 코칭 모델과 진단 항목의 대응을 한눈에 보이게 하고, 두 축을 색으로 강조한다(§3.2).

---

## 2. 절대 건드리지 말 것 (경계)

1. **채점·데이터 불변.** `scoring.ts` 무변경. 준비도 값·순서·산식을 바꾸지 않는다. 이 지시는 카드 배치와 배지 표시(표현)만 다룬다.
2. **참여자 경로 불변.** 이 카드들은 코치 리포트(`ReportScreen`) 것이다. 참여자 미러에 배선하지 않는다.
3. **축 순서 불변.** 준비도 축은 지금의 표시 순서(조감도·현실인식·원씽·피드백·정체성 = G·R·O·W·F)를 유지한다. 배지는 그 순서에 이니셜을 붙일 뿐이다.

---

## 3. 구현 지시

### 3.1 카드 좌우 교환

리포트 1면 2×2 그리드에서 아래 행의 '다섯 영역의 간격'과 '준비도(GROW+F)' 위치를 맞바꾼다. 최종 배치는 다음과 같다.

- 위 행: 활력(좌) · 나침반(우)
- 아래 행: **준비도(좌) · 간격(우)**

그리드 렌더 순서만 바꾼다. 카드 내부 구현·크기는 그대로. 구현 전, 준비도가 원래 오른쪽에 놓였던 레이아웃상의 이유(예: 카드 높이 차)가 있었는지 확인하고, 단순 교환으로 시각적 깨짐이 없는지 본다. 두 카드가 동일 크기 사각 카드라면 문제없다.

### 3.2 준비도 카드 GROWF 배지 (첨부 HTML 기준)

첨부 `readiness_growf_badges.html`이 색·배치의 구현 기준이다. 그대로 옮긴다.

**배지.** 각 축 왼쪽에 정사각(약 30px) 라운드 배지, 이니셜 흰색 볼드. 매핑은 고정이다.

| 순서 | 축(항목명) | 이니셜 |
|---|---|---|
| 1 | 조감도 | G |
| 2 | 현실인식 | R |
| 3 | 원씽 | O |
| 4 | 피드백 | W |
| 5 | 정체성 | F |

**세 강조색.** 배지와 막대(fill)에 같은 색을 적용한다.

| 대상 | 색 | 조건 |
|---|---|---|
| 지렛대 | 초록(#2f8f6b) | **최고점 축.** 동점이면 해당 축 모두 초록 |
| 바닥 | 금색(디자인 토큰 gold 계열) | **F(정체성) 축** 고정 |
| 나머지 | 네이비(기존 막대색) | 위 둘에 해당하지 않는 축 |

**우선순위.** F가 최고점인 경우, 그 축은 **초록(지렛대)을 우선** 적용한다(금색보다 초록이 이긴다). 즉 지렛대 판정을 먼저 하고, 남은 F에 금색을 준다.

**동적 판정.** 최고점은 다섯 축 값에서 런타임으로 계산한다(하드코딩 금지). 첨부 HTML의 R 초록·F 금색은 예시 리포트(현실인식 4.0 최고) 기준의 예시일 뿐이다.

- 디자인 토큰을 쓴다(첨부의 하드코딩 색은 시안 편의용). 초록·금색은 디자인 시스템에 대응 토큰이 있으면 그것을, 없으면 근사값을 추가하되 care 톤과 구별되게 한다.
- 배지 아래·옆 레이아웃은 첨부의 배지+막대 정렬을 따른다.

### 3.3 (선택) 범례

첨부 HTML 하단의 3색 범례(지렛대·바닥·나머지)를 카드 하단에 얇게 넣을지는 최박사 확인. 공간이 좁으면 생략하고 툴팁으로 대체 가능. 기본은 생략, 범례 없이 색만.

## 4. 인수 기준 (테스트)

1. **카드 순서.** 리포트 1면 아래 행이 준비도(좌)·간격(우) 순으로 렌더됨을 단언.
2. **배지 표시.** 준비도 다섯 축에 G·R·O·W·F 배지가 항목명 왼쪽에 순서대로 붙음을 단언.
3. **지렛대 강조.** 최고점 축의 배지·막대가 지렛대 색이고, 동점이면 복수 축에 적용됨을 단언(값을 달리한 케이스로).
4. **바닥 강조.** F 축이 최고점이 아닐 때 금색, 최고점일 때 지렛대색(초록 우선)임을 단언.
5. **불변.** 준비도 축 순서·값이 그대로이고, 참여자 미러에 배지·색 로직이 배선되지 않음을 단언.
