## 1. 개정 항목

### 개정 1 — 우당탕탕 프로젝트 신설 (1면 · areaPick 하위)

**신설 근거**
녹취 [46:10] 인도자 발언. "다음 주까지 정해서 이 우당탕탕 프로젝트의 이름을 한번 붙여보시길 바라요. 여기 후기 쓰는 데 있잖아요, 거기다 딱 쓰세요." 카드에 쓰라고 지정된 항목이 카드에 없다.
같은 발언에서 대상 영역도 지정됐다. "자기의 점수가 제일 낮은 영역에서 뭐가 됐든지 간에 우당탕탕을 좀 해보시기를 원하고요." 카드 ①이 그 영역을 고르는 칸이므로 같은 필드 묶음에 붙인다.

**사양**

| 항목 | 값 |
|---|---|
| 위치 | 1면 `areaPick` 묶음 안, `gap_want` 바로 아래 두 번째 줄 |
| key | `rough_project` |
| 필수 여부 | **선택** (필수 6칸 유지 — `REQUIRED_3` 불변) |
| 입력 형태 | 한 줄 입력 |
| 라벨 | `그 영역에서 시작할 '우당탕탕 프로젝트'의 이름` |
| 보조 문구 | `잘하려 하지 않고 일단 시작해 보는 작은 프로젝트입니다. 완성이 아니라 시작이 목적이라, 이름만 붙여 두셔도 됩니다.` |
| placeholder | `하루 한 줄 쓰기 한 달` |
| 책 페이지 | **붙이지 않는다** (아래 사유) |

**책 페이지를 붙이지 않는 이유**
우당탕탕 프로젝트는 책 98쪽에 한 번 등장하며, 이는 바로 아래 `stuck_named` 문항이 이미 참조하는 96~104쪽 안에 든다. 참조가 여섯이 되면 카드가 색인처럼 읽힌다는 기준(2026-08-09 회신)에 걸린다.

**필수로 올리지 않는 이유**
과제 시점이 어긋난다. 갈무리 제출은 이틀 안(인도자: "월요일까지"), 우당탕탕 명명은 "다음 주까지"다. 필수로 두면 아직 정하지 못한 사람이 카드를 닫지 못한다. 카드는 다음 시간 24시간 전까지 고쳐 쓸 수 있으므로 선택으로 두고 나중에 채우게 한다.

**나눔 후보 열 반영**
`summaryFields` 두 번째 자리에 추가 제안. 짧고 밝고 실행 지향이라 4회차 오프닝에서 읽기 좋다. 항목이 넷이 되는 것이 상한을 넘는지는 플랫폼 대화창 판단에 맡긴다.

```
{ label: '우당탕탕 프로젝트', key: 'rough_project' }
```

### 개정 2 — 습관 짝의 기입 순서 반전 (1면 `pairText`)

**근거**
녹취 [139:45] 참여자 소감. "늘려야 할 습관에는 사실 하나도 못 채웠어요. 없애야 할 습관이랑 새로 시작하는 습관만 엄청 독하게 적었는데, 그래서 이런 저의 잘못된 부분들에 더 집중을 하니까 속으로는 상당히 불편했어요."
사분면 좌측 상단이 Eliminate이고 사람은 위에서부터 채운다. 짝 맞추기를 나중에 요구하면 이미 자책 목록이 완성된 뒤다. 배치가 아니라 **순서**가 만든 결과다.

**현행 → 개정**

| | 현행 | 개정 |
|---|---|---|
| 문항 라벨 | 오늘 다시 짠 습관 중에서, 짝 하나만 옮겨 주세요. (책 117~118쪽) | **이번 주에 실제로 바꿔 볼 짝 하나만 옮겨 주세요. (책 117~118쪽)** |
| from | `habit_stop` · 줄이거나 없애기로 한 것 | **`habit_start` · 이번 주에 새로 시작하거나 늘릴 것** |
| connector | ↓ 그 자리에 | **↓ 그 자리를 만들려면** |
| to | `habit_start` · 그 자리에 들이기로 한 것 | **`habit_stop` · 줄이거나 없앨 것** |
| to.help | 비운 자리를 그냥 두면 며칠 안에 원래대로 돌아갑니다. 실패가 아니라 원래 그렇게 됩니다. | **삭제** (연결선 문구가 논리를 진다) |

**키는 바꾸지 않는다.** 화면 순서만 뒤집는다. 저장된 데이터, 결측 판정, 나눔 열이 그대로 산다.

**`summaryFields`는 그대로 둔다.** `{ from: 'habit_stop', to: 'habit_start' }`는 교체의 의미 방향(없앤 것 → 들인 것)이며 화면 기입 순서와 별개다.

**`REQUIRED_3` 그룹 내 필드 순서**도 화면과 맞춘다(`habit_start` 먼저). 결측 안내가 화면 문구를 그대로 읽으므로 양쪽이 어긋나면 안 된다.

### 개정 3 — 심화① 보조 문구 재작성

| | 문안 |
|---|---|
| 현행 | 고쳐야 할 것을 찾는 칸이 아닙니다. 어긋난 곳이 보이면 그것만으로 충분합니다. |
| 개정 | **보인 것 하나면 충분합니다. 오늘은 알아차리는 데까지가 몫이에요.** |

코치 의견은 삭제였으나 받지 않는다. 이 문구가 심화 블록의 유일한 자책 방지 장치이고, 3회차 녹취에서 그 위험이 실제로 발현됐다. 다만 "~이 아닙니다"라는 부정 서술이 약하다는 지적은 타당하므로 긍정형으로 바꾼다.

### 개정 4 — 심화② 보조 문구 축약

| | 문안 |
|---|---|
| 현행 | 좋은 말이든 아니든 상관없습니다. 그냥 자주 나오는 말이면 됩니다. |
| 개정 | **좋은 말이든 아니든, 그냥 자주 나오는 말이면 됩니다.** |

**문항 라벨은 바꾸지 않는다.** 코치 제안("꼭 바꾸고 싶은 말은 무엇이고 어떻게 바꿀 건가요")은 미수용. 사유 둘.
첫째, 바로 위 습관 짝과 겹친다. 워크북 개정안에서 말 라운드가 이미 짝 구조로 설계되므로 같은 것을 두 번 쓰게 되고, 발주서 §2가 경고한 대로 두 번 다 얕아진다.
둘째, 이 칸은 의도적으로 얕다. 정본 주석대로 4회차를 가볍게 여는 재료다. 세 번 자기를 낮게 본 주간이라 다음 회차를 결심 목록으로 열면 무거움이 두 주 연속된다.

### 개정 5 — 다음 한 걸음 보조 문구 (2면 `step.help`)

| | 문안 |
|---|---|
| 현행 | 오늘 마지막에 정하신 그 하나를 그대로 옮기시면 됩니다. |
| 개정 | **오늘 정하신 것 하나면 됩니다. 위에 우당탕탕 프로젝트를 적으셨다면, 그 첫 걸음이어도 좋습니다.** |

한 걸음을 우당탕탕으로 대체하자는 코치 의견은 미수용. 한 걸음은 고정부이고, 4회차 카드의 지난 한 걸음 결산이 `step_what`·`step_when`을 되비추므로 대체하면 회차 간 사슬이 끊긴다. 층위도 다르다 — 우당탕탕은 여러 주에 걸친 프로젝트, 한 걸음은 이번 주 한 동작이다. 대체 대신 보조 문구로 잇는다.

## 4. 미결 · 판단 요청

**① 여섯 번째 영역**
녹취에서 인도자가 즉석으로 신앙(하나님과의 관계) 축을 추가했고 참여자가 실제로 사용했다. 최고점으로 신앙을 고른 사람 둘, 최저점으로 고른 사람 하나. 카드 ① 칩은 다섯이라 이들이 매핑할 자리가 없다. 6축 체계 승인 여부가 정해지면 칩과 진단 축을 함께 조정한다. **이번 개정에서는 손대지 않는다.**

**② 마음 낱말 '조급함'**
3회차 녹취 실측에서 등장하지 않았다. 대신 나온 말은 "막연한 걱정"(2회차 '막막함'과 중복)과 "자책하지 않고"였다. 이번 개정에서는 바꾸지 않고 3회차 제출 데이터로 선택률을 확인한 뒤 4회차에서 판단한다.

**③ 한 걸음 동질화**
녹취 소감에서 여섯 명 중 다섯이 같은 항목('일기 쓰기')을 골랐다. 인도자가 강하게 권한 결과다. 3회차 카드의 한 걸음도 같은 문장으로 채워질 가능성이 크다. 카드로 막을 문제가 아니라 스크립트북 사안으로 넘긴다.
