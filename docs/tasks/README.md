# docs/tasks — 작업지시서

지휘부가 클로드코드(클코1)에 내리는 작업지시서를 여기에 `.md` 로 둔다.

## 규율

- **참여자 실명·발언 원문을 넣지 않는다**(`architecture.md` §6.0). 이 폴더는 **공개 저장소**에 올라간다.
  녹취 인용이 필요하면 **발언만** 옮기고 이름·연락처·식별 가능한 정황은 지운다.
  실명이 섞여 오면 클코1 은 **커밋하지 않고 먼저 보고한다.**
- 발행 직전 fresh clone 기준 커밋을 명시한다(ADR-88).
- 이전 지시서를 정정할 때는 **부분 폐기 범위**를 절 번호로 명시한다(CC MEMO 관례).

## 파일명

`YYYY-MM-DD-<제목-슬러그>.md` 를 권장하되, 발신 대화창의 자체 명명(`GALMURI_ORDER_S3_rev1.md` 등)을 쓰면 그대로 둔다.
검토·완료 보고서는 `docs/reports/` 에 같은 슬러그로 대응시킨다.

## `docs/` 의 다른 것

`.gitignore` 가 `docs/` 를 **기본 차단**하고 이 폴더와 `docs/reports/` 만 연다.
녹취록·워크북·상담 기록은 저장소 밖(`C:\dev\jindan-private-docs`)에 둔다.
