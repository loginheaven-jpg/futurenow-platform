## 개정 이력 — 1판 §1을 철회한다

1판은 `docs/tasks/GALMURI_ORDER_S3_rev1.md` 22·56행의 발언 원문을 제거하라고 지시했다. **철회한다. 원문을 그대로 둔다.**

**발신 대화창의 오독이었다.** `architecture.md` §6.0의 금지 대상은 개인을 지목할 수 있는 형태이며, 실명이나 식별 가능한 속성과 **결합된** 발언 원문을 말한다. 이름과 분리된 원문 자체는 대상이 아니다. 클코1이 도착분을 "이름이 없어 통과"로 판정한 것이 옳았다. 1판이 이를 "자기 규율을 완화했다"고 적은 것도 함께 철회한다.

근거를 다시 정리하면 이렇다.

| 1판의 논거 | 왜 성립하지 않는가 |
|---|---|
| 열 명 남짓 차수라 재식별된다 | 그 방에 있던 사람은 **이미 그 말을 직접 들었다.** 아는 사람이 계속 아는 것은 공개로 인한 손실이 아니다. 저장소 방문자에게 그 문장은 이름 없는 한 줄이다 |
| 되돌릴 수 없으므로 막아야 한다 | 되돌릴 수 없다는 것은 위험의 크기가 아니라 되돌리는 비용이다. ADR-96의 녹취록은 실명이 든 전문이라 위험이 실재했고, 그 논리를 위험 없는 대상에 그대로 옮긴 것이 오류다 |
| 판정이 필요 없는 규칙이 강하다 | 실명 결합 금지는 판정이 아니라 **관찰**이다. 이름이 붙어 있는가만 보면 된다. 재식별 가능성을 매번 저울질하는 일과 다르므로, 운용 부담을 이유로 원문을 막을 근거가 되지 않는다 |

그리고 잃는 것이 있다. 요지 서술은 인과를 지운다. ERRC 기입 순서를 반전한 판단은 "잘못된 부분에 집중하니 불편했다"는 인과에 걸려 있는데, 요지로 바꾸면 뒷사람이 그 결정을 감리할 근거가 얇아진다. 없는 위험을 막느라 치를 비용이 아니다.

## 1. 시정 — §6.0 문언을 다의적이지 않게 고친다

원문을 지울 일은 없지만 문언은 손봐야 한다. 현행 "실명·발언 원문은 안 되고"가 **두 개의 병렬 금지로도, 한 덩어리로도 읽힌다.** 실제로 발신 대화창이 앞쪽으로 읽어 잘못된 시정 지시가 나갔다. 같은 혼선이 다음 지시서에서 또 난다.

### 조치

1. `architecture.md` §6.0의 해당 문장을 아래 취지로 고친다.

> 금지 대상은 **개인을 지목할 수 있는 형태**다. 실명·연락처, 그리고 실명이나 식별 가능한 속성과 **결합된** 발언 원문. 이름과 분리된 발언 원문은 무방하다 — 요지로 바꾸면 판단의 근거가 얇아지므로 **결합만 끊고 원문은 남긴다.**

2. `docs/tasks/README.md`·`docs/reports/README.md`의 같은 대목을 위 문언과 맞춘다.
3. 정정 사유를 ADR로 남긴다. **지휘부가 규율을 완화한 것이 아니라 발신 대화창의 오독이었다는 점**, 그리고 **클코1의 최초 판정이 옳았다는 점**을 함께 적는다. 이 기록이 없으면 다음에 같은 오독이 났을 때 판례가 없다.
4. 판정이 갈릴 때의 처리를 한 줄 넣는다 — 이름과의 결합이 애매하면 **커밋하지 않고 먼저 보고한다.** 관찰로 끝나지 않는 경우만 보고 대상이다.

## 2. 시정 — `summaryFields` 우당탕탕을 **두 번째** 자리로

완료 보고서 §5-③의 근거가 코드와 어긋난다.

```
src/app/coach/cohort/[cohortId]/checkin/page.tsx:208
  {s.cells.map((c, j) => (c.has ? (...) : null))}
```

빈 칸은 렌더되지 않는다. "빈 칸이 목록 한복판에 생겨 읽는 흐름이 끊긴다"는 상황이 발생하지 않는다.

**자리는 카드 순서를 따른다.** 클코1이 `readModel`에 대해 세운 원칙("열람은 카드를 되비추는 것")을 나눔 열에도 그대로 적용한다. 카드에서 `rough_project`는 `gap_want` 바로 아래이고, 4회차 오프닝에서 프로젝트 선정의 직접 재료다.

```
{ label: '지금 가장 바라는 것',   key: 'gap_want' }
{ label: '우당탕탕 프로젝트',     key: 'rough_project' }   ← 여기
{ label: '습관 바꾸기', from: 'habit_stop', to: 'habit_start' }
{ label: '입에 붙은 말',         key: 'speech_habit' }
```

`session3.test.ts`의 나눔 열 단언도 함께 고친다.
